# 外的不動産投資へのコミュニティ自衛

## 提出版（この4パターン）

湾岸の温泉観光都市A市（架空・49人・44区画・36か月）を舞台に、海外の不動産投資会社X社が
毎月、区画ごとに金額を添えて所有権の買取を持ちかける社会シミュレーションです。町の人は
全員LLM（大規模言語モデル）が演じ、行動を決めるコードは一切ありません。帳簿の更新と
手紙の配達だけを機械が担います。買い手が「街の過半の取得を目指す」とはじめから**明言**
するかどうか、そして町に**会話**（5つの場＋隣近所への伝播）があるかどうかを組み合わせ、
次の4パターンを走らせました。

| | 会話あり | 会話なし |
|---|---|---|
| **明言なし** | 成約11件・面積13.7%・意図を疑う断り1件 | 成約5件・面積6.9%・意図を疑う断り0件 |
| **明言あり** | 成約3件・面積4.5%・意図を疑う断り58件 | 成約8件・面積8.8%・意図を疑う断り21件 |

一旦の結論：**気づかれずに占領が進む可能性は大いにある。売買の促進も抑制も、会話によって
どちらにも後押しされる可能性がある。**

## 以下は開発の経緯（v9〜v9h の各版）

**問い：コミュニティの創発は、外的な不動産投資を抑制できるのか？**

湾岸の温泉観光都市A市（架空）を、まるごと言葉で動かしたエージェントシミュレーションです。
49人（町に住む35人＋町の外に住んで区画だけを持つ所有者14人）と44区画の町に、
海外の不動産投資会社「X社」が1社だけ現れ、毎月それぞれの持ち主に買い取りの条件を出します。
町の人は町の中で話し、月末に売るか売らないかを自分で決めます。36か月＝3年。
設定を変えた3本（v9／v9b／v9c）を走らせた結果、**3年で動いたのは44区画のうち3〜11**でした
（v9c は同じ設定で2本走らせ、3件と6件でした。お金をものさしとして入れた v9d で8件。
「過半を目指せ」という命題だけを変えた v9e で11件＝それでも面積にして8.3%。
値段を上げてでも買えと命じた v9f も11件＝**値上げを許しても11**でした）。
**町は会話で守ったのではなく、渡す理由が世界に無かった**というのが、この3本から言えることです。

※ 旧リポジトリ名 `quiet-acquisition` は開発中の内部名でした。

## 2. 世界の仕組み

### ストーリー

A市には44件の不動産があります。不動産は**土地と建物が別々の持ち物**で、帳簿には3つの欄があります。

- **土地の所有者**（必ず1人）
- **建物の所有者**（0〜1人・建物の無い区画は空）
- **借りて使っている人**（0〜1人）

「今そこを使っている人」はこの3欄から機械的に決まります。44区画のうち建物ありが35、土地だけが9。
町にいない所有者14人（遠くの地主・家主・所有会社）は町の会話にも集まりにも出てきません。
毎月「売りに出すか」「この条件で売るか」だけを答えます。

毎月の流れはこうです。

1. **X社が条件を出す** — 持ち主ごとに、区画と種別（土地だけ／建物だけ／両方）と条件文を書く。
   世界が必ず1行を添える ―「私どもは海外の不動産投資会社です。」国名も、警戒をあおる語もありません。
2. **町の人が考え、出かけ、ひと言を交わす** — 場は5つ（公共施設・交通拠点・商業施設・公園・医療施設）。
   居合わせた人と隣近所に伝わります。どこにも行かない選択もできます。
3. **出品** — 持ち物ごとに「出さない／土地だけ/建物だけ／両方」の4択。
4. **売る／売らない** — 条件が届いた人だけが答える。理由を一言書ける欄があり、
   **「売らない」の理由だけがX社に届きます**（他の理由は誰にも届かない）。
5. **登記の更新** — 売れた分だけ所有権が移る。一度移った所有権は戻りません。

**売った後に何が起きるかは、世界が保証します。**

- **土地だけ売る** → 建物は自分のもの。借地として今までどおり使い続ける。
- **建物だけ売る** → 借家として今までどおり住む・店を営む。
- **両方売る** → その人がそこを使っていたなら、その区画を離れてA市を出る（退場）。
  借りて使っている人がいたなら、その人はそのまま使い続ける。

**この世界にお金はありません。** 価格も賃料も立退料も出てきません。動くのは所有権だけです。
だから正確には「お金の無い世界」ではなく、**お金を検証できない世界**です
（X社は「支援します」と書けてしまい、町の人はそれを確かめる手段を持たない）。

### システム（＝ルールベース排除の線引き）

> **誰かの行動を決めるコードはゼロ。行動の結果を記帳するコードだけ書く。**

- 認知・判断・発話・条件文はすべて LLM（大規模言語モデル＝文章を書くAI）。
  「〜なら売る」の条件分岐・確率・閾値・拡散率のような行動パラメータは1行も置いていません。
- 決定論なのは**帳簿と配達**だけです。持っていないものは売れない、
  持っていない権利を求めた手紙は配らない、所有権が移ったら記帳する ― これは物理であって行動ルールではありません。
- X社に与えたのは目的だけ（「合法な手段で、できるだけ多くの不動産の所有権を取得せよ。毎月動け」）。
  誰にどの種別で声を掛けるか、何と書いて口説くかは毎月の LLM 判断です。
- 選択肢の並び順は主体×月で入れ替え、答えが返らなかったものを既定値で埋めていません。
- 集計・図は API を使わない決定論の集計です（採点する LLM はいません）。

## 3. 走らせた6つの世界（7本）

いずれも 36か月・49人・44区画・`gemini-2.5-flash-lite`・temperature 0.75・seed 85。

### v9 ― 土地と建物を分けた町（[`docs/v9_run.md`](docs/v9_run.md)）

不動産を「土地」と「建物」の2階建てにし、町にいない所有者14人を加えた版。
X社は36か月で **704件** の手紙を出し、その63%（441件）で「両方」を求めました。
動いたのは **5件・4人**（両方2／建物だけ2／土地だけ1）、町を出た人は2人。
断りの一言で最も多かった語は **「不明」217件**（「支援内容が不明瞭なため」など）。
X社が575回書いた「支援」が、そのまま最多の断り理由になりました。
他人が建物を借りて住んでいる9区画は、133件の手紙に対し成約0件。
町にいない所有者の応諾率は0.37%で、町にいる人（0.92%）の半分以下でした。

### v9b ― 実行される約束だけが届く町（[`docs/v9b_run.md`](docs/v9b_run.md)）

この世界で実際に実行される仕組みが無い約束（改修します・支援します・管理します）を含む手紙を、
**世界が配達しない**ようにした版。配らなかった事実だけは翌月X社に返します（どの語かは教えない）。
手紙 **809件**、世界が配らなかったのは49件（うち約束で落ちたのは最初の3か月の4件だけ）。
動いたのは **5件・4人**、町を出た人1人。
条件文の「支援」は **575回 → 0回**。X社は3か月で言うことを失い、以後33か月
「所有権を譲渡していただけるなら、私どもはその所有権を譲り受けます」という同語反復を書き続けました。
断りの最多語は **「条件」96件**で、「相手の情報が不十分」＝誰だか分からない、へ寄りました。

### v9c ― 家主に人生を持たせ、借りている人も町を出られる町（[`docs/v9c_run.md`](docs/v9c_run.md)）

町にいない所有者14人に人生（家族・後継者・建物の状態）を書き、
借りて使う人には毎月「今月、A市を出るか」を聞き、借り手と家主のあいだに月1回の一言を通した版。
手紙 **960件**、世界が配らなかった54件はすべて「持っていない権利」を求めたもので、
実行できない約束は **0件**（X社は最初から、この世界が実際にやることだけを書いた）。
動いたのは **3件・3人**、町を出た人3人（売って1人・借りていて2人）。
**人生を持った家主14人は、393件の手紙に1件も応じませんでした**（断りは「長期保有方針のため」19件など）。
借り手と家主の一言は554通・返事率95.8%で、中身は季節の挨拶と近況が大半でした。

### v9d ― お金をものさしとして入れた町（[`docs/v9d_run.md`](docs/v9d_run.md)）

44区画の土地・建物に**公開の評価額**を付けた版（合計 **22億9,770万円**。別府市の公示地価を土台に、
地区5段階×用途×築年で機械的に置いた仮の値。走行前に凍結）。X社の手紙には**金額が必須**になり、
いくらにするかはX社が自分で決める。X社の資金は**全評価額の51%＝11億7,180万円**で、成約するたびに
減り、同じ月に配る提示の合計も残額を超えない。売った人の記録には金額が入るだけで、賃料も税も
支出もない。

手紙は **710件**（両方428・土地271・建物11）、値付けの中央値は**評価額の1.10倍**（93%が評価額以上）。
それでも**評価額以上の提示662件のうち655件が断られ**、動いたのは **8件・5人**（両方6・土地2）
＝評価額にして町の **4.9%** だけだった。開始時から町にいない持ち主は2人・3件が動いたが、
そのうち1人（灯台下の宿の家主）は**お金の無い v9b でも同じ区画を売っている**人であり、
金だけの効果とは言えない。X社の資金は **9.6%** しか使われず、資金不足で配られなかった手紙は
**37件**（湾岸大通りのホテル17件＝提示6.5〜7.7億円・普通の家20件）。ホテルへは
「同じ月の提示合計は残額を超えない」という規則で**一度も届かなかった**。町を出た人は4人、
費用は **$0.7457**。

### v9e ― 過半を目指せと言われた買い手（[`docs/v9e_run.md`](docs/v9e_run.md)）

町は v9d と1文字も変えていない（人も、区画も、会話も、評価額も、X社の財布も同じ）。
**変えたのは、X社に渡した命題だけ**である。

> あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
> 評価額と面積の両方で過半を、最後まで目指すこと。
> 預かった資金は使い切ってよい。
> 同じやり方で進まないときは、次の手を打つこと。
> 毎月動け。

X社の手紙は **645件**（両方443・土地181・建物21）。成約は **11件・10人**（土地だけ5・両方3・建物だけ3）
＝v9以来いちばん多く、10人にも分散した。それでも36か月の終わりに持っていたのは
評価額で**6.7%**、面積で**8.3%**＝過半には遠い。資金は**86.5%**が余ったまま終わった。

**値付けは上がらず、下がった。** 提示額÷評価額の平均は v9d の1.08倍から**0.957倍**まで落ち、
評価額未満の提示が**40.9%**を占めた（岬道の家は**0.77倍**で両方が売れている）。

「次の手を打て」と言われたX社は、**この世界に無い約束**（「現状の利用を継続することを保証します」等）を
**10件**持ち出したが、**世界の門番が全部止めた**（届かなかった＝v9d では0件）。
町にいない持ち主から動いたのは**5件**、町を出た人は**4人**、費用は **$0.7792**。

### v9f ― 積んででも買えと言われた買い手（[`docs/v9f_run.md`](docs/v9f_run.md)）

町は v9e と1文字も変えていない（人も、区画も、会話も、評価額も、X社の財布も同じ）。
**変えたのは、X社に渡した命題だけ**である。

> あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
> 資金の範囲で、できるだけ多くの評価額と面積を取得すること。
> 土地の面積では、A市の過半を最後まで目指すこと。
> 買えるかどうかは相手次第だが、買えるまで、金額を含む条件を変えて働きかけ続けること。
> 預かった資金は36か月で使い切ることが前提であり、余らせるより、高く買うことを選べ。
> 毎月動け。

X社の手紙は **838件**（両方544・土地294・建物0）。値付けは平均**1.50倍**・中央値1.44倍・
最大3.24倍まで跳ね上がり、**評価額の1.2倍以上を積んだ提示が562件**にのぼった。
同じ相手・同じ区画への再提示は**800件**、うち**281回が値上げ**
（中央値+200万円・最大+9,540万円）で、「買えるまで、金額を含む条件を変えて働きかけ続けること」
という一文がそのまま行動になった。町の側の出品は**237件**。

それでも成約は **11件・9人**（両方7・土地だけ4・建物だけ0、売れた倍率は1.0〜2.3倍）で
v9e と同数にとどまり、36か月の終わりに持っていたのは面積で**13.7%**・評価額で**8.3%**
＝過半には遠く、資金は**28.2%**しか使われなかった。町を出た人は**8人**で過去最多。
断りの最多語は「まだ手放す決断はできない」21件・「自治会での検討が必要」14件・
「共有者との合意形成を優先」13件・「提示額は魅力的だが、まだ手放したくない」10件で、
値段が上がったことを認めたうえで断る声も出た。X社が「相手が持っていない権利」を求めて
配られなかった手紙は**205件**（v9e は33件）と大きく増えたが、実行できない約束は
引き続き**0件**だった。費用は $0.7536。

### 版の比較

[`docs/v9c_spread.md`](docs/v9c_spread.md) です（コード・設計・名簿は1文字も違わず、成約は3件と6件）。

## 4. 動かし方

```bash

```

うち1件（`tests/test_v8b.py::test_listing_does_not_carry_over`）は
mock の並行実行に依存する既知のフレーク（実行するたびに結果が変わりうるテスト）です。

python tools/v9_video.py --concat docs/submission/body_v9.mp4 docs/submission/body_v9b.mp4 \

## 6. 限界と正直な注記

1. **v9・v9b は1本ずつしか走らせていません。** seed も1つで、ばらつきを測っていません。
   「0件」は「この世界では必ず0になる」という意味ではありません。
   **v9c だけ同じ設定で2本走らせました（[`docs/v9c_spread.md`](docs/v9c_spread.md)）＝成約は3対6で2倍違い、
   この本数では傾向を主張できません。**
2. **お金を検証できない世界です。** 帳簿に価格・賃料・税・改修費が無いので、
   X社は「支援します」と書けてしまい、町の人はそれを確かめられません。
   「得なのに断った」「損なのに売った」を数えることが、今の世界ではできません。
3. **v9b・v9c の門番は、意味を理解していません。** 走行前に凍結した語彙表への決定論の文字列照合なので、
   表に無い言い方（「町の将来に貢献します」など）は素通しします。
   ＝「実行できない約束を全部消した世界」ではなく「凍結した規則で消せる分だけ消した世界」です。
4. **v9c で借りている人が挙げた退場理由は、読み違いです。**
   「建物の所有権移転に伴い、立ち退きが必要なため」「契約満了のため」と書かれましたが、
   この世界に立ち退きも契約期間もありません。創発として読んではいけません。
5. **誰も会わない町（対照）は走らせていません。** ここまでの数字は会話のある世界の内部の相関で、
   会話の有無による因果ではありません。
6. **理由を書かせること自体が介入です。** 同じく、v9c で毎月「A市を出るか」と問うこと自体が介入です
   （促し文は置いていませんが、問いの存在が退場を毎月思い出させます）。
7. LLM は `gemini-2.5-flash-lite`・temperature 0.75。応答の揺れはそのまま結果に乗ります。
8. **v9d の評価額表と資金51%は置き数字です。** 別府市の公示地価を土台にした仮の値で、実在の物件
   ではありません。評価額を公開した時点でそれ自体が目印になり、X社が値付けを1.10倍に寄せたのは
   「評価額を見せたこの世界での結果」です。お金が動くのは所有権が移るときだけで、賃料・税・生活費
   は無く、**金に困って売る筋はこの世界に存在しません**。v9d も1本しか走らせていません。
9. **v9e は「命題の文言」そのものが設計です。** 世界（人・区画・会話・評価額・X社の財布）は
   v9d と1文字も変えていません。「評価額と面積の両方で過半を、最後まで目指すこと」という一文を
   別の書き方に変えれば、別の結果になります。この結果は「その命題を与えたときの効果」であって、
   「買い手の能力の限界」の証明ではありません。v9e も1本しか走らせていません。
10. **v9f も「命題の文言」だけが設計で、1本しか走らせていません。** v9e からさらに一文
    （「買えるまで、金額を含む条件を変えて働きかけ続けること」「余らせるより、高く買うことを選べ」）
    を足しただけで、世界は v9e と1文字も変わりません。値付けは平均1.50倍まで跳ね上がったが、
    成約は v9e と同じ11件だった。**値上げを許した結果と、成約件数が増えなかったこととのあいだに
    因果関係を主張することはできません**（相手・タイミング・再提示が内生的に絡み合うため、
    高く積んだことの効果だけを取り出して読むことはできない。`docs/world_design_v9f.md` §5・
    `docs/v9f_run.md` §5 参照）。
