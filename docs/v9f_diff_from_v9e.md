- v9f の結果＝`docs/v9f_run.md`（走行 `simulations/2026-08-30_1711_132_field_v9f_pay_more_if_needed_chat/`）
- v9f の設計＝`docs/world_design_v9f.md`（走行前に凍結）

**v1〜v9e のファイルは1バイトも触っていない。** 世界（町の人・名簿・44区画・格子・会話・
出品・門番3種・評価額の表・資金51%・月内の提示合計の規則・X社の設定文・
面積／取得割合／残り月数の事実行）は **v9e と1文字も違わない**。

## 1. 命題の差

|項目|v9e|v9f|
|---|---|---|
|目標|評価額と面積の**両方で過半**を最後まで目指す|資金の範囲で**できるだけ多くの評価額と面積**／**土地の面積では過半**を最後まで目指す|
|資金|「使い切ってよい」|「**36か月で使い切ることが前提**」|
|価格|（何も書かない）|**「余らせるより、高く買うことを選べ」**|
|粘り|「同じやり方で進まないときは、次の手を打つこと」|**「買えるまで、金額を含む条件を変えて働きかけ続けること」**|

**評価額の過半を外した理由**＝資金が全評価額の51%（11億7,180万円）しかなく、
評価額の過半には11億4,885万円が要る。つまり**平均1.0200倍を超えて買うと原理的に不可能**で、
「高く買え」と同時には成立しない（施主が17:02の初案を撤回・`docs/world_design_v9f.md` §5）。
**面積の過半**は最も安い組み合わせなら3億3,600万円（資金の28.7%）で理論上可能なので残した。

## 3. 命題を強めて何が変わったか

### 3-1. 値付けが **0.96倍 → 1.50倍**に反転した

v9e（過半を目指せ・価格の指示なし）では**安く数を買う**方に振れ（平均0.96倍）、
v9f（余らせるより高く買え）では**平均1.50倍・中央値1.44倍**まで上がった。
1.2倍以上の「積んだ」提示が**838件中562件（67%）**を占める。
月を追うごとに上がり続け、最後の4か月は1.5〜1.75倍だった。

### 3-2. 粘りが数字に出た（再提示800件・値上げ281回）

v9e には無かった観測である。同じ相手・同じ区画・同じ種別に何度も出し直し、
**281回は金額を上げた**（中央値+200万円・最大+9,540万円）。
ただし**値上げの直後に売れたのは3件**にとどまる。

### 3-3. 面積は 8.3% → **13.7%**、資金消化は 13.5% → **28.2%**

目標（面積の過半）に近づきはしたが、**過半には遠い**。
資金は**71.8%が余った**まま36か月が終わった。

### 3-4. **町を出た人が2倍（4人 → 8人）**

v9f の成約は**11件中7件が「両方」**（v9e は3件）。両方を売って自分が使っていた人は
その場を離れて町を出るので、**高い金額は「人が出ていく速さ」として現れた**。
借りていた人の退場も1人→2人になった。

### 3-5. 断り方も変わった

```
v9e：まだ時期尚早23／先祖代々の土地なので23／父の介護を優先するため16
v9f：まだ手放す決断はできない21／自治会での検討が必要なため14／
     共有者との合意形成を優先するため13／**提示額は魅力的だが、まだ手放したくない10**
```

v9f では**「値段は認めるが手放さない」**という形の断りがはっきり出た。
「損なのに売った」（評価額未満で売る）は **0件**である。

### 3-6. 副作用：帳簿の読み違いが6倍に（33件 → 205件）

粘って手を伸ばすほど、**相手が持っていない権利**を求める提示が増え、世界が弾いた。
一方で「実行できない約束」は 10件 → **0件**（v9e の第1月に出た約束型は再発しなかった）。

## 4. 解釈しないこと

1本対1本の差である。成約11件・退場8人・借地1件はいずれも1桁で、揺れと区別できない
（v9c は同設定2本で成約が3件と6件に割れた）。
桁で言えるのは **3-1（値付けが0.96→1.50に反転）**、**3-2（再提示800件・値上げ281回）**、
**3-3（資金消化13.5%→28.2%・面積8.3%→13.7%）**、**3-4（退場4人→8人）**、
**3-6（権利の読み違い33→205件）** の5つである。
なお「積んだ提示の成約率1.25%」は相手・物件の選び方と再提示が内生的に絡むため、
**高く積んだことの因果効果としては読めない**（走行前レビューの指摘）。
