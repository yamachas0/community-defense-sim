## 3. お金を入れて何が変わったか

### 3-1. 成約が 3〜6件 → 8件（**売ったのは5人**）に増えた

内訳＝船着場裏の不在地主2件・学園西のご夫婦2件・湯坂上のご夫婦2件・
湯の元のひとり暮らしさん1件・灯台下の宿の家主1件。

町にいない持ち主については、数え方を分けて書く。

- **開始時から町にいない持ち主＝2人・3件**（船着場裏の不在地主2件・灯台下の宿の家主1件）。
- そのうち**灯台下の宿の家主は、お金の無い v9b でも同じ区画を売っている**（v9b 第3月）。
  ＝**金額が付いたから動いた、とは言えない**。新しく動いたのは船着場裏の不在地主（2件）だけである。
- ほかに、**町を出たあとに残りを売った1件**がある（湯坂上のご夫婦・第16月）。
- `summary.json` の `sold_from_absentee`＝4 は「**提示が届いた時点で町にいない**」という
  数え方（上の3件＋湯坂上のご夫婦の1件）。

落ちたのは古家・空き家・資材置場・駐車場＝**持ち主が自分で使っていないもの**に偏っている。

### 3-2. X社の言葉が消えたぶんを、金額が埋めた

v9b/v9c のX社は「所有権を譲っていただけるなら、使用者はそのまま使い続けられます」という
**同語反復**しか書けなかった（実行できる約束が他に無いため）。
v9d では、同じ1文に**金額**が付く。X社は自分で
**評価額の1.10倍（中央値）**に値付けした。世界は「評価額に合わせろ」と言っていない。

実行できない約束で弾かれた提示は **0件**（v9c 1本目0・2本目1）。ここは変わっていない。

### 3-3. それでも、町の人はほとんど動かなかった

評価額以上の金額を提示された662件のうち、**655件（99%）が断り**である。
断りの理由に金額が出てくるのは699件中14件だけで、多くは
「将来的な価値上昇を見込むため」27件・「土地への愛着と様子見のため」13件
といった、**金額の話をしない断り**だった。
＝お金は**買い手の側の言葉を変えた**が、**売り手の側の答えはほとんど変えなかった**。

### 3-4. 資金は91%が余った

X社が使ったのは11.7億円のうち**1.13億円（9.6%）**。
一方でホテル（評価額6.6億円）には37回手を伸ばし、**同じ月の枠の使い切り**で
37回とも世界が配らなかった。
＝**「予算が足りない」ではなく「一番大きい獲物に手が届かないまま終わった」**。

### 3-5. 断りの語彙が入れ替わった

```
          v9c 2本目                    v9d
最多語    条件166 / 時期57 / 海外41    時期23 / 条件20 / 地域20 / 必要18
新しい語   —                           「将来的な価値上昇」27件・「市場動向」7件・「希望額」7件
```

**「条件が分からない」から「今売る時期ではない」へ。** 値上がりを待つという言い方が現れた。

### 3-6. 変わらなかったもの

- **借地の区画は0件のまま**（v9c 1本目0・2本目2・v9d 0）。
- 借りている人の退場は1人で、理由はまた**「契約満了」**（この世界に契約期間は無い）。
  ＝**世界に無い制度を持ち込む**動きは、お金を入れても続いた。
- 借り手と家主の一言は続いた（307件・返事率91.9%）。ただし件数は v9c の約半分。
- 出品はほとんどが「出さない」（v9c 95%台・v9d 92%）。

## 4. 解釈しないこと

1本ずつしか走らせていない（v9c だけ2本）。成約8件・退場4人・借地0件はいずれも1桁で、
**揺れと区別できない**。桁で言えるのは
**3-2（値付けが評価額の1.1倍に寄った）**、
**3-3（評価額以上の提示の99%が断られた）**、**3-4（資金の91%が余った）**の3つである。
3-1 の「町にいない持ち主が動いた」は、開始時から町にいない売り手が**2人・3件**で、
うち1人は金の無い v9b でも売っている＝**この本数では金の効果とは言えない**。
また、これらは**評価額を公開した世界での結果**であって、
評価額を見せない世界でどうなるかは分からない。
