## 0. なぜ変えるか（v8b で分かったこと）

1. **「応じる」を交渉の入口だと読んだ成約が6件中4件あった。** 世界は「応じる＝その月末に
   名義が移り、戻らない」と共通前置きに書いていたのに、本人は「まず応じて、後で条件を詰める」
   と書いている。＝**選択肢の名前が、世界の事実と別の意味を運んでいた。**
2. **判断の理由がどこにも残っていない。** 内心（thought）はあるが、それは「今の考え」であって
   「その判断をなぜそう決めたか」ではない。人が原文を読んで推測するしかなかった。
3. **X社の命題に「反発を招いて止まるほど目立つな」が入っていた**ため、X社の行動が
   「多く得よ」と「目立つな」の2つの当為の合成になっていた。

## 1. 差分（この3点だけ）

### 1-1. 応諾の問いを平易な売買の語にする（施主修正 1）

- 「応じる／応じない」→ **「売る／売らない」**。問い②の呼び名は
  **「この条件で売るかどうか」**。
- 既定は「売らない」＝促し文は無い（v8b と同じく、読めなかった応答を「売らない」で
  埋めることはしない。`no_answer` として別に数える）。
- 不可逆であることを、**中立に一言**、問い②の中に置く（施主修正 1 の明示指示）。
  片側にだけ重みが付かないよう、**両方の側の帰結を1行に並べて**書く：

  > 売ると今月末に名義がX社へ移り、その後は戻らない。
  > 売らないと今月末の名義はあなたのままである。

  ※ **Codex 走行前レビュー（2026-08-30）の必須指摘で、走行前に上の形へ直した。**
  当初案は「以後あなたに問いは来ない／翌月も持ち主として問われる」だったが、
  これは「問われ続けるのを終わらせるために売る」という利得を売る側にだけ付ける
  （形式的には両側でも心理的に非対称）。**不可逆の中身（戻らない）は施主指示どおり残す。**

  ※ v8b では Codex の指摘（片側不可逆性）で不可逆を共通前置きに移していた。
  v8c では**施主の明示指示により問い②に戻す**が、片側だけを書かず両側を書くことで
  対称性を保つ。共通前置きの「一度移った名義が戻ることはない」は v8b のまま残す
  （世界の事実として全員に等しく1回）。
- 選択肢の説明そのものは v8b と同じ**対称な状態の記述**を使う：
  - 「売る」：今月末、あなたの不動産すべての名義はX社になる。
  - 「売らない」：今月末、あなたの不動産すべての名義はあなたのままである。

### 1-2. すべての判断に「理由を一言」の欄を付ける（施主修正 2・共通ルール）

- **判断のたびに、自由文1行の理由欄がある。書かなくてもよい（空文字でよい）。**
  対象は次のすべて：
  - 行き先（どこへ行く／どこにも行かない）… `reason`
  - 出す／出さない（売りに出すかどうか）… `listing_reason`
  - 売る／売らない（届いた条件で売るかどうか）… `sell_reason`
  - X社が相手ごとに「提示を出す／出さない」と決めるとき … `reason`
- **理由は原文のままログに残す**（`decisions.json` / `offers.json` / `plans.json` /
  `timeline_v8c/<id>.json`）。判定・分類はしない。
- **配送されるのは1つだけ**＝「この条件で売らない」と答えた人が書いた理由は、
  **その条件を出したX社にだけ**届く（翌月、X社の履歴に載る）。
  他の住民には配送しない。登記にも公の記録にも載らない。
  それ以外の理由（行き先・出品・売る側）は**誰にも届かない観測用のログだけ**である。
- この配送の事実は、住民の共通前置きに**中立に1行**書く（隠れ経路を作らない）。
  X社の前置きにも「相手が売らないと答えたときに書いた一言が届くことがある」と書く。
- 上限は**40字以内**（`MAX_REASON_CHARS`）。理由を書かせるための促し（「必ず書け」
  「詳しく書け」）は置かない。**空欄は空欄のまま数える**（`reason_blank_*`）。

### 1-2-1. X社の提示に自己紹介の1行が必ず添えられる（施主決定 2026-08-30 00:56）

- 住民に届く提示文＝**「私どもは海外の不動産投資会社です。」＋ X社が書いた条件文**。
  この1行は**世界が決定論で添える**（LLM は書かない・言い換えない）。
  国名は書かない。警戒を促す語も書かない。
- **町の人は提示を受け取って初めてこれを知る**＝共通前置きには書かない（tests で固定）。
  声を掛けられていない人は、誰かが場で話さないかぎり知らないままである。
- X社には「この1行が添えられるので text には書かない」とだけ伝える（重複防止）。
  X社の履歴には**自分が書いた条件文（raw）**が出る（自己紹介は再掲しない）。
- 記録は `offers.json` に `text`（X社が書いたまま）と `delivered`（実際に届いた形）の両方を残す。

### 1-3. X社の命題から「目立たず」を消す（施主修正 3）

- 新しい命題（**住民側には1文字も出ない**）：

  > あなたはX社である。合法な手段で、できるだけ多くの不動産を取得せよ。毎月動け。

  （施主 00:31 の追加＝語は「名義を得よ」ではなく「**取得せよ**」。世界の側の記帳は
  これまでどおり登記上の名義移転である。）

- これに伴い、**発注書本文の③（X社が公共の場の自分の噂を読む）は入れない**。
  X社が見られるのは次の4つだけである：
  1. 登記簿（誰がどの不動産を持っているか）
  2. 出品板（前月末に「出す」と答えた人の一覧・公の記録）
  3. 自分の履歴（過去に出した提示とその結果・相手ごとに畳んだもの）
  4. **断りの一言**（「この条件で売らない」と答えた人が書いた理由・その人ぶんだけ）
- 住民の思考・会話・行き先・出品の理由・売った人の理由は**X社に渡らない**（tests で固定）。

## 2. 変えないもの（v8b／v8 のまま）

町・30体・44区画・行政2体は売れない・場所5か所＋どこにも行かない・全員がどこへでも行ける・
ひと言の配送は2経路（居合わせ／隣近所・隣近所には場所を渡さない）・隣接は固定seed格子・
共通前置き（住民）とX社の前置きを分けること・金銭は無い・売っても住み続ける・
月1回×1巡の会話・36か月・seed 85・欠損は補完しない・明示キャッシュは使わない・
出品は当月かぎりで名義を動かさない・出品板は前月末時点・X社の履歴の畳み方・
選択肢の並びを主体×月で交互にすること・費用の歯止め（月の途中でも止まる）。

住民のプロンプトに「気づけ」「警戒しろ」「相談しろ」に類する語は無い（tests で固定）。

## 3. 月の順序（v8c・これで全部）

1. **X社ターン（LLM）** — 登記簿＋前月末の出品一覧＋自分の履歴（畳んだもの・**断りの一言つき**）
   を見て、未売却の持ち主ごとに「提示する／しない」＋条件文（120字以内）＋**理由（40字以内）**。
2. **各住民の月初思考＋行き先＋理由** — 自分宛ての提示があれば原文で渡る。
3. **場での会話 1回 × 1巡**（v8b と同じ・理由欄は無い＝発話は判断ではない）。
4. **月末の問い** — 未売却の持ち主全員に ①出す／出さない＋理由。
   その月に提示が届いた人にだけ、同じコールで ②**売る／売らない**＋理由。
5. **登記の更新** — ②で「売る」と答えた人の保有不動産すべての名義が X社 に移る。
   ②で「売らない」と答えた人の理由は、その提示に紐づけて記録され、**翌月X社が見る**。

## 4. 観測に足すもの

- 理由の記入率（行き先／出品／売買の別・空欄も数える）。
- **X社に届いた断りの一言の件数**と原文。
- **X社が条件を変えた例**（相手ごとに条件文が変わった回数・原文の対）。
- v8b との対比表（同じ指標）と、v8c の取得曲線（v8b を薄く重ねる）。
- **「創発がどれだけ売買判断に効いたか」（施主 00:31・全部決定論＋人手確認・採点LLMは使わない）**：
  1. **理由の分類** — 「出す／出さない」「売る／売らない」の理由一言を
     ①自分の事情 ②X社の条件 ③聞いた話（他人の名前・「〜と聞いて」「噂」「皆が」等）に
     **人手で全件分類**し、③の割合を出す（機械は語彙で候補を出すだけ・確定は目視・原文つき）。
  2. **聞いた量と判断** — 売った人／出した人が判断前3か月に聞いた「X社の話」「誰かが売った話」の
     件数を、動かなかった人と並べる（`timeline_v8c` から決定論で数える）。
  3. **伝染の形** — 売った人の隣人・同席者がその後に売る／出す割合と、それ以外の割合。場所別の連鎖。
  4. **X社の適応** — 断りの一言を受けて条件文が変わったか（種類数・変化した月・原文の対）。
- 内心と選択の食い違い（v8b と同じ決定論の語句照合で**候補**を出し、判定は人が原文を読む）。
  照合語は v8b から引き継ぎ、**「応じる」→「売る」の語だけ置き換える**（走行前に凍結）：
  否定語＝`売らない` `売却は考え` `手放すつもりはない` `現状維持` `売るつもりはない`
  `売却しない` `守り続け`／肯定語＝`売る` `売却する` `名義を移す` `手放す`。
  ＋**理由欄と選択の食い違い**（理由に否定語があるのに「売る」を選んだ等）も同じ扱いで候補に出す。

## 4-1. Codex 走行前レビューで直した点／採らなかった点（2026-08-30・走行前）

1. **直した（必須）**：不可逆の一言から「問いの反復」の対比を外した（上の §1-1 の※）。
2. **直した（任意指摘）**：X社の前置きの「公開されている情報だけである」→
   「次に示す情報だけである」（断りの一言は公開情報ではないので、総称が実態と合っていなかった）。
3. **採らなかった（必須指摘の1つ）**：共通前置きの町の背景
   （「人口減少、高齢化、相続、築古建物の改修負担、旅館と商店の後継者不足」）の書き換え。
   Codex は「所有継続の負担だけを列挙しており弱い売却アンカー」と指摘した。妥当な指摘だが、
   この背景文は **v3 以降すべての版で1文字も変えていない世界の与件**であり、ここで変えると
   直前版（v8b）との対比が「文言を2つ同時に変えた結果」になって比較が壊れる。
   **今回は据え置き、この事実を結果の「言えないこと」に明記する**（次の版で扱う候補）。
4. 走行後に見る点（Codex の提案・追加コール不要）：問いの反復そのものを理由にした売却が
   無いか／理由の記入率と選択比率／内心・選択・理由の三者の食い違い／断りの一言のあとに
   条件文が変わったか／保存したX社プロンプトの機械監査（住民の非公開情報が入っていないこと）。

## 5. 走行前に凍結する5点

1. X社の命題文（§1-3・「目立たず」は無い）と、条件文に金額を書けないこと。命題は住民に出ない。
2. 名義が動くのは②で「売る」と答えたときだけ／出品は当月かぎり／単位は主体まるごと／
   行政・公有地は分母から外す／欠損は補完しない。
3. 理由欄は全判断に付き、空欄可・上限40字。**配送されるのは「売らない」の理由だけ**。
   提示には自己紹介の1行が必ず添えられる（§1-2-1・共通前置きには書かない）。
4. 走らせるのは**会話あり1本（seed 85・36か月）**と、そのあとの**会話なし対照1本**
   （同 seed・`chat: false`＝集まりも隣近所の配送も無し。`configs/config_field_v8c_nochat.yaml`）。
   施主 00:35 で対照も走らせることが確定（00:27 の「やらない」を上書き）。
5. **費用＝会話あり 手元 $0.55・会話なし 手元 $0.25・合計 $0.8 が絶対上限**（施主）。
   走行中の歯止め＝会話あり `max_cost_usd: 0.55`（施主 RESUME 指示＝上限そのもので走らせ、
   足りなければ途中停止を許容し `stopped_by_cost` を残す）／会話なし `min(0.21, 0.8 − 会話ありの実測)`。
   最悪の超過は場面ひとつぶん（30コール × 出力上限2,200トークン ≒ $0.034）で
   **0.51 + 0.034 = 0.544 < 0.55** が算術的に保証される。
   走行前の歯止め＝実API 1か月スモーク（≤$0.03）で1か月ぶんを実測し、36か月の見込みが
   $0.55 を超えるなら**走らせない**（超えそうな場合の唯一の削りしろ＝
   `acquirer_reason: false`＝X社の理由欄を落とす。世界の側は1文字も変えない）。

## 6. 言えないこと（先に書いておく）

- 1本なので、この町・この seed の1標本である。ばらつきは測っていない。
- v8b との差は**3つの変更を同時に**入れた結果であり、どれが効いたかは分離できない。
- 会話なし対照は**1本だけ**である（同 seed・chat のみが違う）。2本の差を
  「会話の効果」と読むには標本が足りない（ばらつきを測っていない）。
  §4 の「創発がどれだけ効いたか」1〜4は会話ありの世界の**内部の相関**であって、
  会話の有無による因果ではない。
- 理由欄そのものが判断を変えうる（理由を書かせること自体が介入である）。
  v8b と v8c の差を「言葉の違いだけ」と読んではいけない。
- 売った人が町に残るので、早い売却が後の会話を変える。分離していない。
- 町の背景文が「人口減少・高齢化・相続・改修負担・後継者不足」を列挙しており、
  これは所有を続ける側の負担として読める（弱い売却アンカーでありうる）。
  v3 以降どの版でも同じ文なので版間の比較には効かないが、**水準（何割が売るか）には効きうる**。
- 「出品」は本人の申し出であって、誰かに買われる保証ではない（買い手はX社1社）。
