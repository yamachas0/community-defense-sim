# 人手確認 — 2つの世界の「気づいた月」と「行動した月」（v6・2026-08-29）

採点用の LLM は使っていない（v6 で全廃）。ここに書いてあるのは**決定論の候補**と、
それを**人が読んで下した判定**だけである。判定の基準は走行前の設計
（`docs/world_design_v6_two_worlds.md` §5）に書いたとおり。

## 判定の手順（両世界とも同じ）

1. **候補の網（緩い）**＝公の場の行（発話・記事）で `_v5c_rule_yellow` に当たるもの
   ＝名義が2つ以上出てくる、または名義1つ＋「同じ会社／裏で／別の名前」等の語。
2. **採用の基準（人手）**＝「2つ以上の名義を**1つの買い手・1つの動きとして結びつけている**」か、
   「買い集め／同一／裏で」等で**1者性を言っている**こと。
   単に2つの名前が同じ文に出てくるだけ（別々の相手として扱っている）は**採らない**。
3. 上の基準を機械にした補助フィルタ（`tools/two_worlds.py` の `_linked`）で候補を並べ、
   **月の早い順に人が読んで**、最初に基準を満たした行を採る。採った行の原文をここに載せる。

**緩い網の初出は当てにならない**（実際に読むと、別々の相手として話しているだけの行が
たくさん混ざっていた）。だから採用値は必ず原文つきで出す。

### 行動の中身（人が読んで確かめたこと）

- **「当面売らない」は月に1〜2件のペースで、ずっと出続けた**（A 51件・B 54件・C 55件／
  のべ人数 13・16・14／36か月）。**一斉蜂起ではない**。
- **理由は普通の暮らしの話だった。** 第1月に選んだ人の内心（runB）＝
  「父の世話や自宅の老朽化を考えると…この機会に土地の活用について真剣に考えるべきかもしれない。
  **しかし、すぐに手放すという決断はできない**」。買い手への警戒ではない。
- **解除もある**（A 3件・B 3件・C 0件）＝一度決めたら固定ではない。
- 紙の中身も普通だった。最初の数枚（runB）＝役場「相続・空き家活用に関する住民相談窓口を
  設置します」（第1月）、回覧板「駅裏の事業所…の利用状況について、近隣の方々からの
  情報提供やご意見を伺いたい」（第4月）、町内会の議題「桜台の古家、湾岸大通りの空き地活用に
  関する市役所の支援策について」（第4月）。**「同じ買い手」を告発する紙ではない。**
- **行動は「気づき」より先に出ている**（3本とも第1月に最初の「当面売らない」。
  気づいた月は A なし・B 第3月・C 第12月）。したがって
  **「気づいたから行動した」とは言えない。**

### 「条例・届出の検討を始める」は3本とも0件

役場が選んだのは相談窓口（第1〜3月）と説明会（第6〜20月）まで。
**制度をいじる方の措置には、3本とも一度も手が伸びなかった。**
