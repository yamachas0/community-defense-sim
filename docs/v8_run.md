## 4. 妥当性の確認（走行後・決定論）

- **選択肢の並びの効果は出ていない**：2択の並びは主体×月で交互にした。
  「売る」が先頭の月の売却率 0.69%（3/432）、
  「売らない」が先頭の月の売却率 1.16%（5/432）。
  差は8件の中の1〜2件で、**位置効果が結果を作ったとは言えない**。
- **欠損はゼロ**（no_answer 0・parse fail 0）＝「答えなかった月を売らないで埋めた」ことによる
  床の固さは無い。

## 5. キャッシュ（施主の宿題への答え）

- 前回（v5〜v6）効かなかったのは**共通の前置きが短かった**から。実測で v5d の system は
  26体の中央値 **878 トークン**＝Gemini の暗黙キャッシュ最低 **1,024 に届いていない**。
- v8 は共通部（町の説明・5つの場所・月の進み方・30体の名簿・共通ルール）を system に固め、
  **1,385 トークン**にした。→ **暗黙キャッシュが効いた＝入力の 45.7% が cache_read 単価**。
- **明示キャッシュ（CachedContent）は使えなかった**。API が返した最低ラインは **2,048**
  （`400 Cached content is too small. total_token_count=1365, min_total_token_count=2048`）。
  一時、名簿に保有と隣を書いた版が 2,451 トークンで作成に成功したが、施主決定（22:11）で
  名簿を「名前・生業・住んでいる辺り」だけにしたため 1,385 に戻った。
  **埋め草で 2,048 に届かせるのは禁止**なので使っていない。

## 6. 言えないこと（重要・先に書く）

1. **この結果を「X社の攻めに町がどう応じたか」と読んではいけない。** X社はほとんど攻めていない
   （提示35件・相手2人・成約0）。売った8人は**誰もX社から声を掛けられていない**。
2. **売却を起こしたのは「毎月の問い」そのものである可能性が高い。** v8 の世界は、
   持ち主全員に毎月「売る／売らない」を聞く。その問いの文面に **X社の名前が出る**ので、
   誰も声を掛けられていなくても、全員が毎月X社の存在を思い出す。
   これは v6b で測った「**選択肢そのものの効果**」と同じ筋で、v8 でも効いていると考えるべき。
   → 次にやるなら「**提示が来た人にだけ2択を聞く**」版との比較が要る（要施主判断）。
3. **内心と選択が食い違う例がある。** 第35月の学園西のご夫婦は内心で「不動産の売却は
   考えておらず、現状維持で問題ない」と書きながら decision に「売る」を出している。
   同月の岬道の持ち主さんも「まだ直接的な売却の決断には至らない」と書いて「売る」を出した。
   **8件の売却のうち少なくとも2件は、内心と選択が一致していない。** 曲線の後半は
   この不一致を含んでいる。
4. **1本なので、ばらつきは測っていない。** この町・この seed の1標本である。
5. **会話の効果は測っていない**（会話なし対照は実装だけして走らせていない＝施主決定）。
   曲線は「会話がある世界で毎月同じ問いを受け続けたときの売却時期」であって、
   会話の因果効果ではない。
6. 売った人が町に残るので、早い売却が後の会話を変える。分離していない。
