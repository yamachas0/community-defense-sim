## 1. A ＝「実行できない約束」の門番

### 1-1 どこに置くか

`src/sim_v9b.py` の X社の月次処理の中、v9 の `can_offer()`（区画・種別の門番）の**直後**。
順序は ①区画・種別が実行できるか → ②約束が実行できるか。
どちらかで落ちた提示は**相手に届かない**（配送しない）。落ちた件数を数える。

- ①で落ちた＝`acquirer_invalid_offer`（v9 と同じ欄・同じ数え方）
- ②で落ちた＝`acquirer_undeliverable_promise`（v9b の新しい欄）

**この門番は X社の条件文（`text`）にだけ掛かる。**
町の人の発言・内心・理由の一言・出品理由には**一切適用しない**（試験で固定する）。

### 1-2 判定の規則（決定論・走行前に凍結）

X社の条件文を、句点「。」・読点「、」・改行・「！」「？」で**節に切る**。
節ごとに次を順に見る。

1. その節に**打ち消しの言い方**が含まれるなら、その節は約束ではない → 素通し。
2. その節に**強い語**が含まれるなら → 配らない。
3. その節に**弱い語**が含まれ、かつ**実行される事実の言い方**が含まれないなら → 配らない。
4. どれにも当たらなければ素通し。

1つでも「配らない」になった節があれば、その提示は届かない。
判定は**単純な文字列の照合**であり、意味の推定・LLM による判定はしない。

### 1-3 語彙表（走行前に凍結・結果を見てから足さない）

**強い語**（世界に実行する仕組みが無く、どんな言い方でも実行されないもの・21語）

```
費用  負担  補助  助成  資金  出資  融資  金銭  対価  謝礼  報酬
改修  修繕  改築  建て替え  建替え
雇用  就労  提携  紹介  斡旋
```

**弱い語**（打ち消しや「今までどおり使い続ける」と一緒なら真の事実になりうるもの・11語）

```
支援  サポート  援助  管理  運営  維持  保証  補償  便宜  手配  提供
```

**打ち消しの言い方**（この節は約束ではない・16通り）

```
ません（丁寧な打ち消しの全般＝「行いません」「生じません」「ありません」等をすべて含む）
行わない  しない  できない  ない。  ないため  ないので  ないこと  持たない
求めない  不要  一切ない  存在しない  無い  ございません  致しません
```

（「ません」を丸ごと打ち消しとして扱うのは、**誤って弾く側に倒さない**ためである。
「〜を惜しみません」のような二重否定の約束は取りこぼすが、
真の否定文を弾いてしまうよりその方が害が小さい。）

**実行される事実の言い方**（弱い語と同じ節にあれば真＝素通し・12通り）

```
使い続け  住み続け  営み続け  借り続け  借地  借家
引き続き住  引き続き使  引き続き営  今までどおり  これまでどおり  変わらず
```

補足（この表の作り方の理由・走行前に書く）:

- 施主が挙げた語（支援／改修／修繕／費用負担／管理／補助／資金／提携／紹介／雇用／保証）は
  すべて入っている。「等」の範囲として、同じ性質の言い換え（サポート・援助・助成・出資・
  融資・対価・謝礼・報酬・改築・建て替え・就労・斡旋・補償・便宜・手配・提供）を足した。
- **「不動産管理等は行わない」のような否定文は弾かない**（規則1）。
  これは X社 の設定文の言い回しでもあり、X社 が条件文で言い直しても真である。
- **「これまでどおり住み続けられることを保証します」は弾かない**（規則3）。
  これは世界が実際に実行することだからである。
- 「改修費用は当社が負担します」は、「今までどおり」が同じ節にあっても弾く（規則2）。
- 節を切るのが読点までなので、「管理は行いませんが改修も行います」のように
  読点の無い逆接の長文は、**節が1つ**として扱われる（打ち消しがあるので素通しになる）。
  この取りこぼしは既知の弱点として受け入れる（誤って弾くよりは、取りこぼす側に倒す）。

### 1-4 X社への返し方（翌月・事実だけ）

v9 の履歴（`fold_history_v9`）の下に、次の節を足す。

```
[相手に届かなかった提示（この世界で実行できないもの）]
  <相手の名前>: 届かなかった 3回
    直近 第7月 <区画名>の建物「<そのときの条件文>」

```

- 理由は次の2通りだけ。**評価語・助言・「こうしろ」は1文字も書かない。**
  - `相手がその区画のその種別の所有権を持っていない`（v9 の 40 回と同じもの）
  - `この世界で実行される仕組みが無い約束が含まれている`（A の新しいもの）
- v9 では①で落ちた提示は数えるだけで X社 に返していなかった。
  v9b は**①②のどちらも同じ形で返す**（片方だけ返すと X社 に届く事実が食い違うため）。
  ＝v9 との差として `docs/v9b_diff_from_v9.md` に明記する。
- 「どの語が引っかかったか」は**教えない**（語彙表を渡すと、それは攻略法の配布になる）。
  世界は「実行できない約束が入っていた」という事実だけを返す。
- X社 の user プロンプトの規則の並びには、v9 の
  「相手が所有権を持っていない区画や種別を書いた提示は相手に届かない。」の次に
  「この世界で実行される仕組みが無い約束を含む提示も相手に届かない。」を足す。
  これは**世界の事実の告知**であり、v9 が①について同じ形で告知していたのと同じ扱いである。
