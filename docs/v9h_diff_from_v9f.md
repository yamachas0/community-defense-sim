# v9h は v9f と何が違うのか（設計の差と、結果の差）

- v9f の結果＝`docs/v9f_run.md`（`simulations/2026-08-30_1711_132_field_v9f_pay_more_if_needed_chat/`）
- v9h の結果＝`docs/v9h_run.md`（`simulations/2026-08-30_2017_138_field_v9h_declared_majority_chat/`）
- v9h の設計＝`docs/world_design_v9h.md`（走行前に凍結）。**v9g（全員にフルアタック）は不採用**。

**v1〜v9g のファイルは1バイトも触っていない。** 世界（町の人のプロンプト・名簿・44区画・
格子・会話・出品・門番3種・評価額・**資金51%**・月内の提示合計の規則・**v9f の命題**・
面積／取得割合／残り月数の事実行）は **v9f と1文字も違わない**。

---

## 1. 設計の差（1行だけ）

町の人に届く手紙の冒頭に、**世界が必ず**この1行を添える。

```
私どもは、この街の不動産の過半の取得を目指しています。
```

X社の自由文ではない（毎通・全員に同じ・LLM の裁量なし）。実測で**1,077通すべてに入っている**。
X社の設定文には整合のための1行（「あなたはこの目標を町に公言している」）だけを足した。

## 3. 明言して何が変わったか

### 3-1. **町が「過半」「街全体」という言葉を持った**（0件 → まとまった数）

v9f では、どれだけ手紙が来ても、どれだけ値段が上がっても、
**「過半」「買い占め」は0件、意図を疑う断りは1件**だけだった。
v9h では**意図を疑う形の断りが58件**、断りの理由の1位が
**「X社の意図を考慮し、現時点では売却に応じない」27件**になった。

公の場での発言も変わった。

```
第4月・神明社の自治会長「街全体への影響を考えると、一旦『売らない』と回答し…」
第4月・魚市場前の診療所の院長「特定の事業者が市内不動産の過半を取得した場合の条例は…」
第17月・波止場通りのご夫婦「街全体の取得を目指しているとか。」
```

**自分の損得ではなく、街と制度の話が出た。**

### 3-2. **売れなくなった**（11件 → 3件・資金消化 28.2% → 6.3%）

同じ命題（余らせるより高く買え）、同じ財布（51%）で、成約は**3分の1以下**。
評価額以上の提示721件のうち718件が断り。
値付けの平均も 1.50倍 → 1.08倍に下がっている
（**断られ方が変わると、買い手の値付けも変わる**）。

### 3-3. 出て行った人の中身が入れ替わった

```
v9f：町を出た8人＝売って出た6人＋借りていた2人
v9h：町を出た4人＝**売って出た0人**＋借りていた4人
```

**所有者は1人も町を出なかった。** 売らなければ出て行かないので当然だが、
「明言された町では、持っている人は動かず、借りている人だけが去った」という形になった。

## 4. 「明言」の効果として言えること・言えないこと

**言えること（0件 対 数十件で桁が違う）**

1. **明言すると、町は「過半」「街全体」「意図」という言葉で断るようになる**
   （意図を疑う断り **1件 → 58件**・断りの理由の「過半」**0件 → 61件**）。
2. **明言すると、売れなくなる**（成約 11件 → 3件・資金消化 28.2% → 6.3%）。
   買い手の粘り（再提示1,037回）はむしろ増えている。

**言えないこと**

- **1本対1本**である。同設定2本の v9c が成約3件と6件に割れた実績があり、
  11件対3件も揺れを完全には否定できない（ただし反応語の 1件対58件は桁が違う）。
- 語のカウントは**呼び名に引っかかる**（「支配人」「自治会長」）。上の表はそれを外した数字で、
  外さない生の数字は `emergence_v9h.json` に入っている。
- 「過半」「意図」は**世界が配った文言そのもの**である。町の人がその語を使うのは
  **手紙の言葉を借りている**面があり、ゼロから危機感が生まれたのとは違う。
- 反応語の合計は**内心を含む**（誰にも伝わらない）。
  「町で共有された危機感」と読んではいけない（走行前レビューの指摘）。
- 明言は世界が強制的に配っている＝**実験のための介入**であって、買い手の自発的行動ではない。
