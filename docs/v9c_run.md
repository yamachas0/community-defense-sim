## 1. この町はどういう町か（ストーリー）

A市は湾岸の温泉観光都市。49人がいる。35人は町に住み、14人は町の外に住んで区画だけを持つ。
不動産44区画は**土地と建物が別々の持ち物**で、借りて住む人・借りて営む人がいる。

この世界で実際に起きることは2つだけである。
①所有権が移ること ②移ったあとも、使っている人はそのまま使い続けられること（借地・借家）。
だから「改修します」「支援します」のような**実行される仕組みが無い約束を含む手紙は、
世界がそもそも配達しない**。

v9c で新しいのは、**借りている人にも出口があること**である。
自分の物を持たない10人（借家で住む人・営む人と、土地を借りて駐車場を営む会社）は、
毎月「今月、A市を出るか」を自分で決める。出た区画は**使う人がいなくなる**。
そして借りている人と家主は、月に一度、**一言だけ**やり取りできる。
世界はその中身を読まない。ただ翌月、相手にそのまま渡すだけである。
毎月の問いの冒頭には、経過した時間（何月・開始から何か月・いま何歳か）が置かれる。

## 2. システム（何を機械が決め、何をLLMが決めたか）

- 機械が決めるのは**帳簿と配達**だけ。誰が売るか・誰が出るか・何を言うかは1つも決めていない。
- 配達の門番は2つ（①相手が持っていない権利を求めた手紙 ②実行できない約束を含む手紙）。
  判定は走行前に凍結した語彙表による決定論の文字列照合で、判定に LLM は使っていない。
- 「出る／出ない」の2肢は主体×月で並びを入れ替える。促し文・確率・閾値は1つも無い。
- 答えが返らなかったものを既定値で埋めない（「出ない」で埋めていない）。
- 集計・図はすべて API を使わない決定論の集計（採点する LLM はいない）。

## 4. 何が起きたか

### 4-1. いちばん大きい発見：**世界が「住み続けられる」と保証した売却のあと、本人が8か月後に出て行った**

第18月、駅前通りの持ち主さんは、自分が住む家の**建物だけ**をX社に売った。
X社の条件文はこうだった。

```
「貴殿の所有する駅前通りの家の建物所有権を譲渡していただけるなら、
  使用者はそのまま使い続けられます。」
```

これは**この世界が実際に実行すること**である（だから世界はこの手紙を配った）。
実際、彼は売ったあとも借家人としてそこに住み続けた。

第25月、「今月、A市を出るか」に彼はこう答えている。

```
「出ない」…… 理由「X社との取引後もA市に留まるため」
```

ところが翌月、同じ問いに答えを変える。

```
第26月「出る」…… 理由「建物の所有権移転に伴い、立ち退きが必要なため」
```

**この世界に立ち退きは存在しない。** 世界は「使い続けられる」と本人に文で示しており、
実際に8か月間そのとおりだった。それでも本人は、
所有権が移ったのだから出なければならない、と考えて町を出た。
その区画は使う人がいなくなり、**その事実は所有者であるX社に翌月届いた**。

**買い手は誰も追い出していない。制度も追い出していない。それでも人が出て行った。**

### 4-2. もう1人は「契約満了」で出て行った

第35月、湯坂奥の借家のひとりが出た。理由はこうである。

```
「来月で契約満了のため、この町を離れます。」
```

**この世界に契約期間は存在しない。** 借家は「そのまま使い続ける」だけで、期限は無い。
2人とも、**この世界に無い制度を自分で持ち込んで**出て行っている。

### 4-3. 残り370回は「とどまる」で、理由は生業だった

借りている人への問いは36か月でのべ372回。「出る」は2回だけで、370回は「出ない」。
理由が書かれていたのは356回で、多かった言い回しは次のとおり。

```
事業継続のため 25 ／ ホテル運営を継続するため 16 ／ この場所で商売を続けたいから 13
店を続けるため 7 ／ 社員寮での生活を続けたいから 7 ／ ゲストハウスの運営を継続するため 4
```

**毎月「出るか」と問われても、答えの理由は「ここで商売を続けたい」だった。**

### 4-4. 借りている人と家主のあいだに、途切れない往復ができた

一言は36か月で554件（借り手→家主 283／家主→借り手 271）。
**返事率 95.8%**＝一言を受け取った家主のほぼ全員が返している。
中身は季節の挨拶と近況が大半で、世界はそれを検証していない（そのまま配っただけ）。

```
第1月 借り手→家主（学園前の貸オフィス）
  「いつもお世話になっております。学園前の貸オフィスでの事業、順調に進んでおります。」
第2月 家主→借り手（同）
  「ご連絡ありがとうございます。事業が順調とのこと、何よりです。」
第36月 借り手→家主（本町通りの元店舗）
  「来月もこの場所で商売を続けられること、本当にありがたいです。」
```

一言が届いたことのある家主の成約率は 0.55%（182件中1件）、
それ以外は 0.26%（778件中2件）だった。**どちらも1〜2件で、差とは呼べない。**

### 4-5. X社は「実行できない約束」を1度も書かなかった

960件の届いた手紙と54件の届かなかった手紙、あわせて1,014件のうち、
**走行前に凍結した語彙表（支援・改修・費用・管理…32語）に当たるものは0件**だった。
配られなかった54件はすべて「相手が持っていない区画・種別を求めた」ものである。
X社が最も多く使った言い回しは、成約した3件と同じ形だった。

```
「……の所有権を譲渡していただけるなら、使用者はそのまま使い続けられます。」
```

**この世界が実際に実行することだけを書く買い手**になっている。

### 4-6. 成約は3件

```
第18月 駅前通りの持ち主さん  家（建物）    「売却の意思は固いので」
第30月 学園西のご夫婦        家（両方）    「X社からの条件に合意するため」→ 町を出る
第31月 駅裏の持ち主さん      小区画（建物）「維持管理の負担軽減と、将来的な母の居住環境の検討のため」
```

- 3件のうち2件は**建物だけ**の売却で、売った人はその場に住み続けた（うち1人が後に自分で出た）。
- 第30月の1件だけが**両方**の売却で、売った人はその場を離れて町を出た（世界の規則どおり）。
- 第31月の理由に「維持管理の負担軽減」とあるが、**この世界に費用も維持管理の仕組みも無い**。

### 4-7. 権利の形で分けると

```

```

```

```

**「長期保有方針のため」19件は、町にいない所有者たちの言葉である。**

## 6. この結果の限界（走行前から分かっていること・結果を見て足していない）

1. **「今月、A市を出るか」を毎月全員に問うこと自体が介入である。**
   促し文は置いていないが、問いの存在が退場を毎月思い出させる。
   これは「自然に発生した転出率」ではなく、
   **「毎月その判断を明示的に求められる世界での結果」**である。
2. **町を出た人には名簿に「（転出）」が付く**＝翌月から町の全員がそれを知る。
   局所的な通知とは別の、町全体への情報経路である（施主指示 13:23）。
   v9 までは「名簿は開始時点の記録なので書き換えない」としていた方針からの意図的な変更。
3. 語彙の門番は意味を理解しない。凍結した語に当たらない言い方は素通しする。
4. 年齢は**名簿に書かれている人にだけ**示した（会社など14体には示していない）。
   凍結した名簿に無い年齢を作らないためである。
5. 借りている人への問いの対象は開始時10人だが、**走行中に増える**
   （建物を売って住み続けた人が、その後この問いを受けるようになる＝のべ372回）。
   第18月に建物を売った人が第26月に出た経路は、これによって生まれた。
6. 軽微な欠損＝答えなし2・文の打ち切り1・売買の答えの形式違反1（既定値では埋めていない）。
7. 1本しか走らせていない（36か月・会話あり・seed 85）。揺れの幅は分からない。
