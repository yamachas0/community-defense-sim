## 4:15–5:00　24か月版と、言えないこと（run 切替：v5bA / v5bB / v5bC）

- 画面のランを **v5b** に切り替える（24か月・売買19件と賃借9件）。
  X社は**所有41.3%、賃借を入れると60.9%**まで握ります。
- **「同じ相手が複数を動かしている」までは届きます。**3本とも成立し、2本では**26人全員が公の場で**口にしました。
  もう1本は**8人（30.8%）どまり**で、17人は内心にとどめた。
- **しかし「買い占め」「地上げ」「乗っ取り」とは、ほぼ誰も言いませんでした。**
  3本の**22,686行のうち7行**。判定として成立したのは **0 / 3 / 2 件**。
  一番近づいたのは、**自分が売った当事者の内心**です。そこでも動機は
  「**温泉権を守るために買い集めているのだろう**」という**善意の説明**に落ち着きました。
- **言えないこと**（最後に必ず言う）：
  1本は1実現です。**気づく確率は言えません**。同じ台本で結果が割れました（26人 vs 8人）。
  判定は走行前に固定しましたが、**偽陰性の人手監査はしていません**。
  だから言えるのは「**保存した出力の中に、事前に定義した表現は無かった**」までです。
  配線の判定も**不合格**です（打切りが 0.1〜0.2% 残っています）。**都合の悪い数字も画面に出しています。**

> 静かな占領は、隠したから成立するのではありません。
> **見えていても、名前が付かないから**成立する。

## 質疑の想定

- **「兆候を増やせば気づくのでは？」**
  → 増やしません。それは実験条件であって、結果を出すための調整ではない（この研究の絶対ルール）。
  実際、前の版で見つかった「隣の区画の名義が毎月見える」漏れを塞いだら、第1月の言及は9件から0件になりました。
- **「LLMが勝手に喋っているだけでは？」**
  → 世界が主体に渡すのは観測だけで、話題も態度も指示していません。X社は一度も呼ばれていません。
  それでも街はX社の話を始めました。
- **「24か月でも占領と言わないのは、モデルが弱いから？」**
  → 分かりません。語彙の問題か世界の性質かを切り分けるのが次の実験です（人手監査・第二分類器・語彙拡張）。
