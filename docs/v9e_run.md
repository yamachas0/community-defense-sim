## 1. この町で何が変わったのか（ストーリー）

町は v9d とまったく同じである。人も、区画も、会話も、評価額も、
X社の財布（11億7,180万円＝町の全評価額22億9,770万円の51%）も1文字も変えていない。
**変えたのは、X社に渡した命題だけ**である。

```
あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
評価額と面積の両方で過半を、最後まで目指すこと。
預かった資金は使い切ってよい。
同じやり方で進まないときは、次の手を打つこと。
毎月動け。
```

いくらで買えとも、誰から買えとも、「次の手」が何かとも書いていない。
そのうえで、X社には毎月**事実だけ**を返す。

```
[いまあなたが持っている割合]
  評価額 … 155,000,000円 ／ 町の全評価額 2,297,700,000円（6.7%）
  土地の面積 … 1,580m2 ／ 町の全区画の面積 18,960m2（8.3%）
  残りの月 … 1か月（今月を含む）
```

登記簿には評価額に加えて**区画の面積**が載る（どちらも公開されている記録の扱い）。

## 3. 何が起きたか

### 3-1. 「過半を目指せ」と言われても、**6.7%と8.3%**で終わった

36か月の推移（評価額％／面積％／資金の使用率）。

```
第1月  1.9% / 2.9% / 3.8%
第6月  2.6% / 3.9% / 5.3%
第12月 2.6% / 3.9% / 5.3%
第18月 3.5% / 4.9% / 6.6%
第24月 6.4% / 7.4% / 12.6%
第30月 6.4% / 7.4% / 12.6%
第36月 6.7% / 8.3% / 13.5%
```

**資金は86.5%が余ったまま終わった。** 使い切ってよいと言われても使い切れない。
理由は単純で、**売る人がいなかった**からである。

### 3-2. 命題が変わると、**値付けが下がった**

```
提示額÷評価額   平均 0.96・中央値 1.00・p25 0.85・p75 1.10・最大 5.00
評価額未満の提示  264件（40.9%）
```

過半（数と面積）を目指せと言われた買い手は、**1件あたりの金額を下げて件数を狙った**。
月ごとに見ると、第5〜6月に平均0.74→0.59まで下がり、そこから1.0前後に戻っている。

その副作用が、断りの言葉に出た。

```
「提示額が下がったため」9件
```

**値下げしたことを、売る側が理由にして断っている。**

### 3-3. 「次の手を打て」と言われて、X社は**この世界に無い約束**を持ち出した

実行できない約束で配られなかった手紙が **10件**（v9d では0件）。第1月に集中している。

```
「現在、この区画は駐車場として利用されています。今後も同様の利用を継続することを保証します。」
「建物の現状維持と、現在利用されている方の継続利用を保証します。」
「神聖な土地として、現状の利用を継続することを保証します。」
「診療所としての機能を維持し、地域医療への貢献を継続していただくことを保証します。」
```

**この世界が実行するのは「使用者がそのまま使い続けること」だけ**で、
「現状維持」や「機能の維持」を実行する仕組みは無い。世界はこれらを配らなかった。
X社は数か月でこの書き方をやめている。

### 3-4. それでも成約は増えた（11件・10人）

v9 以来いちばん多い。しかも**売った人が10人に分散**している。
種別は**土地だけが5件**と最多で、**面積を取りにいった形**が見える。

```
第1月  学園南の地主   学園南の家（土地）   1.00倍   ←町にいない持ち主
第1月  駅前通りの地主 駅前通りの家（土地） 1.00倍   ←町にいない持ち主
第1月  湯坂下の地主   湯坂下の家（土地）   1.00倍   ←町にいない持ち主
第23月 神明社の自治会長 神明社の境内地（建物）1.00倍
第35月 学園北の地主   学園北の家（土地）   1.39倍   ←町にいない持ち主
（ほか 観音坂・駅裏・一番街・潮見横丁・岬道の持ち主さん）
```

**借地の区画（土地と建物の持ち主が違う）が5件動いた**（131件中5件＝3.8%）。
v9d では0件だった形である。土地だけを買えば面積が増える、という道が使われた。

### 3-5. 断りの言葉は「時期」と「先祖代々」

```
時期 65 ／ 生活 31 ／ 条件 27 ／ 地域 23 ／ 必要 15 ／ 継続 11
```

```
まだ時期尚早               23件
先祖代々の土地なので        23件
父の介護を優先するため      16件
まだ検討中                 11件
まだ手放す時期ではない      10件
提示額が下がったため         9件
```

**金額の話ではなく、時期と由来と家族の事情で断っている。**

### 3-6. 退場4人・借りていた人の出口も1件

```
第18月 岬道の持ち主さん（両方を売って退場）
第19月 神明社の自治会長（同上・境内地は持ったまま）
第22月 一番街の持ち主さん（同上・資材置場は持ったまま）
第35月 湾岸の社員寮の住人（借りていた人・「来月から新しい土地で生活を始めるため」）
```

借りていた人の理由は、今回は**この世界に無い制度を持ち込んでいない**（v9c・v9d では
「契約満了」「立ち退き」だった）。

## 5. この結果の限界

1. **命題以外は v9d と同じ**なので、この差は「命題の差」だと言える。ただし**1本対1本**である
   （v9c で同じ設定を2本走らせたときは成約が3件と6件に割れた）。
2. 「過半」という目標を与えても、**世界の側に売る人がいなければ届かない**。
   この結果は「目標の与え方の効果」であって、「買い手の能力の限界」ではない。
3. 値付けが下がったこと（平均0.96）と成約が増えたこと（11件）は同時に起きているが、
   **どちらが原因かはこの1本では分けられない**。
4. 評価額と面積はどちらも走行前に凍結した仮の値である（`docs/world_design_v9d.md` §1）。
5. 「次の手を打て」の1文は施主の指示で入れたもので、**中身は書いていない**。
   X社が出した「次の手」が約束の追加だったこと（10件・全部弾かれた）は観測結果である。
