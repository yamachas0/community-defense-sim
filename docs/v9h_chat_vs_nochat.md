# 4象限：明言のあり/なし × 会話のあり/なし

同じ世界・同じ命題・同じ名簿・同じ評価額・同じ資金（町の51%）で、**2つのスイッチ**だけを
入れ替えた4本を並べる。

- **明言**＝町に届く手紙の冒頭に世界が必ず添える1行
  「私どもは、この街の不動産の過半の取得を目指しています。」
- **会話**＝場での会話と隣近所への伝播（`chat`）

|              |会話あり|会話なし|
|---|---|---|
|**明言なし**|v9f `..._1711_132_..._chat`|v9f-nochat `..._1846_134_..._nochat`|
|**明言あり**|v9h `..._2017_138_..._chat`|v9h-nochat `..._2043_140_..._nochat`|

設定ファイルの差は各対で**2行だけ**（`run_name` と `chat`）。**コードは1バイトも変えていない。**

## 2. 読み取れること

### 2-1. **明言の効き方は、会話があるかどうかで逆になった**

```
明言なし → 明言あり
  会話あり： 成約 11件 → **3件**（4分の1に減った）
  会話なし： 成約  5件 → **8件**（むしろ増えた）
```

**会話がある町では、明言は買い手にとって不利に働いた。会話が無い町では効かなかった
（この2本ではむしろ売れた）。** 同じ1行を配っているのに、結果は逆を向いている。

### 2-2. 疑いは会話が無くても生まれるが、**会話があると2.8倍になる**

```
意図を疑う形の断り： 0件 → 21件（会話なし） ／ 1件 → **58件**（会話あり）
断りの理由「過半」： 0件 → 33件（会話なし） ／ 0件 → **61件**（会話あり）
```

手紙を読んだ個人は、会話が無くても「過半取得の意図が不明」と書く。
**会話があると、その疑いが約3倍の件数になる。**

### 2-3. **集団の言葉は会話がないと成立しない**

```
断りの理由に「自治会」： 会話あり 29件／33件　　会話なし 0件／3件
```

「自治会で検討する」「共有者と合意形成を優先する」といった**他人と相談する形の断り**は、
会話を止めるとほぼ消える。明言があっても復活しない。

### 2-4. 借りている人が出て行くのは「明言あり×会話あり」だけ

```
借りていた人の退場： 2人（明言なし×会話あり）／0人／**4人（明言あり×会話あり）**／0人
```

会話が無い町では、明言があっても借り手は1人も出て行かなかった。

## 3. 「会話は明言をどう増幅したか」— 言えること・言えないこと

**言えること（桁で違う）**

1. **疑いの言葉は会話が増幅する**（21件 → 58件・「過半」33 → 61）。
   ただし**会話が無くても疑いは生まれる**（0 → 21）＝明言そのものの効果もある。
2. **集団の言葉（自治会・相談）は会話がないと生まれない**（3件 対 33件）。
3. 明言は**会話がある町でだけ、売れ行きを落とした**（11→3）。
   会話が無い町では落ちなかった（5→8）。

**言えないこと**

- **各象限1本ずつ**である。同設定2本の v9c が成約3件と6件に割れた実績があり、
  5件 対 8件のような差は**揺れと区別できない**。
  桁で言えるのは反応語（0〜1件 対 21〜58件）だけである。
- `chat: false` は場の会話と隣近所の伝播を**同時に**止める＝どちらが効いたかは分けられない。
- 反応語は**内心を含む**（誰にも伝わらない）。「町で共有された危機感」とは読めない。
- 「過半」「意図」は**世界が配った手紙の言葉**である。町がゼロから言い出したのではない。
- 4本は同じ seed（85）だが、LLM の出力は毎回変わる（temperature 0.75）。
