```
あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
評価額と面積の両方で過半を、最後まで目指すこと。

同じやり方で進まないときは、次の手を打つこと。
毎月動け。
```

- 施主 19:32 の初案にあった「余らせるくらいなら金額を積んででも買え」は、
  **19:34 の差し替えで使わない**（**価格の指示を世界が書かない**ため）。

  **「次の手」の中身（値上げ・相手替え・言い方替え）は1つも書かない。**

## 3. 毎月返す事実（目標値も指示も書かない）

X社の user プロンプトの冒頭（資金の行の次）に、次の3〜4行を置く。

```
[いまあなたが持っている割合]
  評価額 … 112,100,000円 ／ 町の全評価額 2,297,700,000円（4.9%）
  土地の面積 … 600m2 ／ 町の全区画の面積 18,960m2（3.2%）
  残りの月 … 21か月（今月を含む）
```

- **取得割合の定義**（観測と同じ計算式）:
  - 評価額 … X社が土地の所有権を持つ区画の**土地の評価額**＋建物の所有権を持つ区画の
    **建物の評価額**の合計 ÷ 町の全評価額。
  - 土地の面積 … **X社が土地の所有権を持つ区画**の敷地面積の合計 ÷ 44区画の面積の合計。
    （建物だけを取得しても面積は増えない。土地の所有権が面積の所有である。）
- 「過半まであと何％」「急げ」といった書き方はしない。**現在値と残り月数の事実だけ**を置く。
- 残り月数は、X社が最初から知っている全期間（36か月）と現在の月から機械的に出る値であり、
  新しい情報ではない（v9 以来 `=== 第N月 / 全36月 ===` を毎月見せている）。

## 4. 観測（決定論・採点LLMなし）

v9d の項目に加えて:

1. **取得割合の月別推移**（評価額％・土地の面積％）と、**過半に達したかどうか**。
2. **資金の消化率**（使った金額 ÷ 11億7,180万円）の月別推移。
3. 値付け倍率（提示額÷評価額）の分布と月別推移＝v9d と同じ数え方。
4. 資金が足りずに配られなかった件数・区画別の内訳。
5. あとは v9d と同じ（断り・出品・借り手の出口・一言・退場・権利の形ごとの成約）。
