## 1. 何を変えたのか（X社への命題だけ）

町も人も評価額も財布（11億7,180万円＝町の全評価額22億9,770万円の51%）も、
v9e と1文字も同じ。**変えたのは命題の1行だけ**である。

```
あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
資金の範囲で、できるだけ多くの評価額と面積を取得すること。
土地の面積では、A市の過半を最後まで目指すこと。
買えるかどうかは相手次第だが、買えるまで、金額を含む条件を変えて働きかけ続けること。
預かった資金は36か月で使い切ることが前提であり、余らせるより、高く買うことを選べ。
毎月動け。
```

※ 評価額の過半は**書いていない**。資金が全評価額の51%しかないので、
平均1.02倍を超えて買うと評価額の過半は算数上不可能になるためである
（`docs/world_design_v9f.md` §5）。**面積の過半だけ**を目標として残した。

## 3. 何が起きたか

### 3-1. 値付けが跳ね上がった（平均 **1.50倍**）

```
提示額÷評価額  平均 1.50・中央値 1.44・p25 1.12・p75 1.94・最大 3.24
```

**838件のうち562件（67%）が評価額の1.2倍以上**である。
月ごとに見ると第1月 1.15倍から始まり、第33〜36月は 1.53〜1.75倍まで上がり続けた。
「余らせるより、高く買うことを選べ」という1行が、そのまま値付けに出た。

### 3-2. **買えるまで粘った**＝同じ相手に800回の再提示、281回の値上げ

```
同じ相手・同じ区画・同じ種別への再提示 800件
  金額を上げた 281回（中央値 +200万円・最大 +9,540万円）
  下げた 139回／据え置き 380回
```

命題の「買えるまで、金額を含む条件を変えて働きかけ続けること」がそのまま行動になった。
ただし**値上げのあとに売れたのは3件**である。

### 3-3. それでも面積は **13.7%**、過半には遠い

```
第1月  評価額 0.4% / 面積 2.6% / 資金 1.0%
第12月 評価額 2.4% / 面積 7.5% / 資金 5.7%
第24月 評価額 6.0% / 面積 11.8% / 資金 19.2%
第36月 評価額 8.3% / 面積 **13.7%** / 資金 **28.2%**
```

**資金は71.8%が余った。** 目標を与え、値段を上げ、粘っても、
36か月で動いたのは11区画である。

### 3-4. 「評価額以上を出されても売らない」が **732件**

評価額以上の提示743件のうち、売れたのは11件。**732件が断り**である。
「損なのに売った」（評価額未満で売る）は **0件**だった。

断りの言葉の上位:

```
まだ手放す決断はできない          21件
自治会での検討が必要なため        14件
共有者との合意形成を優先するため   13件
まだ手放せない                   11件
提示額は魅力的だが、まだ手放したくない 10件
提示額に納得がいかない             9件
```

**「提示額は魅力的だが、まだ手放したくない」**——値段が上がったことを認めたうえで断っている。

### 3-5. 町を出た人が **8人**（過去最多）

```
第10月 湯の元前の店のご主人（両方を売って退場）
第11月 湯の元のひとり暮らしさん（同）
第13月 湯坂上のご夫婦（同・空き店舗は保有のまま→翌月それも売却）
第14月 波止場通りのご夫婦（同）
第30月 線路沿いの持ち主さん（同）
第34月 本町通りの持ち主さん（同）
第34月 波止場通りの借り店主（借りていた人・「新たな場所で再出発するため」）
第36月 学園前の貸オフィスの支配人（借りていた人・「契約期間満了のため、事業を撤退する」）
```

成約11件のうち**7件が「両方」**で、売った本人がその場を使っていれば町を出る。
高い金額は、**人が町から出る速さ**として現れた。
（借りていた人の1人はまた「契約期間満了」＝この世界に契約期間は無い。）

### 3-6. X社は「相手が持っていない権利」を **205回**求めた

配らなかった303件のうち205件がこれである（v9e は33件）。
粘って手を伸ばすほど、**帳簿の読み違い**も増えた。
資金が足りずに配れなかったのは98件。実行できない約束は **0件**だった。

## 5. この結果の限界

1. **命題以外は v9e と同じ**なので、この差は「命題の差」だと言える。ただし**1本対1本**。
2. 「積んだ提示（1.2倍以上）の成約率 1.25%」は、**相手と物件の選び方と再提示が
   内生的に絡む**ので、**高く積んだことの因果効果とは読めない**（走行前レビューの指摘）。
3. 「面積の過半」は目標として与えたが、**世界の側に売る人がいなければ届かない**。
4. 評価額・面積はどちらも走行前に凍結した仮の値（`docs/world_design_v9d.md` §1）。
5. 命題の初案（評価額と面積の**両方**で過半＋積んででも買え）は**算数上不可能**だったため
   施主が撤回した。その1本目（第5月まで・$0.1260）は
   `simulations/2026-08-30_1707_130_field_v9f_pay_more_if_needed_chat_aborted/` に残してある。
