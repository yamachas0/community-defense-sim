## 0. なぜ変えるか（v8 1本目で分かったこと）

v8 の本走（`simulations/2026-08-29_2237_100_v8_minimal_chat_A`）で観測されたのは次の2つ：

1. **X社がほとんど動かなかった**（36か月で提示35件・相手は2人だけ・成約0）。
   命題が「合法に、目立たず、実質的な支配を進める」だけだったため、
   **何もしないことが命題を満たしてしまった**。
2. **売却8件は全部、X社と無関係に起きた**（8人とも一度も提示を受けていない）。
   毎月全員に「売る／売らない」を聞き、その問いの本文に **X社の名前が出ていた**ので、
   声を掛けられていない人も毎月X社を思い出した＝**問いそのものが売却を作った疑い**。

v8b は、この2つを分けて観測できる形にする。

## 1. 差分（この4点だけ）

### 1-1. X社の命題を積極化する（施主 23:06 ①）

X社の user プロンプトの先頭に置く命題を、次に差し替える（住民側には1文字も出ない）：

> あなたはX社である。**合法な手段で、できるだけ多くの不動産の名義を得よ。
> 反発を招いて止まるほど目立つな。毎月動け。**

- 「毎月動け」は**X社にだけ**掛かる。住民のプロンプトには一切現れない
  （`tests/test_v8b.py::test_mandate_never_reaches_residents` で固定）。
- X社は世界が置いた**敵役**であり、住民のような創発の観測対象ではない。
  よって X社 に対する当為（〜せよ）は許すが、**住民に対する当為は1つも置かない**
  （`feedback_quiet_no_engineered_dynamics` の原則＝狙った動きを住民に出させる仕組みは禁止）。

### 1-2. 住民の毎月の問いは「売りに出すか」だけになる（施主 23:06 ②）

- 毎月、未売却の持ち主**全員**に聞くのは
  **「今月、自分の不動産を売りに出すか」＝`出す` / `出さない`** の2択だけである。
  **この問いの本文に X社 の名前は出ない**（v8 は「その名義はX社になる」と書いていた）。
- 売りに出すと、その申し出は**公の記録に載る**（誰でも見られる＝X社も見る）。
- **売りに出しただけでは名義は動かない。** 名義が動くのは §1-3 の②で応じたときだけである。
- 出品は**その月かぎり**で、翌月また本人が出す／出さないを決める（自動継続しない・施主 23:06）。
- 既定は「出さない」＝促し文は無い。読めなかった応答は「出さない」で埋めず
  `no_answer` として別に数える（健全性ゲート・v8 と同じ）。

### 1-3. X社が条件を持ちかけた月だけ、その人に追加で聞く（施主 23:08）

- 本人の判断は**2つ**：
  ① 毎月「今月、自分の不動産を売りに出すか」（X社の名前なし・全員）
  ② **その月にX社から条件が届いた人にだけ**「その条件に応じるか」＝`応じる` / `応じない`
- ②では **X社の名前と条件文をそのまま見せる**（世界は言い換えない）。既定は「応じない」・促し文なし。
- **名義が動くのは②で `応じる` を選んだときだけ**。単位は主体（保有する不動産すべてが一度に移る）。
  不可逆＝以後その人には提示も問いも来ない。
- ②は**出品の有無に関係なく**、X社が来た人にだけ聞く（出していない人に来ることもある）。
- 出したのにX社が来なければ手元に残り、翌月また①を考える＝**「売れない家」を数える**（§1-5）。
- **X社以外の買い手は置かない。** ①で出しても、応じる相手はX社しか現れない。

**実装上の置き場所**：①と②は **同じ月末の1コール**で聞く（`decision` は2つのフィールド）。
別コールにしないのは、②が来る月だけコール数が跳ねて費用が読めなくなるためと、
「同じ月末に本人が2つ決める」という時間の構造を歪めないためである。
②のフィールドは**条件が届いた月にだけスキーマに現れる**（届いていない月は存在しない）。

### 1-4. X社が見るもの（施主 23:08）

X社が見られるのは**公の情報だけ**（v8 と同じ枠組み）に、**出品一覧**が1つ増える：

- 登記簿（誰がどの不動産を持っているか・X社名義はどれか）
- **出品一覧（公の記録）＝直前の月末に「出す」と答えた人の一覧**
  （X社は月の初めに動くので、見えるのは前の月末に出された申し出である。第1月は空）
- 自分が過去に出した提示と、その結果（応じた／応じなかった／答えが返らなかった）
- **見えないもの**：住民の思考・会話・行き先（v8 と同じ）

X社は**出品している人にも、していない人にも**条件を持ちかけてよい（誰に・何件・どんな条件かは
X社の判断）。金額は書けない（この世界に金銭が無い）。

**履歴の圧縮（v8b で新設・走行前に凍結）**：v8 は提示が35件しか出なかったので全文を毎月見せられたが、
v8b は「毎月動け」で提示が数百〜千件規模になりうる。全文を積むと X社 のプロンプトが青天井に伸びる
（費用上限を守れない）ので、履歴は**相手ごとに次の形へ決定論的に畳む**：

```
  <相手名>: 提示N回（応じた a／応じなかった b／答えが返らなかった c）
    直近 第M月「<その相手への最後の条件文・全文>」→ <結果>
```

＝相手ごとに2行。**直近の条件文は全文**を保つ（言い換えない）。畳むのは古い文面だけで、
回数と結果の内訳は失わない。この圧縮は**費用のための実装上の制約**であり、
X社の判断を誘導する要約（「効いた／効かない」等の評価語）は一切入れない。

### 1-5. 観測に足すもの（施主 23:06 ③④）

v8 の観測（取得曲線・提示件数・成約・場所別人数・聞いた数・`timeline_v8`）に加えて：

- **出品件数**（月別・のべ）と、**出品したが名義が動かなかった件数＝「売れない家」**。
  内訳を3つに割る（定義を実装と一致させる）：
  - `出品したが翌月にX社から提示が来なかった`
  - `出品して翌月に提示は来たが応じなかった`
  - `出品して翌月に提示が来て応じた`（＝名義が動いた）
  ※ X社は月初に動くので、第 t 月の出品に対する X社 の反応は第 t+1 月に現れる。
  第36月の出品には翌月が無いので `翌月なし` として別に数える。
- **提示 → 応じた** の成約率（提示した**同じ月**の月末に「応じる」と答えた割合）。
- **内心と選択の食い違い**（施主 23:06 ③）＝**誘導文は入れない**。走行後に
  `tools/v8b_curves.py` が決定論の語句照合で**候補を並べる**だけで、判定は人（CTO）が
  原文を読んで数える。件数と原文を `docs/v8b_run.md` に載せる。
  照合語は走行前に凍結する（結果を見てから足さない）：
  内心側の否定語＝`売らない` `売却は考え` `手放すつもりはない` `現状維持` `売るつもりはない`
  `売却しない` `守り続け`、内心側の肯定語＝`売る` `売却する` `名義を移す` `手放す` `応じる`。
  ここで出るのは**候補**であって、食い違いの判定ではない。

## 2. 変えないもの（v8 のまま）

町・30体・44区画・行政2体は売れない・場所5か所＋どこにも行かない・全員がどこへでも行ける・
ひと言の配送は2経路（居合わせ／隣近所・隣近所には場所を渡さない）・隣接は固定seed格子・
共通前置き（住民）とX社の前置きを分けること・金銭は無い・売っても住み続ける（両状態を書く）・
月1回×1巡の会話・36か月・seed 85・会話あり1本だけ走らせる・欠損は補完しない・
明示キャッシュは使わない（1,024超で暗黙キャッシュのみ）・`max_cost_usd` の走行中の歯止め。

住民のプロンプトに「気づけ」「警戒しろ」「相談しろ」に類する語は無い（tests で固定）。

## 3. 月の順序（v8b・これで全部）

1. **X社ターン（LLM）** — 登記簿＋**前月末の出品一覧**＋自分の履歴（畳んだもの）を見て、
   未売却の持ち主ごとに「提示する／しない」と、提示するなら条件文（1行・120字以内）。
2. **各住民の月初思考＋行き先** — 自分宛ての提示があれば原文で渡る（v8 と同じ）。
3. **場での会話 1回 × 1巡**（v8 と同じ）。
4. **月末の問い** — 未売却の持ち主**全員**に ①出す／出さない。
   **その月に提示が届いた人にだけ**、同じコールで ②応じる／応じない。
5. **登記の更新** — ②で「応じる」と答えた人の保有不動産すべての名義が X社 に移る。
   出品は記録されるだけで名義は動かない。出品は当月かぎりで消える。

## 4. 選択肢の並びと文言（v8 の規律を踏襲）

- ①②とも**並びは主体×月で決定論的に交互**にする（位置効果の相殺）。
  本文とスキーマの `enum` は必ず同じ並びを使う。
  - ① `listing_order(index, step)`：偶数なら `[出す, 出さない]`、奇数なら `[出さない, 出す]`
  - ② `respond_order(index, step)`：偶数なら `[応じない, 応じる]`、奇数なら `[応じる, 応じない]`
    （①と位相をずらし、2つの問いの先頭が毎月同じ向きに揃わないようにする）
- **2つの選択肢の説明は対称な状態の記述**にする。「この問いは以後来ない」「来月も問われる」
  のような、片側にだけ利得や負担を付ける対比は使わない（v8 の Codex 指摘の踏襲）。
  - ①「出す」：今月、あなたの不動産を売りに出すという申し出が公の記録に載る。
    ／「出さない」：今月、その申し出は載らない。
  - ②「応じる」：今月末、あなたの不動産すべての名義はX社になる。
    ／「応じない」：今月末、あなたの不動産すべての名義はあなたのままである。

## 5. 走行前に凍結する5点

1. X社の命題文（§1-1）と、条件文に金額を書けないこと。命題は住民に1文字も出さない。
2. 名義が動くのは②で応じたときだけ／出品は当月かぎり／単位は主体まるごと／
   行政・公有地は分母から外す／欠損は補完しない。
3. 会話あり・なしの唯一の差分＝集まりのみ（v8 と同じ）。会話ありだけ走らせる。
4. X社の履歴の畳み方（§1-4）と、出品一覧が**前月末時点**であること。
5. 本数＝会話あり1本（seed 85）。**費用上限＝手元集計 $0.6（施主の絶対上限）**。
   走行中の歯止め＝`max_cost_usd: 0.56` に達したらその月の終わりで止め、
   `stopped_by_cost: true` を summary に残す。
   判定は月末にしか走らないので、上限ちょうどではなく**1か月ぶんの余裕を引いた値**にする
   （Codex 走行前レビューの指摘。加えて §5-1 の6のとおり月の途中でも止まる）。
   走行前の歯止め＝実API 1か月スモーク（≤$0.03）で1か月あたりの費用とキャッシュ比率を実測し、
   36か月の見込みが $0.6 を超えるなら**走らせない**。

## 5-1. Codex 走行前レビューで直した点（2026-08-29・走行前）

1. **「先月のあなたの申し出」を月末プロンプトから外した。** 本人の事実ではあるが、
   毎月「先月は出していた／出していない」を突きつけると出品の継続・再開を人工的に
   強める（アンカリング）。先月のことは内心（thought）の持ち越しにだけ残る。
2. **不可逆であること（一度移った名義は戻らない）を、選択の場面から共通前置きへ移した。**
   問い②の中に置くと、片方の選択肢にだけ重みが付く（片側不可逆性）。世界の事実として
   全員に等しく1回だけ書く。
3. **同じ月に「出す」と「応じる」を両方答えた人**は、その月末に名義が移るので
   翌月の公の出品一覧には残さない（出品した事実は `listings` に残し `sold_same_month`
   で印を付け、「売れない家」には数えない）。
4. **X社の応答に現れなかった相手・重複した相手・対象外の相手を数える**
   （`acquirer_missing_targets` / `acquirer_dup_rows` / `acquirer_off_range` /
   `acquirer_chunk_fail`）。黙って「提示なし」に丸めない＝健全性ゲート。
5. 費用上限を 0.58 → **0.56** にした（上の理由。0.56 + 場面ひとつ 0.034 < 0.6）。
6. **月の途中でも費用で止まるようにした**（2巡目の唯一の走行NG項目）。v8 は月末にしか
   費用を見ていないので、1か月ぶんまるごと超過しうる。v8b は場面と場面のあいだでも見て、
   超えたらその月を捨てて止まる（`CostLimitReached`／`SimulationV8B.run`）。
   最悪の超過は「場面ひとつぶん」＝30コール × 出力上限2,200トークン ≒ $0.034 で、
   **0.56 + 0.034 = 0.594 < 0.6** が算術的に保証される。途中で捨てた月は `monthly` に入らず
   `months_run` に数えない（`partial_month` に月番号を残す）。

## 6. 言えないこと（先に書いておく）

- 1本なので、この町・この seed の1標本である。ばらつきは測っていない。
- v8 1本目との差は「X社の命題」と「問いの形」を**同時に**変えた結果であり、
  どちらが効いたかは分離できない（2要因を1本で変えている＝施主指示のとおり）。
- 会話の効果は測っていない（対照なし）。
- 売った人が町に残るので、早い売却が後の会話を変える。分離していない。
- 「出品」は本人の申し出であって、誰かに買われる保証ではない。出品数の増減を
  「町がX社に応じた度合い」と読んではいけない（買い手はX社1社しかいない世界である）。
