## 0. 何を変えたのか（2つだけ）

1. **町の人に届く手紙の冒頭に、世界が必ず1行を添える。**

```
私どもは、この街の不動産の過半の取得を目指しています。
```

   - **X社の自由文ではない。世界が付ける事実行**である。
   - **毎通・全員に同じ文**が付く（LLM の裁量はない・出す/出さないも選べない）。
   - 位置は自己紹介「私どもは海外の不動産投資会社です。」の**直後**、
     X社が書いた条件文の**前**。X社の条件文は言い換えない（v9 以来の規律）。
2. **X社の設定文に整合のための事実を1行足す**（行動の指示ではない）。

```
あなたが出すすべての提示には、冒頭に「私どもは、この街の不動産の過半の取得を目指しています。」
という1行が必ず添えられて相手に届く。あなたはこの目標を町に公言している。
```

世界の側はほかに何も変えない＝町の人のプロンプト・名簿（`configs/personas_v9c.yaml`）・
44区画・格子・会話・出品4択・売る/売らない・借家人の「今月A市を出るか」・
家主と借り手の一言・門番3種・評価額の表・**資金51%（11億7,180万円）**・
月内に配る提示の合計の規則・面積／取得割合／残り月数の事実行・
**v9f の命題**（できるだけ多く／面積は過半／買えるまで条件を変えて働きかけ続けろ／
余らせるより高く買え）・36か月・`gemini-2.5-flash-lite`・temperature 0.75。

```

規模の語       過半／街全体／町ごと／支配／乗っ取
意図を疑う断り  上のうち 買い占め・警戒・意図・危機・支配・乗っ取 を断りの理由に含むもの
集団的な言葉    自治会／申し合わせ／みんなで断／住民同士／協力して
```
