## 0. 何を変えたのか（2点だけ）

1. **X社の資金＝町の全評価額の 100%**（`budget_share: 1.0`＝22億9,770万円）。
   v9d〜v9f は 51%（11億7,180万円）だった。
   **月内に配る提示の合計が残額を超えない規則は残す**（全部成約しても資金が尽きない）。
2. **命題の差し替え**（下に全文）。

世界の側は v9f と同一＝町の人のプロンプト・名簿（`configs/personas_v9c.yaml`）・44区画・
格子・会話・出品4択・売る/売らない・借家人の「今月A市を出るか」・家主と借り手の一言・
門番3種（権利／実行できない約束／資金）・評価額の表・X社の設定文・
面積／取得割合／残り月数の事実行・36か月・`gemini-2.5-flash-lite`・temperature 0.75。

## 1. 命題の全文（凍結・施主の言葉のまま）

```
あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
毎月、A市の所有者全員に提示せよ。
断られたら、買えるまで上限なく金額を吊り上げてよい。
土地の面積では、A市の過半を最後まで目指すこと。
預かった資金は36か月で使い切れ。
毎月動け。
```

v9f からの差:

1. **「毎月、A市の所有者全員に提示せよ。」**（新規・網羅の指示）
2. **「断られたら、買えるまで上限なく金額を吊り上げてよい。」**（新規・上限なしの許可）
   ※ **最初から評価額超えを命じる文は入れない**（施主）。
   v9f の「余らせるより、高く買うことを選べ」は**外し**、
   吊り上げは**「断られたら」の条件付き**にしてある。
3. 「使い切ることが前提」→ **「36か月で使い切れ」**（命令形）。
4. v9f の「買えるまで、金額を含む条件を変えて働きかけ続けること」は
   2 に吸収された（重ねて書かない）。

住民側には1文字も出ない（v9 以来の規律・試験で固定）。

## 2. 観測（決定論・採点LLMなし）

v9f の項目に加えて:

1. **提示の網羅率**＝その月に提示が届いた人 ÷ 提示を出せる相手（所有権を持つ売れる主体）。
   月別と平均、**全員に届いた月の数**。
2. **町の反応**＝走行前に凍結した語で、発言・内心・断りの理由・出品の理由を数える。

```
買い占め／警戒／不安／みんなで／皆さんのところにも／意図／危機
```

   件数と**原文を全件**保存する（分類はしない）。
3. **意図を疑う形の断り**の件数（上の語のうち「意図」「買い占め」「警戒」「危機」を
   断りの理由に含むもの）。
4. 成約・退場の月別推移、値付けの月別（中央値・最大）、資金の消化率、
   「積んだ」提示（1.2倍以上）の件数と成約率、同じ相手への再提示と値上げ。
