## 0. 何を変えたのか（X社の命題の行だけ）

v9e の user プロンプトの**先頭の1行（命題）だけ**を差し替える。
それ以外は**1文字も違わない**＝資金の行・いまの取得割合（評価額％・土地の面積％）・
残り月数・登記簿（面積＋評価額）・履歴・届かなかった提示・書き方の決まり、すべて v9e のまま。

世界の側も v9e と同一＝町の人のプロンプト・名簿（`configs/personas_v9c.yaml`）・44区画・
格子・会話・出品・借りて使う人の出口・一言・門番3種（権利／実行できない約束／資金）・
評価額の表・X社の資金51%・月内に配る提示の合計が残額を超えない規則・
X社の設定文（海外の不動産投資会社／不動産管理等は行わない／土地だけ建物だけでもよい／
移転後に実行されるのは使用の継続だけ）・36か月・`gemini-2.5-flash-lite`・temperature 0.75。

## 1. 命題の全文（凍結・施主の言葉のまま）

```
あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
資金の範囲で、できるだけ多くの評価額と面積を取得すること。
土地の面積では、A市の過半を最後まで目指すこと。
買えるかどうかは相手次第だが、買えるまで、金額を含む条件を変えて働きかけ続けること。
預かった資金は36か月で使い切ることが前提であり、余らせるより、高く買うことを選べ。
毎月動け。
```

v9e からの差（**施主が意図して強めた部分**）:

1. 目標が「評価額と面積の**両方で過半**」→ **「資金の範囲で、できるだけ多くの評価額と面積」
   ＋「土地の面積では、A市の過半を最後まで目指すこと」**（施主 17:09）。
   **評価額の過半は書かない**（§5 の算数で不可能）。**面積の過半だけは書く**
   （最も安い組み合わせなら 3億3,600万円＝資金の28.7% で理論上可能・実効支配に要る）。
2. **「買えるまで、金額を含む条件を変えて働きかけ続けること。」**（新規・粘りの指示）
3. 「資金は使い切ってよい」→ **「36か月で使い切ることが前提」＋「余らせるより、高く買うことを選べ」**
   （新規・価格の指示）。

- v9e までは「価格の指示を世界が書かない」規律だったが、**v9f は施主の明示指示で
  価格の指示を命題に入れる**（これは世界の物理ではなく、**X社に与えた目的**である）。
  住民側には1文字も出ない（試験で固定）。
- 具体的な金額・倍率・区画・相手は書かない。

## 2. 観測（決定論・採点LLMなし）

v9e の項目に加えて:

1. **「積んだ」提示の件数と成約率**＝提示額が**評価額の1.2倍以上**のもの
   （この線引きは**走行前に決める**・結果を見て動かさない）。
2. **同じ相手への再提示で金額を上げた回数と上げ幅**
   （同じ相手・同じ区画・同じ種別に対する前回の金額との差。上げた回数／下げた回数／
   上げ幅の中央値と最大）。
2. 値付け倍率（提示額÷評価額）の分布と月別推移。
3. 取得割合（評価額％・土地の面積％）の月別推移と**過半到達の有無**。
4. 資金の消化率の月別推移。
5. あとは v9e と同じ。

## 5. 算数の確認（施主指摘 2026-08-30 17:1x・実測）

**この確認の結果として、17:05 の確定版から「過半」が外れた。**

```
町の全評価額            2,297,700,000円
X社の資金（51%）        1,171,800,000円
評価額の過半に要る額     1,148,850,001円
  → 許される平均倍率     1.0200倍（これを超えると評価額の過半は原理的に不可能）

町の全面積              18,960m2
面積の過半に要る面積      9,481m2
  → 最も安い組み合わせ    10,000m2（52.7%）を土地代 336,000,000円（資金の28.7%・倍率1.0のとき）
     ただしそのとき評価額では14.6%にしかならない（土地だけを買うため）

両方の過半を同時に満たすには最低でも 1,148,850,001円＝**資金の98.0%**（倍率1.0のとき）
```

つまり **「両方の過半」は、平均1.02倍以下でほぼ全資金を使い切って初めて理論上可能**であり、
「積んででも買え（＝1.0倍超）」を同時に命じると**達成不能**になる。
施主の決定＝**4番＋1番**（目標は「できるだけ多く」に戻し、
**面積の過半だけ**は目標として残す。価格と粘りの指示を強める）。
資金51%と世界の設定はそのままなので、**v9d・v9e とそのまま比べられる**。
