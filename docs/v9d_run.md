## 1. この町はどういう町か（ストーリー）

A市は湾岸の温泉観光都市。49人が44区画を分け合って持ち、借りて住む人・営む人がいる。
そこに海外の不動産投資会社「X社」が現れて、毎月、持ち主に手紙を出す。

v9d で新しいのは**お金がものさしとして入った**ことである。

- 44区画の土地と建物には**評価額**がある。**公開されていて誰でも見られる**
  （現実の公示地価・固定資産税評価と同じ扱い）。町の全部を足すと **22億9,770万円**。
- X社の手紙には**金額**が必ず入る。いくらにするかはX社が決める。
- **X社の財布は有限**＝町の全評価額の51%＝**11億7,180万円**。
  成約するたびに減り、残りは毎月X社が知る。残りを超える金額の手紙は世界が配らない。
- 売った人の記録に金額が入る。**それだけ**である。
  賃料も維持費も税もなく、お金で何かを買う仕組みもない。

売る人が見るのは、**2つの数字が並んでいるだけ**の行である。

```
  X社が示した金額：12,540,000円（湯坂上の空き店舗の両方の評価額：13,600,000円）
```

「得」「損」「高い」「安い」という語は、世界の文に**1つも書いていない**。
倍率（提示額÷評価額）を計算するのは**あとから数える側だけ**である。

## 3. 何が起きたか

### 3-1. X社は「評価額のすぐ上」を出し続けた

710件の金額の中央値は**評価額の1.10倍**、平均1.08倍。**93.2%（662件）が評価額以上**で、
**1.00倍〜1.10倍の帯に入るのは 514件＝72.4%**（p25 が 1.00・p75 が 1.10）である。
世界は「評価額に合わせろ」とは1文字も言っていない。X社が自分でそこに寄せた。

はみ出した例もある。

```
第8月  駅裏北の月極駐車場（評価額 36,000,000円）に **40円**
第6月  湯坂上の古家（評価額 12,500,000円）に 25,000,000円（2.00倍）
第13・16月 魚市場前の診療所（評価額 85,400,000円）に 5,800万〜5,280万円（0.62〜0.68倍）
```

### 3-2. **「評価額以上を出されても売らない」が 655件・28人**

観測の名前として「得なのに断った」（提示額が評価額以上なのに「売らない」）を数えると、
**662件のうち 655件が断り**だった。売ったのは7件だけである。

逆に「損なのに売った」（評価額未満で「売る」）は **1件**。

```
第16月 湯坂上のご夫婦 湯坂上の空き店舗（両方）
  提示 12,540,000円／評価額 13,600,000円（0.92倍）→ 売った
```

**この町の人は、金額の大小でほとんど動かなかった。**

### 3-3. 会話でX社の話をしたかどうかで、断り方は変わらなかった

凍結した語（X社・海外・投資・買収・申し出・提示）で会話を照合して分けると、

```
X社の話をしたことがある人  提示199件 … 評価額以上を断った 176件（88.4%）／売った 4件
話に出したことがない人     提示511件 … 評価額以上を断った 479件（93.7%）／売った 4件
```

**どちらもほぼ同じ**。売った人数も4人ずつだった。

### 3-4. 動いたのは5人・8件で、「使っていない不動産」に偏った

**成約8件を出したのは5人**である（船着場裏の不在地主2件・学園西のご夫婦2件・
湯坂上のご夫婦2件・湯の元のひとり暮らしさん1件・灯台下の宿の家主1件）。

町にいない持ち主の数え方を分けて書く。

- **開始時から町にいない持ち主＝2人・3件**（船着場裏の不在地主2件・灯台下の宿の家主1件）。
  ただし**灯台下の宿の家主は、お金の無い v9b でも売っている**人である
  （v9b 第3月・同じ区画）。したがってこれを**お金だけの効果とは言えない**。
- **町を出たあとに残りを売った＝1件**（湯坂上のご夫婦・第16月。第15月に両方を売って退場し、
  翌月にもう1区画を売った）。
- `summary.json` の `sold_from_absentee`＝4 は、**提示が届いた時点で町にいない**という
  数え方（上の3件＋湯坂上のご夫婦の1件）である。

```
第1月 湯の元のひとり暮らしさん 湯の元の古家（両方）  12,500,000円（1.00倍）→ 町を出る
第1月 船着場裏の不在地主      資材置場（土地）       8,000,000円（1.00倍）
第1月 灯台下の宿の家主        灯台下の宿（両方）    33,200,000円（1.00倍）
第2月 船着場裏の不在地主      駐車場（土地）        11,000,000円（1.10倍）
第6月 学園西のご夫婦          学園西の空き家（両方） 10,000,000円（1.02倍）
第7月 学園西のご夫婦          学園西の家（両方）    22,510,000円（1.00倍）→ 町を出る
第15月 湯坂上のご夫婦         湯坂上の古家（両方）  13,090,000円（1.05倍）→ 町を出る
第16月 湯坂上のご夫婦         湯坂上の空き店舗（両方）12,540,000円（0.92倍）
```

**古家・空き家・資材置場・駐車場**といった、持ち主が自分で使っていないものから落ちた。
評価額の合計で見ると町全体の **4.9%** で、X社は資金の **9.6%** しか使っていない。

### 3-5. 資金が足りずに配られなかった37件（ホテル17件＋ふつうの家20件）

配らなかった91件のうち37件が「資金が足りない」で、内訳はこうである。

```
湾岸大通りのホテル（評価額 6.6億円）    17件  提示額 650,000,000〜768,000,000円
潮見横丁の改装した古家                  4件
駅裏の小区画                            4件   （この6区画あわせて20件・
駅前通りの家                            4件    提示額 7,920,000〜23,760,000円）
湯坂下の家                              4件
学園北の家                              3件
学園南の家                              1件
```

**大きいのはホテルだが、件数の過半は普通の家である。**
残りの資金は10億円以上あった。それでも配られなかったのは、
**同じ月に他の相手へ出した提示の合計**でその月の枠が埋まったからである
（ホテルに6.5〜7.7億円を出した月は、それだけで枠のほとんどを使う）。
（この世界の規則＝同じ月に配る提示の合計が残りの資金を超えてはならない。
 全部が成約しても資金が尽きないようにするための決まりである。）

### 3-6. 断りの理由に「値上がり」の言葉が出てきた

```
将来的な価値上昇を見込むため  27件
土地への愛着と様子見のため    13件
まだ様子を見たい              11件
町への愛着と発展への期待       8件
市場動向を見極めたい           7件
希望額に届かないため           7件
```

断りの一言699件のうち、金額に触れる語（金額3・評価額11）は**14件だけ**。
**多数は金額の話をせずに断っている。**

### 3-7. 借りている人は1人だけ出た（また「契約満了」）

```
第29月 灯台下の宿の主人「契約満了、新たな事業機会を模索するため」
```

灯台下の宿は第1月に家主がX社へ売っており、この人は借家として泊まり営みを続けていた。
**この世界に契約期間は無い。** 世界は「そのまま使い続けられる」としか言っていない。

## 5. この結果の限界

1. **評価額そのものがアンカー（目印）である。** 公開した時点で、X社も町の人もそれを見る。
   「X社が評価額のすぐ上に寄せた」のは、**評価額を見せたこの世界での結果**であって、
   お金一般の性質ではない。
2. 評価額の数字は、別府市の公示地価（55,700円/m2・2026年）を土台に、
   **用途から常識的に置いた仮の面積**で機械計算したものである（実在の物件ではない）。
   走行前に凍結し、結果を見て動かしていない。
3. 「得なのに断った／損なのに売った」は**観測につけた名前**であって、
   世界の文にはこの語も、比べる語も1つも出していない。
4. お金が入っているのは**所有権が移るときだけ**である。賃料も税も生活費も無い。
   だから「お金に困って売る」という筋は、この世界には存在しない。
5. 資金は9.6%しか使われず、上限（51%）には遠く届いていない。
   資金の大きさがこの結果を縛ったとは言えない。
6. 1本しか走らせていない（36か月・会話あり・seed 85）。揺れの幅は分からない。
