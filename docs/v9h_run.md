## 1. 何を変えたのか（1行だけ）

町も人も評価額も財布（11億7,180万円＝町の51%）も命題も v9f と同じ。
変えたのは、**町の人に届く手紙の冒頭に世界が必ず1行を添える**ことだけである。

```
X社から（湯坂上の古家 の 両方 について）：
「私どもは海外の不動産投資会社です。私どもは、この街の不動産の過半の取得を目指しています。
  <X社が書いた条件文>」
```

この1行は**X社の自由文ではない**。世界が付ける事実行で、**毎通・全員に同じ**。
実測＝**届いた1,077通すべてに入っている**（1,077 / 1,077）。

## 3. 何が起きたか

### 3-1. **町が「過半」という言葉を持った**

走行前に凍結した語で数えると、v9 系列で初めて**まとまった数**が出た。

```
                発言    内心    断りの理由   出品の理由
過半             2      34       **61**        14
街全体           5      29        12            4
支配             5       9         0            0
買い占め         3       4         0            0
意図             0      31       **58**         3
警戒             0       9         5            0
不安             0       7         0           17
自治会          14      63       **33**         0
```

**「意図を疑う形の断り」は 58件**（v9f を同じ語で数え直すと **1件**だった）。

※ この表の「支配」「自治会」は**役名にも当たる**（「湾岸大通りのホテルの支配人」
「神明社の自治会長」）。役名を外して数えると v9h の「支配」は発言5・内心9・断り0、
「自治会」は役名を除くとほぼ残らない。**役名を含む生の数字**が上の表で、
外した数字は `docs/v9h_diff_from_v9f.md` にある。

### 3-2. 断りの理由の1位が「X社の意図」になった


第2月から出ている。

```

第3月 同「過半取得の意図が不明瞭なため」
```

### 3-3. 町の会話に「街ごと買われる」話が出た

```

  「皆様、X社から集会所と境内地の件で条件が届いています。評価額通りの金額ですが、
    街全体への影響を考えると、一旦『売らない』と回答し、現状維持としたいと考えています」

第4月・魚市場前の診療所の院長（場での発言）

    特に、特定の事業者が市内不動産の過半を取得した場合の…」

第17月・波止場通りのご夫婦（場での発言）
  「X社からの買収提案、気になりますね。街全体の取得を目指しているとか。」
```

**自分の損得ではなく「街全体」と「制度」の話が、公の場で出た。**

## 5. この結果の限界

1. **1本である。** 成約3件・退場4人は1桁で、揺れと区別できない。
2. 反応語の件数は**発言・内心・断り・出品理由を分けて数えている**が、
   **内心は誰にも伝わらない**。合計を「町で共有された危機感」と読んではいけない
   （走行前レビューの指摘）。同じ人の反復も、否定文もヒットする。
3. 「過半」「意図」は**世界が配った文言そのもの**である。
   町の人がその語を使うのは**手紙の言葉を借りている**面があり、
   ゼロから危機感が生まれたのとは違う。
4. 明言の1行は世界が強制的に配っている（X社が言うかどうかを選べない）。
   これは**実験のための介入**であって、買い手の自発的な行動ではない。
