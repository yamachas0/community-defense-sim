## 2. 借りて使っている人の「出る／出ない」

### 誰に聞くか

**他人の不動産を借りて使っていて、自分は何の所有権も持っていない、町にいる人**（開始時10人）。
＝借家で住む・営む人9人と、土地だけを借りて使っている駐車場の会社1社。
この10人は v9b では月末に何も聞かれていなかった（売る物を持たないため）。

会社（駐車場の会社）も同じ扱いにする＝この世界で「A市を出る」とは
**その区画を使うのをやめて町からいなくなること**である。

### 聞き方（促し文を置かない）

```
[今月末の問い]
今月、A市を出るかどうかを決める。
leave に「出る」「出ない」のいずれかを書く。
  「出る」：今月末、あなたは<区画名>を使うのをやめ、A市を出る。以後この町にはいない。
  「出ない」：今月末、あなたは<区画名>を今までどおり使い、A市にとどまる。
leave_reason には、その理由を一行で書く（60字以内・書かない場合は空文字）。
この理由は誰にも伝わらない。
```

- 2肢の並びは主体×月で決定論的に入れ替える（v9b の `sell_order` と同じ規則）。
- 答えが返らなかったときに「出ない」で埋めることはしない＝`no_answer` として数える
  （世界は何もしないので、結果としてその人はとどまる）。
- 促し文・兆候・確率・閾値は1つも置かない。

### 出たあとに何が起きるか

- その人は退場する。以後、行き先・場での会話・隣近所・この問いのどれにも現れない。
- **その区画を使う人はいなくなる**（家主が自動で使い始めることはない）。
- 名簿（住民の共通前置き）のその人の行の末尾に「（転出）」が付く。
  ※ v9 は「名簿は開始時点の記録なので書き換えない」としていたが、
  施主指示 13:23 によりここだけ変える。**売って町を出た人にも同じ印を付ける**（扱いを揃える）。
- 家主（その区画の建物の所有者。建物が無ければ土地の所有者）に、**翌月初に事実1行**が届く。
  所有権が移ったときの通知と同じ仕組み・同じ文体である（感想・評価・指示を付けない）。

```
（記録）先月末、<区画名>を借りて使っていた <呼び名> がA市を出た。この区画を使う人はいない。
```

## 3. 借りて使っている人と家主の一言（月1回・任意）

- 借りて使っている人は、月末の問いのときに、**自分の家主あてに一言**を書ける
  （`to_landlord`・空文字でよい・60字以内）。
- 家主は、翌月の月末の問いのときに、その一言を読み、**返事の一言**を書ける
  （`to_tenant`・空文字でよい・60字以内）。返事は翌月、借りている人に届く。
- **世界は中身を検証しない。配るだけである**（言い換え・要約・判定をしない）。
- 家主が町にいない所有者であれば、その月次コールに届く（会話の場には出ない）。
- **X社にはこの一言は見えない**（登記簿にも履歴にも入らない・試験で固定する）。
- 書く欄があるだけで、書くことを促す文は置かない。

## 4. 経過した時間（全員同じ扱い）

毎月の user プロンプトの冒頭に、次の1行を置く。

```
（第7月・開始から6か月・あなたは74歳）
```

- 年齢＝**名簿に書かれている開始時の年齢 ＋ 経過年（(N-1)//12）**。
- **名簿に年齢が書かれていない主体には年齢を書かない**（会社と、年齢の記載が無い個人）。
  ここで年齢を作り出すことはしない（凍結した名簿に無い事実を足さないため）。
  その場合は `（第7月・開始から6か月）` だけになる。
- X社にも同じ1行を置く（会社なので年齢は無い）。X社の命題の行はそのまま先頭に残し、
  その次の行に置く。
- 行き先・場での会話・月末の問い・X社の月次のすべてに置く。
