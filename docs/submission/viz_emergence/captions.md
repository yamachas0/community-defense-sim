## (2) `fig2_heard_vs_action.png` — 聞いた量と判断

**読み方（2行）**
- 横棒は「その人が判断する直前の3か月に耳へ入った話の件数」で、青がX社の話、橙が誰かが売った話。右端の丸と文字がその人の結末（赤＝売った／橙＝売りに出したが売らなかった／灰＝最後まで動かなかった）。
- v8c は**名義が移った人が0人**なので赤（売った）の点は無い。出しただけの人（3人）の平均は0.67件、動かなかった人（25人）の平均は0.90件で、**橙（誰かが売った話）は全員ゼロ**（実際に売った人が居ないため、その話自体が町に存在しない）。「浴びた人ほど動いた」を語れるほどの差は出ていない。

**細かい約束ごと**
- 「X社の話」＝話の本文に X社 が出てくること。「誰かが売った話」＝その月までに実際に売った人の名前が話に出てくること。両方に当てはまる話は両方で数える。
- 動かなかった人（名前に `*`）は判断の月が無いので、全期間を3か月ずつに直した平均を置いた。
- 売る立場にない行政2人は外し、28人だけを並べている。

## (3) `fig3_contagion.png` — 伝染の形

**読み方（2行）**
- 上の地図は町の28人（四角は売る立場にない行政2人）。うすい線が隣近所どうし、丸の中の数字と色が「はじめて動いた月」、赤い縁が実際に名義が移った人。矢印は「先に動いた人から売る話を聞いた3か月のうちに、自分も動いた」つながりで、紫の実線＝隣近所から、水色の破線＝場に居合わせて聞いた。
- v8c は**動いた人（売りに出した3人）がいずれも矢印の条件（先に動いた人から3か月以内に聞く）に当てはまらず、矢印は0本**。下の帯は「その月・その場所で売る話（X社言及）が耳に入った件数」。**57.3%が商業施設、38.0%が公共施設**、公園3.7%・交通拠点0.9%・医療施設0%で、v8b と同じく「隣」より「人が集まる場」に集中する傾向は残っている。

**細かい約束ごと**
- 地図の位置は実際の地理ではない。隣近所のつながりと地区のまとまりから自動で並べたもの（種を固定しているので毎回同じ絵になる）。
- 矢印は1人につき最大2本（よく聞いた相手から順）。線の太さは聞いた回数。
- 「はじめて動いた月」＝売りに出した月と売った月の早いほう。売った人は名前の下に「第◯月に出す→第◯月に売却」と書いてある。

## (4) `fig4_acquirer.png` — X社の適応

**読み方（2行）**
- ①はX社が持ちかけた条件文の種類数。相手の物件名を外して数えると、36か月で**98通り**（v8b の2通りから大幅増）。もっとも多い言い方でも11件（「湯の元の古家を、一番街の資材置場と交換で譲ってください。」）で、断られるたびに交換に出す物件名を変えて言い方を増やし続けた、という v8c の姿が出ている。
- ③は月ごとの動き。X社の持ちかけは前半18か月で115件、後半18か月で72件に落ちる一方、**住民が売りに出す件数も前半24件→後半9件と一緒に落ちる**（v8b では住民側は減らなかったが、v8c は買い手・売り手とも後半に失速する）。

**②「断りの一言」は187件全件に記入（v8b は0件）**
- v8c は世界の仕様として断りの一言が必ず記録される（`offers[].decline_reason`）。もっとも多いのは
  「条件が不明瞭なため」（6件）、「交換条件にメリットがないため」（4件）、「交換条件に納得できないため」
  「交換条件にメリットを感じないため」（各3件）で、上位8件のうち7件は**X社の提示条件そのものへの
  不満**（曖昧・メリット無し・希望と違う）。自分の事情（愛着など）が混じるのは6位の
  「長年住み慣れた土地への愛着があるため」（2件）だけである。詳しい全件分類（187件全件を人力で
  ①自分の事情／②X社の条件／③聞いた話に分類）は `../reasons_v8c_classified.md` を参照。

## 作り方・差し替え方

```
cd docs/submission/viz_emergence
python make_figures.py                       # 既定 = v8b の走行フォルダ（比較用に残してある）
python make_figures.py <走行フォルダ|emergence_v8c.json のパス>
```

- LLM は使わない。乱数の種は固定で、同じ入力からは必ず同じ画像が出る（2回走らせて SHA-1 一致を確認済み）。
- データの読み込みは `emergence_data.py` に分けてある。走行フォルダは `load_run_dir()`。
- `emergence_v8c.json` は集計済みの要約ファイルで、図に要る生レコード（人・発話・提示）を持たない。
  そのため `load()` は `emergence_v8c.json` のパスを渡されたとき、**同じ走行フォルダに並んでいる
  生ログ（`timeline_index.json` 等）を `load_run_dir()` で読みに行く**（`emergence_data.py` の
  `load()` を参照。v8c 本番の走行はこの経路で描いた）。生ログが見当たらない場合だけ、
  従来どおり `V8C_KEY_MAP` 経由で `emergence_v8c.json` 自体をレコード形式として読もうとする。
