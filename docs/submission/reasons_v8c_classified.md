# 「売る／売らない、出す／出さない」理由の分類（v8c・36か月・全件人力読み）

走行データ＝`simulations/2026-08-30_0111_104_v8c_reasons_chat_A/`（`decisions.json` / `offers.json` /
`utterances.json` / `listings.json` / `emergence_v8c.json`）。**この文書の分類は判定用LLMを1本も使わず、
作業者本人が原文を全件読んで手作業で付けたもの**である。`emergence_v8c.json` の
`reason_candidates` は語句照合による粗い「候補」に過ぎず（同ファイルに明記あり）、この文書の分類が
それに代わる確定版になる。

**分類基準（(a)(b)共通）**　理由の原文を読み、①**自分の事情**＝愛着・生活・家族（介護・進学・相談）・
商売（経営継続・後継者・組合や自治会の存続）など、書き手側の事情に基づく理由、②**X社の条件**＝
条件が不明確・具体的でない・交換が成立しない（相手が所有していない物件が対価に含まれる等）・
メリットがない・信用できない・交換の存在そのものに触れているなど、**相手（X社）の提示内容そのもの**
についての理由、③**聞いた話**＝他人の発言・噂・隣近所の様子を根拠に挙げている理由、の3つに分け、
①②の両方に触れている一文は**複合**とした。①②③のどれとも判定しがたい極めて短い言い回し
（例：「検討中のため」「現状維持」）は、原文に「条件」「交換」「X社」等の明示がなければ①（自分の
事情の一形態＝迷い・様子見という自分の姿勢）に寄せた。この寄せ方自体が主観であることは
末尾の「言えないこと」に明記する。

## (b) 「売りに出す／出さない」理由

同じ3分類（+複合）で数えた。`listing_reason` は書かなくてもよい欄なので、記入率は
「出す」100%（33/33）・「出さない」48.9%（477/975、残る498件は無記入）。**無記入は
分類のしようがないため対象外**（この点は(a)の断り一言＝記入率100%と条件が違う）。

### 出す — 33件（実人数3人：観音坂の持ち主さん・駅裏の持ち主さん・灯台下の宿の主人）

- **①自分の事情＝22件（66.7%）**（多くは「将来的な売却の可能性を探るため」「市場の反応を見るため」
  「空き地の売却を検討するため」等、自分の意向・経営判断）
- **②X社の条件＝10件（30.3%）**（「X社からの交換の申し出があったため」等、X社の申し出そのものが
  出品のきっかけと書かれている）
- **複合＝1件（3.0%）**（「交換条件とは別に、売却の意思表示のため」）
- **③聞いた話＝0件（0.0%）**

### 出さない — 477件（実人数28人）

- **①自分の事情＝341件（71.5%）**（「現状維持で問題ないため」「家族との時間を大切にしたいから」
  「組合の方針を優先するため」等）
- **②X社の条件＝131件（27.5%）**（「交換条件に納得できないため」「条件が不明確なため」等）
- **複合＝5件（1.0%）**（例：「組合の存続とX社の動向を警戒するため」「近隣の売却状況とX社の
  動向を注視したい」）
- **③聞いた話＝0件（0.0%）**（複合の1件を除き、単独カテゴリとしての「聞いた話」はゼロ）

**(a)(b)共通の所見**：187+510=697件の理由を通読して、**「誰かに聞いたから」を単独の理由として
書いた例は実質ゼロ**（複合の中に2件だけ、それも「X社の動向」を注視する文脈での言及）。断り・
出品どちらの理由も、書き手は「相手（X社）の条件」か「自分の事情」のどちらかで語っており、
噂や隣人の発言を根拠に挙げる書き方はほぼ選ばれていない。

## (e) 伝染 — `emergence_v8c.json` の値をそのまま引用

### heard_before_decision（判断の前3か月に聞いた話の量、window_months=3）

```
"売った":       {"n": 0,   "heard_mean": 0.0,  "heard_about_x_mean": 0.0,  "share_with_any_x_talk": 0.0}
"出した":       {"n": 33,  "heard_mean": 5.24, "heard_about_x_mean": 2.18, "share_with_any_x_talk": 0.8485}
"どちらもしない": {"n": 975, "heard_mean": 4.98, "heard_about_x_mean": 1.51, "share_with_any_x_talk": 0.5036}
```

- **売った n=0**：実際に名義を売った人が1人もいないので、「売った人が事前にどれだけ聞いていたか」は
  そもそも測る対象が無い（分母ゼロ）。
- **出した n=33（実人数3人）**：出品を決めた月の直前3か月に、平均5.24件の話を聞いており、そのうち
  X社がらみの話は平均2.18件。84.85%の月でX社の話を1件以上聞いていた。
- **どちらもしない n=975**：直前3か月の平均は4.98件（X社がらみ1.51件）、X社の話を1件以上
  聞いていた月は50.36%。
- 出品した月のほうが「聞いていた割合」（84.9% vs 50.4%）は高いが、**出品したのは実人数3人だけ**
  なので、この差を町全体に一般化はできない。

### contagion（伝染の形、window_months=3）

```
"events": [], "exposed_agents": 0, "exposed_acted_share": 0.0,
"not_exposed_agents": 28, "not_exposed_acted_share": 0.1071,
"note": "「触れた人」＝売った人の隣人 or 売った月に同席した人。相関であって因果ではない"
```

- **events=[]**：実際に売った人が0人なので、「売った人の話を聞いて、その後動いた」という具体的な
  連鎖は1件も記録されなかった。
- **exposed_agents=0**：「売った人の隣人、または売った月に同じ場に居合わせた人」に該当する人は
  0人（売った人がいない以上、当然ゼロ）。
- **not_exposed_agents=28 / not_exposed_acted_share=0.1071**：売った人に触れていない28人の
  うち10.71%（≈3人）が、期間中に「出す」か「売る」を選んだ。これは(b)出す＝実人数3人と符合する。
- 結論：**「伝染」を測ろうにも、売った人が0人なので測る対象自体が存在しない。** 出品（listing）に
  ついては「聞いていた割合が高い」という弱い傾向はあるが、これは相関であって因果ではない
  （contagionのnoteにも明記あり）。

## 言えないこと（3行）

1. **この分類は1本の走行を、作業者本人が読んで付けた主観の産物である。** 「①自分の事情」
   「②X社の条件」の線引き（特に「現状維持のため」のような短い言い回しをどちらに寄せるか）は
   別の読み手が読めば変わりうる。機械的な語句照合（`emergence_v8c.json` の候補集計）とも
   数字が大きく異なる（例：出す/出さない510件で機械候補は①140件だが本分類は①363件）。
2. **書かれた理由と本当の動機が一致する保証はない。** 「断りの一言」も「出品の理由」も、
   本人がその場で選んだ言い訳であって、その通りに考えて行動したかは原文からは証明できない。
3. **(c)(d)の件数は「言及した／しなかった」の集計であり、判断を変えたかどうかは別問題。**
   (e)の伝染データが示す通り、売った人が0人なので相関そのものが測れておらず、海外・X社への
   言及の多さと実際の取得（0件）を結びつける根拠はこの1本には無い。
