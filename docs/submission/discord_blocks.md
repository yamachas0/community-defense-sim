- 図：fig_two_worlds.png（3枚並びの全体＝2つの時計）
- 台詞：「違うのは1つだけ、中立な選択肢を3段置いたこと。『そうしなさい』とは1文字も書いていません。結果、7割が2割。×印が、売らないと決められていて買えなかった月です。68件。」

**⑤ いちばん正直な話**
- 最初の「当面売らない」は3本とも第1月。「同じ買い手だ」と公の場で言えたのは第3月と第12月（1本は最後まで無し）。
- 一斉蜂起でもない。月1〜2件が36か月続いただけ（51〜55件・のべ13〜16人）。解除した人もいる。
- 出てきた紙も普通。「相続・空き家の相談窓口を設置します」。同じ買い手を告発する紙は1枚も無い。
- 図：fig_quote.png（原文3枚）
- 台詞：「線が寝た理由は『気づいたから』ではありません。行動のほうが気づきより先に出ている。『今は売らない』と普通に言える窓口が、気づく前からそこにあった。」

**⑥ 言えないこと（先に言う）**
- 6本と3本の比較で、無作為化した比較ではない。傾向であって統計ではない。
- 足したのは選択肢だけでなく束（宣言が続く／全部の土地にかかる／紙が全員に配られる／買い手が買い直さない）。どれが効いたかは言えない。
- 「買えなかった68件」は予定が不成立になった数で、買い手が諦めた数ではない。
- 図：なし（文字だけ・大きめ）
- 台詞：「言えないことを先に言います。……それでも、選択肢を置いた世界と置かない世界で、こういう差が出た。ここまでが今日言えることです。」

**【A4一枚の要約】静かな占領 ── 見えていても、動く手が無ければ止まらない**

AIの町ひとつで、「気づき」と「行動」を別々に測った。48区画・住民26人が全員 言葉のAI。買い手は台本（買い手はAIを一度も使わない）。世界に置いた部品は3つだけ＝登記簿／買った後に街に残る痕跡／人が集まる場。同じ町を2通り走らせ、違いは中立な選択肢を3段置いたかどうかだけにした。

**図1枚：fig_two_worlds.png**
横軸＝月（1〜36）、縦軸＝買い手が押さえた土地の数。左＝経路なし6本／中＝経路あり3本／右＝毎月の問いかけをやめた2本。○＝気づいた、×＝買えなかった。

**一文の結論**
> 町の人に中立な行動の選択肢を3段置くだけで、買い手の線は寝た。ただし寝た理由は「同じ買い手だと気づいたから」ではない。

だから今回の答えは「気づかせる仕組み」より先に、普段の「今は売らない」が登記に効く経路を作れ、になる。これは条例やチラシを作る前に、どの仕組みが効くかを試せる装置である。

**限界（3行）**
- 6本と3本の比較で、無作為化した比較ではない。傾向であって統計ではない。
- 足したのは選択肢だけでなく束（宣言が続く／その人の全部の土地にかかる／紙が全員に配られる／買い手が買い直さない）。どれが効いたかは言えない。
- 止めることと、見抜くことは別。経路ありの世界では気づきがむしろ遅く・弱くなった（機序は未検証）。
