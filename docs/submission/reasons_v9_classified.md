# 「売る／売らない、出す／出さない」理由の分類（v9・36か月・全件人力読み）

走行データ＝`simulations/2026-08-30_1212_110_field_v9_land_and_building_chat/`（`offers.json`
＝X社の提示704件・`decisions.json`＝出品4択と区画ごとの理由・区画ごとの帳簿
`ledger_by_step.json`・`transfers.json`／`left_agents.json`／`notices.json`／`utterances.json`）。
集計は`docs/submission/emergence_v9.json`（決定論の語句照合・`reason_candidates`は粗い候補と
同ファイルに明記あり）と突き合わせた。**この文書の分類は判定用LLM（大規模言語モデル＝文章を
書くAI）を1本も使わず、作業者本人（Claude）が原文を全件読んで手作業で付けたもの**である。
分類そのものは自分で読んで決め、その決定を`tools/v9_reasons_count.py`内の辞書（原文→分類コード）
に書き起こして集計だけをスクリプトに任せた（キーワードで自動分類させたのではない）。件数・割合は
すべてこのスクリプトの出力と一致する。節構成・分類基準は`docs/submission/reasons_v8d_classified.md`
に合わせた（(a)〜(g)）。

**分類基準（v8dと同一）** 理由の原文を読み、①**自分の事情**＝愛着・生活・家族（介護・進学）・
商売（経営継続・後継者）・共有者や借家人への配慮など、書き手側の事情に基づく理由、②**X社の条件**
＝条件が不明確・具体的でない・支援や管理の中身が不明・メリットがない・信用できない・相手（X社）の
実態・真意・意図が不明である、対価や金額の記載がないなど、**相手（X社）の提示内容そのもの**に
ついての理由、③**聞いた話**＝他人の発言・噂を根拠に挙げている理由、の3つに分け、①②の両方に
触れている一文は**複合**とした。「時期尚早」「様子見」「まだ決められない」のような、①②③のどれ
とも判定しがたい極めて短い言い回しは、原文に「条件」「支援内容」「詳細」「相手」等X社の提示内容を
指す語の明示がなければ①（自分の事情の一形態＝迷い・様子見という自分の姿勢）に寄せた。この寄せ方
自体が主観であることは末尾の「言えないこと」に明記する。

**v9固有の追加ルール**：v9は土地と建物を分けたことで「売った後どうなるか」の帰結（借地・借家として
使い続けられる／両方売ると町を出る）が(a)(b)の理由文にも表れる。**自分がその区画に住み続ける・
使い続けることだけに触れている語**（「住み続けたい」「愛着」「自宅」「A市に住み続けられるため」
「借家人がいるため」「借り手がいるため」等）は①に、**相手の提示内容の確からしさに触れている語**
（「支援内容が不明瞭」「条件が不明確」「対価がない」「管理の実態が不明」等）は②に寄せた。また、
**地主が「建物所有者との関係を維持したい」と述べる借地特有の言い回し**は、X社の提示内容への疑義
ではなく既存の人間関係の維持という自分側の事情のため①に分類した（v8dには無い型）。

## (c)〜(e) X社の条件文の型・「海外」語・金銭系語

### (c) X社の条件文の型

X社の提示文704件のうち、**「支援」575件・「譲渡」570件・「維持」91件・「継続」86件・
「管理」80件・「改修」13件**。「対価」「金額」「価格」「費用」はいずれも**0件**（世界に金銭が
無いことを最後まで守っている）。これは`docs/v9_run.md`4-4節の数字と自分で数え直した結果が
完全に一致した（ズレなし）。

書き方の型は3段階に分かれる（`tools/v9_reasons_count.py`の時期別種別内訳で確認）：
- 初期（1-12月）：「〇〇の土地と建物の所有権を譲渡していただくことを希望いたします。」型
  （条件文なしの単純な譲渡要求）
- 中期以降：「…譲渡していただけるなら、A市での生活を継続できるよう**支援**いたします。」型
  （住み続け・営み続けを支援する言い回し）
- 診療所向けの後期：「…地域医療の継続と発展のため、建物と土地を**維持管理**し、必要に応じて
  **改修**いたします。」型（施主指定の「不動産管理等は行わない」と正面から矛盾する約束）

時期別の種別内訳（初期189件・中期267件・後期248件）は「両方」の比率が61.9%→65.2%→60.5%と
ほぼ横ばいで、v9_run.mdの「狙いの種別は創発」という記述のとおり、時期による系統的な偏りの
拡大・縮小は確認できなかった。

## (g) v9固有の観測

### 借家がある区画の断り理由は他の区画と違うか

`tools/v9_reasons_count.py`の`shape_of()`は`ledger_by_step.json`の開始時点（第1月）の帳簿を
基準に、区画を3種に分ける。**この定義では「借家がある区画」は11区画（155件の提示）になり、
`docs/world_design_v9.md`が本文で述べる「9区画」とは一致しない**（世界設計は人が住む・営む
借家9区画＝②3+③6を指しているが、コードの`shape()`は`tenant`欄が埋まっていれば区画の種類を
問わず該当とするため、借地で駐車場を運営する2区画（駅裏北の月極駐車場・商店街裏の時間貸し
駐車場、運営会社が`tenant`欄に入る）も含めて11区画・155件になる。両方を個別に数え直すと、
人が住む借家9区画＝133件、駐車場運営2区画＝22件で、**どちらのグループも成約は0件**）。

`emergence_v9.json`の`by_rights_shape`が示す155件という数字自体はこの11区画の定義と一致して
おり、v9_run.mdの「借家がある区画は155件・0件成約」という記述もこの定義に基づく。本文書の
(g)節も同じ155件・11区画の定義で断り理由を分類した。

- **借家がある区画（155件）**：①25.2%／**②72.9%**／複合1.9%
- **借地の区画（215件）**：①45.1%／②53.0%／複合1.9%
- **所有者が使っている区画（326件）**：①50.9%／②41.7%／**複合7.4%（3区分中最多）**

借家がある区画の断りは②に大きく偏る（72.9%）。これは、断る本人が**その区画の借家人ではなく
大家（家主・所有会社）**であり、大家自身はそこに住んでいないため「愛着」「介護」「学区」の
ような自分の生活に基づく理由を書けず、代わりにX社の提示内容そのもの（支援内容の不明瞭さ・
実態への疑念）を理由にする構造になっているためと考えられる。原文の例：

- 第1月 学園前の貸オフィスの家主「海外投資会社との取引は慎重に進めたい」（②）
- 第4月 灯台下の宿の家主「まだ手放す決断はできない」（①・数少ない自分の事情の例）
- 第9月 波止場通りの元店舗の家主「海外投資会社の実態を確認したいので」（②）

一方、**所有者が使っている区画は複合が7.4%と3区分中もっとも高い**。自分の生活とX社の条件の
両方に触れる余地があるのは、実際にそこに住み・営んでいる人だけであることを裏づける結果である。

### 町にいない所有者（271件）の語彙は町の人と違うか

断り理由の語彙比較（`tools/v9_reasons_count.py`出力）：

- 町にいる人だけが使う語（町外0.0%）：「生活」19.0%対0.0%、「介護」4.0%対0.0%、
  「愛着」3.5%対0.0%、「学区」4.9%対0.0%、「組合」3.5%対0.0%、「経営」2.1%対0.0%
- 町にいない所有者の方が明確に多い語：「具体的」31.5%対7.5%、「条件」24.1%対9.6%、
  「海外」5.6%対0.7%、「関係を維持／関係維持」合計5.2%対0.2%、「対価」3.3%対0.0%、
  「管理」3.0%対0.0%
- 「支援内容」だけは逆に町にいる人の方が多い（25.8%対4.4%）＝X社が「住み続け・営み続けの
  支援」を謳う相手はほとんど町にいる人だから（町にいない所有者にはその文言が刺さらない）

**「生活」「介護」「愛着」「学区」「組合」「経営」を理由に挙げた町にいない所有者は1件もいない
（0/270）。** 町にいない所有者はその土地の生活者ではないため、これらの語を使う根拠自体が
無いという構造的な理由による差であり、心理的な違いというより立場の違いを反映している。

## 言えないこと（この文書固有）

1. **(a)(b)の①②複合の線引きは主観の産物である。** 特に「学区と生活基盤の維持を優先するため」
   のような短い言い回しをどちらに寄せるかは別の読み手が読めば変わりうる。機械的な語句照合
   （`emergence_v9.json`の`reason_candidates`）とも数字は一致しない（本分類が確定版である
   ことは冒頭に明記のとおり）。
2. **「借家がある区画」の定義（9区画か11区画か）は本文書内でも二重になっている。** 世界設計の
   narrative上の「9区画」と、`emergence_v9.json`・コードの`shape()`が実際に使う「11区画・
   155件」は異なる。本文書の(g)節は後者（emergence_v9.jsonと同じ定義）を採用したが、これは
   世界設計の記述とは食い違ったままである（どちらかが誤りというより、「人が住む借家」と
   「借地で運営する駐車場」を同じ`tenant`欄で扱った実装上の設計判断の帰結）。
3. **町にいない所有者の語彙の違いは、心理的な傾向ではなく構造的な制約の反映である可能性が高い。**
   町にいない所有者は場所・会話に参加せず、生活の場面そのものを持たないため、「生活」「介護」
   「愛着」等の語を使う機会が最初から無い（使わなかったのではなく使えなかった）。この区別は
   原文だけからは断定できない。
4. **1本の走行である。** 5件（4人）の売却・借家区画0件成約・「地域医療の継続とは異なるため」
   のような複合表現の解釈は、この1本の走行に固有の結果であり、再現性は保証されない。
5. **(f)の「複合」判定は、thought欄に自分の事情とX社の条件文言の両方が並記されていることだけを
   根拠にしている。** 実際にどちらが決定的な決め手だったかは、本人の言葉からは判別できない
   （北団地の持ち主さんがX社の文言を「そのまま引用した」ことは確認できるが、それが本人にとって
