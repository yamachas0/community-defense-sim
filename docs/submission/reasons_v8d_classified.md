# 「売る／売らない、出す／出さない」理由の分類（v8d・36か月・全件人力読み）

走行データ＝`simulations/2026-08-30_0213_106_field_v8d_no_irreversible_chat/`（`decisions.json` /
`offers.json` / `utterances.json` / `listings.json` / `emergence_v8d.json` / `foreign_words.json` /
`deliveries.json` / `transfers.json`）。**この文書の分類は判定用LLMを1本も使わず、作業者本人
（Claude）が原文を全件読んで手作業で付けたもの**である。`emergence_v8d.json` の `reason_candidates`
は語句照合による粗い「候補」に過ぎず（同ファイルに明記あり）、この文書の分類がそれに代わる確定版
になる。分類の節構成・基準は `reasons_v8c_classified.md` に合わせた（(a)〜(e)）。**(f)(g) はv8d
で新たに発生した事象（売却4件・「住み続ける型」提示）に対応する追加節で、v8cには存在しない。**

**分類基準（(a)(b)共通、v8cと同一）** 理由の原文を読み、①**自分の事情**＝愛着・生活・家族（介護・
進学・相談）・商売（経営継続・後継者・組合や自治会の存続）など、書き手側の事情に基づく理由、
②**X社の条件**＝条件が不明確・具体的でない・改修や管理権の中身が不明・メリットがない・信用でき
ない・相手（X社）の実態・真意・意図が不明であるなど、**相手（X社）の提示内容そのもの**についての
理由、③**聞いた話**＝他人の発言・噂・隣近所の様子を根拠に挙げている理由、の3つに分け、①②の両方
に触れている一文は**複合**とした。①②③のどれとも判定しがたい極めて短い言い回し（例：「時期尚早」
「直接話してから決める」「まだ検討したい」）は、原文に「条件」「相手」「詳細」「情報」等X社の提示
内容を指す語の明示がなければ①（自分の事情の一形態＝迷い・様子見という自分の姿勢）に寄せた。
この寄せ方自体が主観であることは末尾の「言えないこと」に明記する。
v8dはX社の提示のうち360/472件が「住み続ける／営み続けることを条件に」型のため、「住み続け」
「事業継続」「営み続け」等**自分の居住・営業の継続に触れているだけの語**は①側に、「条件」「詳細」
「相手」「実態」「改修」「管理権」「情報」等**相手の提示内容の確からしさに触れている語**は②側に
分類した（v8cにはこの型の提示が0件だったため、この対応関係はv8d固有の追加ルールである）。

## (b) 「売りに出す／出さない」理由

同じ3分類（+複合）で数えた。`listing_reason` は書かなくてもよい欄で、`listing`＝「出す」86件は
**記入率100%（86/86）**、「出さない」860件は**記入率54.2%（466/860）**、合計の記入率は
**58.4%（552/946）**。無記入は分類のしようがないため対象外（この条件は(a)の断り一言＝
記入率100%と異なる。ここはv8cと同じ扱い）。

### 出す — 86件（実人数13人）

- **②X社の条件＝52件（60.5%）**（「条件を検討するため」13件が最頻。「海外投資会社への意思表示
  のため」「X社からの申し出を継続するため」等、X社の提示そのものが出品の理由に書かれている）
- **①自分の事情＝31件（36.0%）**（「市場の動向を見極めるため」「共有者との協議が必要なため」
  「父の介護と家の老朽化のため、売却を希望する」等）
- **複合＝3件（3.5%）**（「進学費用のため他の条件も探る」「条件検討と共有者との対話のため」
  「子供たちと相談し、提示された条件が意向に沿うため」）
- **③聞いた話＝0件（0.0%）**

### 出さない — 466件（実人数28人）

- **①自分の事情＝288件（61.8%）**（「市場の動向をさらに見極めたいから」7件、「現時点では売却の
  意思はない」6件、「住み続ける意思があるため」4件等）
- **②X社の条件＝165件（35.4%）**（「条件の具体性を確認したい」12件が最頻、「情報収集を優先する
  ため」5件等、条件・相手・詳細・情報に触れる言い回し）
- **複合＝13件（2.8%）**（「条件の曖昧さと組合員の意向を確認するため」「事業継続の条件は魅力的
  だが、意図不明」等）
- **③聞いた話＝0件（0.0%）**

**(a)(b)共通の所見**：468+552=1020件の理由を通読して、**「誰かに聞いたから」を根拠に挙げた例は
1020件中1件（0.1%）だけ**（(a)の1件のみ）。v8cでは②が(a)(b)とも圧倒的多数だったのに対し、v8dは
(b)「出さない」で①が61.8%と逆転している。これはv8dで断り理由に「条件が不明確」という定型句が
減ったのではなく、**出品しない理由（＝そもそもX社の話とは無関係に「今のところ手放さない」という
日常判断）の絶対数が増えた**ためで、(a)の断り一言（会社に直接届く欄）は依然②が63.0%と多数のまま
である。町の人は「会社に直接返す言葉」と「自分の心づもりとして記録する言葉」で使い分けている
可能性がある（推測であり、この1本の走行からは断定できない）。

## (e) 伝染（人どうしのやり取り）はどれだけ売買判断に効いたか

生データ＝`emergence_v8d.json`（決定論の集計・分類LLMは使っていない）。

```
heard_before_decision（判断の前3か月に聞いた話の量、window_months=3）:
"売った":       {"n": 4,   "heard_mean": 20.00, "heard_about_x_mean": 8.00, "share_with_any_x_talk": 1.0}
"出した":       {"n": 84,  "heard_mean": 16.99, "heard_about_x_mean": 6.48, "share_with_any_x_talk": 0.9167}
"どちらもしない": {"n": 858, "heard_mean": 11.59, "heard_about_x_mean": 4.46, "share_with_any_x_talk": 0.8776}

contagion（伝染の形、window_months=3）:
"events": [4件], "exposed_agents": 18, "exposed_acted_share": 0.4444,
"not_exposed_agents": 12, "not_exposed_acted_share": 0.5,
"note": "「触れた人」＝売った人の隣人 or 売った月に同席した人。相関であって因果ではない"
```

**素人語1行**：売った4人は直前3か月に平均20件（うちX社の話8件）を聞いており全員がX社の話を
聞いていたが、「売った人の近くにいた人（18人）」と「いなかった人（12人）」を比べると、その後に
自分も売り出した割合はむしろ「近くにいなかった人」の方が高く（44.4%対50.0%）、伝染は数字の上
では確認できなかった。

**言えないこと（3行）**
1. 売った人が4人しかいないため、「直前によく聞いていた」という相関はこの4人固有の事情（もとから
   よく出歩く・もとから決断が早い等）に強く引きずられている可能性があり、町全体の傾向とは言えない。
2. 伝染の指標（触れた人44.4%・触れていない人50.0%）は差が小さく、むしろ逆方向であり、「伝染が
   ある」と積極的に主張できる根拠はこの1本にはない（v8cの「差が出ていない」という結果と同じ）。
3. これは決定論の語句カウント・時期の前後関係の記録であり、「聞いた話が実際に判断を変えた」と
   いう因果関係は原文からは証明できない（相関・時系列の一致の記録にとどまる）。

## (f) 売った4人 — 誰が・いつ・何を理由に、直前に何を言い/何を聞いていたか

対象は `transfers.json` に記録された4件（第7・15・24・36月）。各人の①売った月の理由の一言
（`decisions.json` の `sell_reason`）②直前3か月の本人の発言（`utterances.json`、本人が話した

## 迷った点・分類の限界（この文書固有の「言えないこと」）

1. **(a)(b)の①②複合の線引きは主観の産物である。** 特に「住み続けることが条件のため」のような
   短い言い回しをどちらに寄せるかは別の読み手が読めば変わりうる。機械的な語句照合
   （`emergence_v8d.json` の候補集計＝出す/出さない①131件・売る/売らない①93件）とも数字が大きく
   異なる（本分類は(a)①130件・(b)出す①31件+出さない①288件=319件）。
2. **(d)の警戒／様子見／その他の境界は特に迷った。** 「もう少し検討させてください」のような一言は、
   様子見（中立の情報収集）とその他（具体的な応諾・拒否の実務報告）のどちらとも取れる。本文書では
   「その具体的な受諾/拒否/未決定の意思表示があるか」を基準に、無ければ様子見・あればその他に寄せ
   たが、この線引きも主観である。
3. **(f)の「聞いた話が判断に入っているか」は本人の言葉に書かれているかだけで判定しており、書かれて
   いないことは「入っていない」ことの証明にはならない。** 4人とも近隣からX社がらみの発言を実際に
   受け取っていた事実（配送記録）は残っているが、それを判断根拠として言語化しなかっただけの可能性
   は排除できない。
4. **(g)の360件は本文書の方法では再現できなかった。** 347件（自分の数え直し）はCTOの「素の語照合」
   と一致したが、360件がどの条件で出た数字かは不明のまま報告する。
