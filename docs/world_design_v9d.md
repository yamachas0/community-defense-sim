## 0. 何を変えたのか（4つだけ）

1. **評価額（公開）** … 44区画の土地・建物それぞれに評価額がある。登記簿と同じ扱いで、
   X社にも町の人にも見える（現実の公示地価・固定資産税評価と同じ位置づけ）。
2. **X社の提示に金額が必須** … 区画＋種別＋**金額（円）**＋条件文。金額はX社が自分で決める。
3. **X社の資金は有限** … 町の全評価額の **51%**。成約ごとに減り、残額を毎月X社が知る。
   残額を超える金額の提示は世界が配らない（件数を数える）。
4. **財布は記帳だけ** … 売った人の記録に金額が入る（開始時0）。財布は何も起こさない。

**入れないもの**＝賃料（借地・借家の継続は今までどおり無料）・出品の希望価格・行政のお金・
町の人に計算をさせる仕組み。A（実行できない約束の門番）と v9c の4点はそのまま。

**「得か損か」はどこにも書かない。** 世界が置くのは評価額と提示額という**2つの数字**だけである。

## 1. 評価額の作り方（走行前に凍結）

### 根拠

土地の単価は、**別府市（大分県・人口約11万人の温泉観光都市）の公開値**を土台にした。

- 公示地価の平均 **55,700円/m2**（2026年・坪18.4万円）
  <https://e-estate.jp/land/market-price/oita/beppushi/> ／ <https://tochidai.info/oita/beppu/>
- 基準地価 商業地の平均 **70,240円/m2**（2025年・同上）

A市は人口約12万人の温泉観光都市という設定なので、この水準をそのまま使い、
**地区5段階**に割り付けた。

```
駅前商業 120,000円/m2（中央駅前地区）
観光沿岸  80,000円/m2（湾岸観光地区）
温泉住宅  55,000円/m2（温泉丘陵地区＝別府市の公示地価の平均に相当）
学術生活  40,000円/m2（北部学術・生活地区）
縁辺特殊  20,000円/m2（浜辺の街区公園・神明社の境内地・宮の下の源泉地・船着場裏の2区画）
```

面積（敷地・延床）・建物単価・残価率は、**区画の用途から常識的に置いた仮の値**である
（実在の物件ではない）。建物の評価額＝延床×単価×残価率、土地＝敷地×段階の単価。
どちらも10万円単位に丸める。表と計算は `src/field_v9d.py` にあり、試験で固定している。

## 2. X社の提示

- 出力は `{to, send, parcel, kind, amount, text, reason}`。**amount（円の整数）が必須**。
- 金額をいくらにするかは**X社が決める**。世界は評価額を見せるだけで、
  「評価額に合わせよ」「これ以上出すな」とは1文字も書かない。
- 門番の順序＝①相手が持っていない区画・種別 → ②実行できない約束 → ③金額が0以下
  → ④**残りの資金を超える金額**。①②④で落ちた提示は配らず、翌月X社に事実と理由だけ返す。
- **同じ月に配った提示の合計も残りの資金を超えない**（全部成約しても資金は尽きない）。

## 3. 資金

```
町の全評価額の合計 2,297,700,000円
X社の資金（51%）  1,171,800,000円
```

- 施主決定＝「理論上、過半を超えられる予算」。
- 成約するたびに提示額が引かれる。残額は毎月X社のプロンプトの冒頭に出る。

## 4. 売る側に見せるもの（比べる語を書かない）

- 届いた提示の欄に、事実として2つの数字を**並べる**だけ。

```
  X社が示した金額：12,000,000円（駅前通りの家の土地の評価額：21,600,000円）
```

- 月末の問いの末尾に、自分に関わる区画の評価額と、自分の記録に入っている金額を置く。
- 「得」「損」「高い」「安い」「相場より」「妥当」等の語は世界の文に**1つも書かない**（試験で固定）。
- 計算（倍率）は世界がしない。**倍率を出すのは観測（集計）だけ**である。

## 5. 世界の事実（3者に同じ文で置く）

```
--- お金 ---
この町の不動産には、土地と建物それぞれに評価額がある。評価額は公開されていて、誰でも見ることができる。
不動産の所有権が移るとき、買い手は金額を示し、その金額が売った人の記録に入る。
この世界にあるお金は、不動産の所有権が移るときに動くものだけである。
賃料はない。借地も借家も、これまでどおり金銭のやり取りなしに続く。
維持費も税もない。お金で何かを買う仕組みもない。記録に入った金額は、そのまま記録に残る。
```

## 6. 観測（決定論・採点LLMなし）

v9c の項目に加えて:

1. 提示ごとの **提示額÷評価額の倍率**。分布と月別推移。
2. **得なのに断った**（倍率1.0以上で「売らない」）／**損なのに売った**（倍率1.0未満で「売る」）
   の件数と人。※この2語は**観測の名前**であって、世界の文には出さない。
3. 上の2つを、**会話でX社に触れた人／触れていない人**で割る（`utterances.json` を
   凍結した語（「X社」「海外」「投資」「買収」「申し出」「提示」）で照合）。
4. 資金の減り方（月別）・資金不足で配らなかった件数。
5. **町にいない所有者14人が金で動くか**（v9〜v9c では 0/2/0/0 件）。
6. 誰がどの倍率で売ったか（全件）。断り・出品理由の金額系の語の件数。理由は全文保存。
