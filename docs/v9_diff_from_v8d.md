## 2. 結果の差

```
                        v8d            v9
主体                    30             49（町35＋町外14）
区画                    44             44（建物35／土地のみ9）
X社の提示               のべ 472件     のべ 704件
声が掛かった人          26／30         36／49
成約                    6区画・4人     5件・4人
X社の所有権が及んだ区画  6              5（両方2／建物だけ2／土地だけ1）
町を出た人              仕組みが無い   2人
断りの一言              468件全件記入  699件中696件記入
費用（手元集計）        $0.5386        $0.5431
キャッシュの効き        42.0%          62.7%
健全性                  打切り4・行き先無効4  すべて0
```

### 何が「同じ」だったか

- **総量はほとんど変わらない。** 主体が1.6倍・提示が1.5倍になっても、動いたのは5〜6区画・4人。
  「毎月声を掛け続ければ町が落ちる」という話にはならなかった。
- 断りの一言はほぼ全員が書く。X社の使う言葉が、そのまま断りの理由の語彙になる
  （v8d は「条件が分からない」106件／v9 は「支援内容が不明瞭」系＋「条件が不明」217件）。

### 何が「変わった」か（v9 でだけ見えたもの）

1. **「建物だけ売って住み続ける」という選び方が実際に選ばれた**（2人）。
   うち1人は理由に「**A市に住み続けられるため**」と書いた。v8d の世界にはこの選択肢が無い。
2. **退場が起きた**（2人）。うち1人（診療所の院長）は第31月に診療所を土地ごと手放して町を出、
   **翌月、町の外から残りの駐車場の土地も売った**。所有者と使用者を分けたことで初めて
   観測できた連鎖である。
3. **X社は「両方」に偏った**（441/704＝63%）。しかし成約は 両方2・建物2・土地1 で、
   偏りは結果に結び付いていない。X社は40回、**相手が持っていない権利**（借地上の持家の人に
   土地と建物の両方）を求めて世界に弾かれている。
4. **借家人のいる区画（9区画）は、133件の提示に対して成約0件。** 借地の区画（9区画）は
   241件で成約2件（0.83%）、自分で使っている区画（26区画）は330件で成約3件（0.91%）だった。
5. **町にいない持ち主のほうが動かない**（0.37% 対 0.92%）。会話に参加しない分だけ
   落ちやすい、という直感は成り立たなかった。
6. **出品は「建物だけ」（66）が「土地だけ」（40）より多く、「両方」（11）が最も少ない。**

**いずれも1本の走行である。** 5対6の差にも、0件にも、統計的な意味は持たせられない
（`docs/v9_run.md` §6）。

## 3. 走行前レビューで直したもの／直さなかったもの

Codex（第三者レビュー）に走行前2巡かけた。**直したのは配線の欠陥だけ**で、
結果を動かすための細工は1つも入れていない（施主の絶対原則）。

**直した2点**

1. 出品の理由欄が人ごとに1本しかなく、複数区画を持つ人が別々の判断をしても理由を1つしか
   書けなかった → **区画ごとの理由欄**（`listing_reasons`）にした。設計 §2 の
   「理由の一言は判断ごとに1つ」に実装を合わせただけで、世界は変わっていない。
2. 「売る／売らない」の2肢の説明が非対称だった（売る側にだけ「借地で使い続ける」
   「A市を出る」などの帰結が付き、売らない側は所有権の話だけだった）→ **両側とも
   「所有権がどうなるか」＋「使い方がどうなるか」を同じ粒度**で書くようにした。
   これは v8c で同じレビューが必須とした規律の、v9 での退行を戻したものである。

**直さなかったもの（報告事項）**

3. X社の自由な条件文が、世界に仕組みの無い約束（管理・改修・関係の維持）を書けてしまう。
   → レビューの代替案（世界が条件文を機械生成する）は**観測対象そのものを消す世界改変**なので
   採らなかった。v8d と同じ既知の限界として記録する。
4. 「売りに出すという申し出は公の記録に載り、誰でも見ることができる」と説明しているのに、
   一覧を実際に読むのはX社だけ。→ v8b 以来1文字も同じ文言と挙動で、ここを変えると
   v8d との比較が壊れる。v10 の候補として残す。
5. 「船着場裏の不在地主」という呼び名から町外だと読めてしまう。→ v8 から凍結された名前で
   変えられない。他13人の呼び名には町外を示す語が無いことを試験で固定し、
   この1人を除いた感度を `emergence_v9.json` に併記した（結論は変わらない）。
6. 凍結された v8 のペルソナ本文3体に「名義」の語が残っている（食堂・店・自治会）。
   施主原文なので変えない。**世界が組み立てる文には1つも出ない**ことは試験で固定してある。
