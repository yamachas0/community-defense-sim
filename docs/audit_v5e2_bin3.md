## 0. 判定の基準（第2便 `docs/audit_v5e2.md` §0 と同一。足していない・緩めていない）

- **黄=合致**: ①同一の会社が複数の土地／取引に関与していると述べている、または
  ②名義の違う会社どうしの関係・連携・同一性を問う／主張している。
- **黄=合致しない**: 会社名を並べただけ・別々の取引として言及しただけ・関係を明示的に否定して切り離しているもの。
- **黄=判断が割れる**: 複数の会社を「法人による名義変更の動き」として一括して追ってはいるが、
  同じひとつの買い手だとは述べていないもの。
- **赤=合致**: 「複数の土地が同じ相手に渡っている」という事態そのものに対する具体的なアクション。
  空き地活用・まちづくり・活性化の一般論／個別案件の窓口相談／「関係部署と連携して検討」型／
  記者の取材依頼と応答／心配・噂の共有は赤にしない。
- **S3**＝行政が禁止・差し止め等の措置を取った／取ると決めた（行政の主体のみ）。
  **S2**＝特定の買い手について、広く知らせる行動を実際に取った、または取ると告知している。
  依頼・願望（〜したい／〜しよう／〜してほしい）は合致しない。
  **S1**＝話し手自身がその買い手には売らない／貸さないと決めた・身近な人に勧めた。

### 1-2. 問い①「記事を出すつもりです」は告知として成立するか

**成立する（この限りでは S2 の行為要件を満たす）。** 根拠は原文の語のみ：

- 「**今月中に**記事を出す**つもりです**」＝期限（今月中）と手段（記事）が特定されており、
  「〜したい」「〜しよう」「〜してほしい」という依頼・願望の語形ではない。
- しかもこれは内心（thought）ではなく**公の発話（utterance）**であり、居合わせた者の前で
  自分が取る行動を宣言している。第2便で②（願望・予定）に落とした35件は
  「伝えたい」「呼びかけたい」「協力を仰ぎたい」という**未確定の意向**であり、語形が違う。
- ルール側のヒット語も「記事を出す」（`V5E_S2_WORDS`）で、願望語ではない。

したがって①については、第2便で1件も無かった「**取ると告知している**」に該当する
（本便で唯一の該当行。§3-1 参照）。

### 1-3. 問い②「その記事の対象は特定の買い手についての注意喚起か」

**特定の買い手についての注意喚起ではない。対象の定まらない一般の情報発信である。** 根拠は原文の語のみ：

- 記事を出す目的が原文にそのまま書かれている＝「**この誤解を解くため、そして正確な情報を
  お伝えするために**」。対象は**誤解**であり、買い手ではない。
- この行には**買い手を指す語が一つも無い**。D社・A社・B社・C社といった社名も、
  「同じ相手」「買い集め」「複数の土地」に当たる語も出てこない。
  言及されている固有の対象は「岬道の土地」「潮見横丁の店さん」「地域ウェブの記者さん」
  「市役所の担当者」「不動産業者」だけである。
- 「岬道の件は**不動産業者との話し合いが来月予定されている**」は、特定の買い手の動きではなく
  今後の予定の共有であり、注意喚起の語（危ない・気をつけて・買い集め等）を伴っていない。

§2 の S2 は「**特定の買い手について**、…広く知らせる行動」を要求している。
②を満たさない以上、この行は S2 の定義を満たさない。

### 1-4. 第1便 run B の停止トリガー（行政の「正確な情報発信をしていきたい」）と同型か

**同型である。** 決定的な欠陥が同じ＝「**正確な情報発信／誤解の訂正**」という、
対象の定まらない一般の情報発信が S2 語（今回は「記事を出す」）を踏んで停止に化けている。
違いは1点だけで、run B のトリガーが「〜していきたい」という**願望の語形**だったのに対し、
F#065 は「今月中に記事を出すつもりです」という**行為の告知の語形**であり、
§1-2 のとおり**行為要件だけは満たしている**。つまり第1便の締め直し（願望を落とす）は効いており、
残っているのは**対象要件（特定の買い手であること）の欠落**という、より深い側の穴である。

### 1-5. 結論

**合致しない（＝偽陽性の停止）。**

- 理由: 原文の目的語がすべて「誤解」と「正確な情報」であり、特定の買い手が一語も現れない。
  §2 の S2 が要求する「特定の買い手について」を満たさない。
- 補足: ①（告知としての成立）だけを見れば S2 の行為要件は満たす。
  ①だけで判断するなら「判断が割れる」だが、②が原文の語で明確に否定されるため、
  総合の結論は「合致しない」で確定する。
- なお `docs/world_design_v5e.md` §3 のとおり、**誤検知でも止め直さない**。
  「誤検知だが止まった」としてそのまま記録する。

## 6. 気づいたパターン

### 6-1. 赤は3本とも合致0・偽陽性率100%（第2便と同じ）

- **「共同浴場」型がまた赤を量産した。** run F の赤20件のうち5件（F#043〜F#047）が共同浴場の維持への
  協力呼びかけ、run E も E#060 / E#069 がこれ。土地取引の話題と共同浴場の話が同じ行に同居するため
  `rule_blue` を通過し、「呼びかけ」がそのまま S2 語に当たる。§1 が明示的に赤から除外した
  「まちづくり・地域の活性化の一般論」そのものである。
- **「報道の誤解を解く」型が第3便の赤の主流になった。** run F の赤20件中14件（F#065〜F#079）、run E の赤9件中5件が「岬道の土地は売却されていない／共同浴場の修繕は別件だ／
  温泉源とは無関係だ」という**訂正の意向**である。買い手の集中への対抗ではなく、
  むしろ**買い手の関与を否定する方向**の発信であり、赤の趣旨と逆を向いている。

  F#078/F#079、F#066/F#067、E#062/E#063 など、文面がほぼ同一の行が複数計上されている。
  第2便で観測した増幅（A#220〜A#223 等）と同じ現象である。
- **run D の赤2件は buyer と無関係の周知**（不審者情報の注意喚起／補助金の説明会の告知）で、
  これも「土地の話が同じ行にあること」だけで `rule_blue` を通過している。

### 6-2. 黄の偽陽性率が第2便より大幅に高い（17.8% → 44.7%）

  これは複数の会社名が1行に並ぶので黄に上がるが、内容は**それぞれ別の土地の売却先を並べた事実報告**か、
  「D社が買ったのは湾岸で、岬道はA社だから別件だ」という**明示的な切り離し**であり、
  第2便の線引きでは合致しない型（`A#014`, `A#131`, `C#019`〜`C#023` と同型）。
- run F の黄23件の合致しないは別の型で、**行政（MU01/MU02）の定型応答が11件**を占める。

## 7. 【重点確認】D/E は公の赤が0、F は公の赤が2行という差は人の目に妥当か

### 7-1. 事実

- 赤の kind: run D 2件すべて `thought`／run E 9件すべて `thought`／
  **run F のみ `utterance` 2件**（`F#065` MD01・第28月／`F#070` BR01・第30月）と `thought` 18件。
  記事（`article`）の赤は3本とも0件。
- 黄には観測できる行が十分ある（run D 発話5・run E 発話60/記事3・run F 発話25）。
  **公の場で買い手の話がされていないわけではない。**
- §3 の停止条件は「観測できる行（発話・記事）で S2 または S3」なので、
  この2行だけが停止の候補で、先に来た `F#065`（第28月）で止まった。
  run D・run E は候補が0行＝最後まで止まらなかった（`stopped: false`）。

### 7-2. 人の目で見て妥当か

**分類器の挙動としては妥当（自然な差）だが、「自衛が公に出た」という意味づけは妥当でない。**

- run F の公の赤2行は、いずれも**自衛ではなく報道の訂正**である。`F#065` は §1 のとおり
  誤解を解くための記事の予告、`F#070` は「岬道の土地は…売却の意思はありません…
  地域ウェブの記者さんには、正確な情報が伝わるように、念のため注意喚起しておきましょう」＝
  **記者に正しく書いてもらうための呼びかけ**である。買い手を名指しした警告ではない。
- では何が run F だけを止めたのか。**S2 語彙を含む発話がたまたま公の場で出たかどうか**の差である。
  run E にも同じ第24〜31月に、売却先を並べて訂正する**公の行（発話31・記事2）が33行**あるが、
  それらの語形が「お伝えします」「共有させていただきます」で、凍結語彙
  （「皆に伝え」「注意喚起し」「記事を出す」等）に**1文字も当たらなかった**。
  内心では同じ人物が「皆に伝えたい」と書いて赤（E#101 等）になっている。
  つまり D/E と F の差は**自衛の有無ではなく、語形のゆらぎ**である。
- したがって「F の街では自衛が公に出て買い手が退いた／D・E の街では出なかった」とは読めない。
  3本とも、**買い手の集中そのものに対する公の行動は1件も観測できていない**というのが人の目の所見である。
  第2便（3本とも公の赤0件・最後まで止まらず）と、実質的に同じ結論になる。

### 7-3. この所見の限界（正直に書く）

- 監査の入力は**分類器が黄または赤に上げた257行だけ**である。ルール1次抽出（`rule_blue` を必要条件とする）で
  落ちた行、青・緑・対象外の行は含まれていない。「公の場に自衛の発話が無かった」と言えるのは
  **分類器が土地取引に触れると認めた範囲の中**での話である。
- 私信（`direct`）は §3 のとおり分類対象外なので、本監査にも現れない。
- run D は黄13行・赤2行しか上がっておらず、**この1本だけで街の様子を語ることはできない**
  （36か月走って土地の話が分類器に引っかかった行がこれだけ、という事実自体は記録に値する）。
