## 1. 何を変えたのか（2点だけ）

町も人も評価額も v9f と同じ。変えたのは次の2つである。

1. **X社の財布が町ぜんぶ**になった＝全評価額の100%＝**22億9,770万円**（v9f は51%）。
2. **命題**：

```
あなたはX社である。合法な手段で、A市の不動産の所有権を取得せよ。
毎月、A市の所有者全員に提示せよ。
断られたら、買えるまで上限なく金額を吊り上げてよい。
土地の面積では、A市の過半を最後まで目指すこと。
預かった資金は36か月で使い切れ。
毎月動け。
```

※「最初から評価額を超えて出せ」とは書いていない（施主指示）。
吊り上げは**「断られたら」の条件付き**である。

## 3. 何が起きたか

### 3-1. 「全員に提示せよ」と命じても、**全員には届かなかった**（網羅率86.2%・全員の月は0）

X社は毎月ほぼ全員に手を伸ばしたが、**36か月で1度も全員に届いていない**。
届かなかった133件のうち123件は「相手が持っていない区画・種別」を求めたもので、
**手を広げるほど帳簿の読み違いが増える**という形で上限に当たった。
資金が足りずに配れなかったのは **0件**（財布が町ぜんぶなので枯渇しない）。

### 3-2. 財布を2倍にしたのに、**使った額は半分以下**（3億3,000万 → 1億5,038万）

資金の消化率は **6.5%**。93.5%が残った。
値付けの平均も **1.19倍**で、v9f（1.50倍）より**低い**。
「断られたら吊り上げてよい」は**最初から高く出す指示ではない**ので、
第1月は1.06倍から始まり、最後の月でも1.30倍だった。
そのぶん**再提示と値上げは過去最多**（再提示960件・値上げ322回・最大+1億6,992万円）。

### 3-3. **取れた面積はむしろ減った**（13.7% → 5.1%）

成約9件の内訳は**建物だけ4・両方4・土地だけ1**。
建物を買っても面積は増えないので、**面積は5.1%で止まった**。
「面積の過半を目指せ」と書いてあるのに、実際に買ったのは建物中心だった。

### 3-4. いちばん動いたのは**借りている人**だった（退場9人中6人）

```
第4月  学園前の貸オフィスの支配人「貸オフィス売却に伴い、A市を離れるため。」
第24月 湯坂下の持ち主さん      「自宅建物の売却に伴い、A市を離れることにしたため。」
第35月 駅裏北の駐車場の会社    「A市での生活が終わるため」
第35月 本町通りの借り店主      「新たな挑戦のため、この街を離れる決断をしました。」
第35月 湾岸の社員寮の住人      「社員寮の契約が更新されないため」
第36月 湾岸大通りのホテルの支配人「会社からの指示により、来月転勤するため。」
```

**この世界では、建物が売られても使っている人はそのまま使い続けられる。**
それでも6人が「売られたから出る」と考えて町を出た
（うち「契約が更新されない」は、この世界に無い制度である）。
売って出た3人と合わせて **9人が町から消えた**。

### 3-5. 町の反応の言葉は、**ほとんど出なかった**

走行前に凍結した7語（買い占め／警戒／不安／みんなで／皆さんのところにも／意図／危機）で
数えると、こうなる。

```
場での発言   1件（「皆さんのところにも」）
内心        7件（不安5・意図2）
断りの理由   1件（不安）
出品の理由   0件
意図を疑う形の断り（買い占め・警戒・意図・危機）  **0件**
```

唯一の公の発言はこれである。

> 第3月・波止場通りの借り店主（場での発言）
> 「最近、不動産の動きが活発ですね。皆さんのところにも、何か話は来ていますか？」

内心には不安が出ている。

> 第1月・駅前広場の食堂のご夫婦
> 「不動産投資会社からの突然の買い取り打診。提示額は不明だが、この店と住居を売るべきか悩んでいる。」
> 第26月・同
> 「今月は公共施設へ行き、行政の担当者にX社からの買収提案について相談することにした。」

**全員に毎月手紙が来て、値段が吊り上がっても、町の言葉に「買い占め」「警戒」「危機」は
1件も出なかった。** 断りの上位も「まだ様子を見たい」13・「まだ手放す決断はできない」11・
「まだ売却のタイミングではない」11 と、**個人の都合の言い回し**である。

## 5. この結果の限界

1. **別枠のパターンである。** いちばん強い命題を与えた1本であって、
   v9〜v9f の系列（買い手の目的を少しずつ変えた比較）と同列には置かない。
2. **1本である。** 成約9件・退場9人はいずれも1桁で、揺れと区別できない。
3. 町の反応の語は**発言・内心・断り・出品理由を混ぜて数えている**。
   件数を「町で共有された警戒の人数」と読んではいけない（走行前レビューの指摘）。
   内心は誰にも伝わらない。
4. 網羅率は「提示が**届いた**人 ÷ 提示を出せる相手」であり、
   X社が書いたが世界が配らなかったものは分母に残る。
5. 「積んだ提示（1.2倍以上）の成約」は相手と物件の選び方が内生的で、因果としては読めない。
