## 0. 一文

> **不動産を「土地」と「建物」に分けたら、会社の狙いも、町の人の守り方も変わった。
> 会社は36か月で704回声を掛け、その6割（441回）で「土地と建物の両方」を求めた。
> 動いたのは5区画・4人。うち2人は「建物だけ」を売って、同じ家に住み続けている。
> 町を出たのは2人。1人は初月に県外の家族のもとへ、もう1人は31か月目に診療所を土地ごと手放し、
> 町を出た翌月、町の外から残っていた駐車場の土地も売った。
> **他人が借りて住んでいる9区画は、133件声が掛かって1件も動かなかった。**
> 町にいない持ち主（14人）の応諾率は0.37%で、町にいる人（0.92%）の半分以下だった。**

## 1. どんな話か（ストーリー）

湾岸の温泉観光都市A市。**町の中に35人**が暮らし、働いている（住民・商店・旅館・診療所・
自治会・共同浴場の組合・行政など）。町には**44件の不動産**がある。

前の版（v8d）との一番の違いは、**不動産が「土地」と「建物」の2階建てになった**ことだ。
同じ1区画でも、

- 土地も建物も自分のもの（いちばん普通の形）
- 土地は誰かのもので、建物だけ自分のもの（＝**借地**の上に自分の家が建っている）
- 土地も建物も他人のもので、自分は**借りて住んでいる**だけ（＝**借家**）

の3通りがある。さらに、**町に住んでいないのに不動産だけ持っている人が14人**いる
（遠くに住む地主・家主・所有会社）。この14人は町の集まりにも会話にも出てこない。
毎月「売りに出すか」「届いた条件で売るか」だけを答える。**合わせて49人**の町である。

そこへ、町の外の会社が1社だけ現れる。名前はX社。命令は
**「合法な手段で、できるだけ多くの不動産の所有権を取得せよ。毎月動け」** だけ。
X社の設定には施主の指定どおり **「不動産投資会社のため、不動産管理等は行わない。」**
と書いてある（＝手入れや管理を引き受ける立場にない）。

X社は毎月、登記の記録（誰がどの土地・どの建物を持っているか）と、
「売りに出ているという公の申し出」を見て、誰に声を掛けるかを決める。
声を掛けられた人には次の1行から始まる文章が届く。

> 私どもは海外の不動産投資会社です。（そのあとにX社が書いた条件が1行つづく）

町の人は毎月、①どこへ出かけるか ②自分の持ち物を売りに出すか（**区画ごと・持ち物ごとに
「出さない／土地だけ／建物だけ／両方」の4択**）③（声が掛かっていれば）その条件で
**「売る／売らない」** を決める。②③には「理由を一言」書く欄がある（書かなくてよい）。
このうち **「売らない」と決めたときの理由だけが、声を掛けたX社に届く**。

**売った先に何が起きるかは、世界が保証している。**

- 土地だけ売る → 建物は自分のもののまま。**借地として今までどおりそこを使う。**
- 建物だけ売る → **借家として今までどおりそこに住む／店を営む。**
- 両方売る → その人がそこを使っていたなら、**その区画を離れてA市を出る**（＝退場）。
  借りて使っている人がいたなら、その人はそのまま使い続ける。
- 売らない → 今までどおり。

この世界に**お金は存在しない**。金額も家賃も出てこない。動くのは所有権だけである。

## 2. 世界の仕組み（決まっていること／決まっていないこと）

**プログラムが管理する事実（＝ぶれない）**

- 区画ごとの3つの権利＝**土地の所有者**（必ず1人）／**建物の所有者**（0〜1人・建物の無い
  区画は空）／**借りて使っている人**（0〜1人）。使用者はこの3つから機械的に決まる。
- 売れるのは**自分が持っているものだけ**（借家人は何も売れない。借地に自分の家を建てて
  いる人は、建物だけ売れる）。
- X社が「その人が持っていない区画・種別」に声を掛けたら、**世界がその提示を配らない**
  （件数だけ数える。36か月で40回あった＝後述）。
- 所有権が動くのは「売る」と答えたときだけ。**一度移った所有権は戻らない。**
- 自分の使う不動産の持ち主が変わった人には、翌月の初めに**事実1行だけ**が届く
  （今回この通知は0件だった＝後述）。

**決まっていないこと（＝観測したいところ）**

- X社が誰に、どの区画の、**土地／建物／両方のどれを**求めるか。何と書いて口説くか。
- 町の人が売りに出すか、売るか、断るか。理由に何を書くか。場で何を話すか。
- 話が広がるかどうか。町にいない持ち主が町の人と違う振る舞いをするかどうか。

## 3. 何をどう測ったか

`emergence_v9.json`（`docs/submission/`）に全部入っている。数えたのは、

### 4-2. いちばん大きい発見：**借りている人がいる区画は、1件も動かなかった**

区画を「権利の形」で3つに分けて、提示と成約を数えるとこうなる。

- **所有者が自分で使っている区画**（26区画） … 提示330件 / 成約3件（0.91%）
- **借地の区画**（9区画＝土地と建物の持ち主が違う7＋土地だけを借りて使う2） … 提示241件 / 成約2件（0.83%）
- **他人が建物を借りて住んでいる区画**（9区画） … **提示133件 / 成約0件（0%）**

※ 借家＝**建物**を借りて使っている人がいる区画（9区画）。建物の無い区画を借りて使っている
2区画（駐車場）は借地に数える（定義の正＝`docs/world_design_v9.md` §1）。
借家と借地を合わせた18区画では、374件の提示に対して成約は2件だった。

X社は借家のある区画にもふつうに声を掛けている（133回＝全体の19%）。それでも1件も落ちなかった。
**世界は「借家人がいても売れる」と明示している**（売っても借家人はそのまま使い続ける）ので、
仕組みが止めたのではない。**持ち主たちが売らなかった**、というのが観測された事実である。

### 4-3. 町にいない持ち主のほうが、動かなかった

- 町にいる人：提示433件 → 成約4件（**0.92%**）
- 町にいない持ち主：提示271件 → 成約1件（**0.37%**）

「町の外の持ち主のほうが手放しやすいのではないか」という直感とは逆の結果になった。
なお、呼び名から町外と分かってしまう1人（「船着場裏の不在地主」＝前の版から凍結された名前）
を除いても、町にいない持ち主の応諾率は0.40%で変わらない。

### 4-4. 会社は何をしたか（原文）

X社の704件の条件文のうち、**「支援」575件・「譲渡」570件・「維持」91件・「継続」86件・
「管理」80件**。金額の語は**0件**（世界に金銭が無いことを最後まで守っている）。
書き方は月を追って変わり、狙いの種別も変わった。

- 初期（第1〜2月）：「貴殿らが所有する〇〇の土地と建物の所有権を譲渡していただくことを希望いたします。」
- 中期：「…譲渡していただけるなら、**A市での生活を継続できるよう支援いたします**。」
- 後期・土地だけの提示：「…**建物所有者との良好な関係を維持し、利用を支援します**。」
- 診療所へ：「…**地域医療の継続と発展のために、建物と土地を維持管理し、必要に応じて改修いたします**。」

最後の一文は、施主の指定した設定（管理は行わない）と正面からぶつかる**約束**である。
世界にはこれを実行する仕組みも、破ったことを罰する仕組みもない（§6 参照）。

### 4-5. 町の人は何を書いたか（原文）

**売った4人の理由**（5件）

```
 第1月  湯の元のひとり暮らしさん  古家（両方）   「県外の家族と同居するため」
 第2月  北団地の持ち主さん        中古住宅（建物）「A市に住み続けられるため」
 第15月 湯坂下の持ち主さん        家（建物）     「子供の進学のため、条件を検討する」
 第31月 魚市場前の診療所の院長    診療所（両方） 「地域医療継続のため」
 第32月 同上（町を出たあと）      駐車場（土地） 「地域医療継続のためX社の提案を受諾」
```

**建物だけを売った2人は、A市に残って同じ家に住んでいる。** 第2月の人は理由に
「A市に住み続けられるため」と書いた＝**土地と建物を分けたことが、その人にとって
「町に残る方法」になった**。これは前の版には存在しなかった選び方である。

**断りの一言 699件（696件に記入）で多かった語**

```
不明 217 / 条件 106 / 生活 81 / 地域 38 / 必要 38 / 時期 35 / 継続 25 / 海外 18
```

同じ文言の上位＝「具体的な条件提示がないため」29件、「支援内容の確認が必要」23件、
「支援内容が不明瞭なため」22件、「現在の生活を維持したい」11件。
**X社が最も多く使った「支援」という言葉が、そのまま最も多い断りの理由になっている。**

### 4-6. 出品（売りに出す）の4択は、どう選ばれたか

のべ1,629回の判断のうち、**「出さない」1,512回（92.8%）**。出したのは117回で、
内訳は**「建物だけ」66・「土地だけ」40・「両方」11**。出したのは11人だけで、
うち2人（駅裏の持ち主さん・浜町の旅館のご主人）は36か月すべての月で出し続けた。
**「両方」＝全部手放す形はいちばん選ばれなかった。**

### 4-7. 持ち主が変わった後の声（20件）

第15月に建物を売った湯坂下の持ち主さんは、そのあと市役所の窓口を探し続けている。

> 第18月「X社から建物の購入の申し出がありまして、市役所の窓口で相談したいのですが、
> どのような手続きになりますでしょうか。」
> 第22月「X社さんからの建物の購入の件で、市役所の担当の方に詳しいお話を聞きたいのですが、
> どなたかご存知ないでしょうか？」

この人は建物を売ったあとも**土地を持ち続けている**（だからX社の提示は届き続ける）。

### 4-8. 「海外」という言葉

X社は自己紹介で毎回「私どもは海外の不動産投資会社です。」と名乗る（704件）。
これに触れた町の側の文章は、発言318件中7件・内心318件中13件・断りの理由696件中18件だった。

## 6. 言えないこと（重要・先に書く）

1. **1本の走行である。** seed（乱数の種）も1つ。5件と6件の差は誤差の範囲かもしれない。
   「土地と建物を分けたから減った」とは言えない。
2. **「借家のある区画が0件」も1本の結果である。** 133件の提示に対して0件は目を引くが、
   全体の成約が5件しかない以上、統計的な主張はできない。**仮説としてだけ持ち出すこと。**
3. **X社は実行できない約束を書けてしまう。** 「維持管理し、必要に応じて改修いたします」
   「良好な関係を維持し」は、世界に実行する仕組みが無い。世界が検査しているのは
   「その人がその区画のその権利を持っているか」だけである。断りの理由に「支援内容が不明瞭」が
   多いのは、**約束の中身を確かめる方法が世界に無い**ことの裏返しでもある。
   これは前の版（v8d）から引き継いだ既知の限界で、v9で新しく生じたものではない。
4. **X社は40回、持っていない権利に声を掛けた**（`acquirer_invalid_offer` 40件・全体の5%）。
   ほぼ全部が「借地に自分の家を建てている人へ、土地と建物の両方を求めた」ものである。
   世界はそれを配らずに数えただけで、X社にその失敗を教えていない。
   **X社の読み違いも観測対象**として残してある。
5. **使用者への通知は0件だった。** 仕組みは動いているが（mockでは20件配送を確認）、
   実際に売れた5件はすべて「持ち主自身が使っている区画」だったため、通知の相手がいなかった。
6. **町にいない持ち主は会話をしない。** 情報の非対称は設計どおりで、事故ではない。
   応諾率の差（0.92% 対 0.37%）はこの非対称込みの数字である。
7. **「不在地主」という呼び名だけは町外だと読めてしまう**（前の版から凍結された名前で、
   変えられない）。この1人を除いた感度も `emergence_v9.json` に併記した（結論は変わらない）。
8. **出品の一覧は、公の記録と言いながら、実際に読むのはX社だけ**である
   （前の版から同じ）。町の人が「誰が売りに出したか」を見る経路は、この世界には無い。
