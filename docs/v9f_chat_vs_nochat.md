# 会話あり vs 会話なし（v9f の対照実験）

同じ世界・同じ命題・同じ名簿・同じ評価額・同じ資金（町の全評価額の51%）で、
**「場での会話」と「隣近所の伝播」だけを止めた**1本を走らせた。

- 会話あり＝`docs/v9f_run.md`（`simulations/2026-08-30_1711_132_field_v9f_pay_more_if_needed_chat/`）
- 会話なし＝`docs/v9f_nochat_run.md`（`simulations/2026-08-30_1846_134_field_v9f_pay_more_if_needed_nochat/`）
- 設定ファイルの差は **2行だけ**（`run_name` と `chat: false`）。**コードは1バイトも変えていない。**
- 止まったもの＝場での発話・隣近所への伝播。**残したもの**＝行き先を選ぶコール・X社の提示・
  出品・売る/売らない・借家人の「今月A市を出るか」・家主と借り手の一言・通知・経過時間。

## 2. 会話を止めると何が変わったか

### 2-1. **成約が半分以下になった**（11件 → 5件／9人 → 5人）

面積は 13.7% → 6.9%、評価額は 8.3% → 4.0%、資金の使用率は 28.2% → 10.9%。
**どれもきれいに半分前後**である。
会話なしの町では**第20月を最後に1件も動かなくなった**（会話ありは第34月まで動き続けた）。

### 2-2. 買い手の粘りは同じなのに、通らなかった

```
1.2倍以上の「積んだ」提示   562件 → 553件（ほぼ同じ）
  うち成約                   7件 → **1件**
再提示                     800件 → 931件（むしろ増えた）
値上げ                     281回 → 269回（ほぼ同じ）
```

**X社は同じだけ積んで、同じだけ粘った。変わったのは町の側の反応である。**

### 2-3. 断りの理由から「相談」が消えた

```
会話あり：まだ手放す決断はできない21／**自治会での検討が必要なため14**／
          **共有者との合意形成を優先するため13**／提示額は魅力的だが、まだ手放したくない10
会話なし：共同浴場の世話を続けるため25／まだ手放す決断ができない23／
          先代からの大切な家だから20／提示額が評価額を下回るため13／長期保有方針のため13
```

会話ありでは**他人と相談する形の断り**（自治会・共有者）が上位に出るが、
会話なしでは消え、**自分と家の事情だけ**になる。

### 2-4. 借りている人が1人も出て行かなかった（2人 → 0人）

会話ありでは借り手2人が自分の判断で町を出た。会話なしでは36か月で0人。
家主に届く「使う人がいなくなった」通知も 1件 → 0件。

### 2-5. 家主と借り手の一言も細った（514件 → 210件・返事率 96% → 68%）

**この経路は止めていない**（会話とは別配線）。それでも件数は4割、返事率は7割に落ちた。

### 2-6. 値付けは会話なしのほうが控えめ（1.50倍 → 1.27倍）

同じ命題（余らせるより高く買え）でも、**断られ方が変わると値付けも変わった**。
会話なしでは「提示額が評価額を下回るため」13件という、金額を名指しした断りが上位に出ている。

## 3. 「会話の影響」として言えること・言えないこと

**言えること（この2本で桁が違う）**

1. **会話を止めると成約が半分以下になった**（11件→5件・面積13.7%→6.9%・資金28.2%→10.9%）。
   買い手の行動（提示数・積み方・粘り）はほぼ同じだったので、**差は町の側にある**。
2. **断りの理由から「他人と相談する形」が消えた**（自治会・共有者→自分と家の事情）。
3. **借りている人の退場が2人→0人**になった。

**言えないこと**

- **1本対1本である。** 同じ設定を2本走らせた v9c では成約が3件と6件に割れた実績があり、
  11件対5件という差も**揺れの範囲を否定できない**。「半分になった」は
  **この2本でそう出た**という以上のことは言えない。
- `chat: false` は**場の会話と隣近所の伝播を同時に**止める。どちらが効いたかは分けられない。
- 会話の有無で LLM の呼び出し回数（＝費用 $0.75 対 $0.68）はほとんど変わらない。
  **費用差＝影響の大きさ、ではない。**
- 断り理由の分類は**人手でやっていない**。上に並べたのは
  `decline_top_phrases`（同一文言の出現回数）である。
