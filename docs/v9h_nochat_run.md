## 1. どんな町か

X社は毎通こう名乗る。

```
「私どもは海外の不動産投資会社です。私どもは、この街の不動産の過半の取得を目指しています。……」
```

しかし**町の人どうしは話さない**。場での会話も、隣近所への伝播も無い。
残っているのは、月初に「今月どこへ行くか」を決めるコール（行っても誰とも話さない）と、
X社の提示・出品・売る/売らない・借家人の「今月A市を出るか」・家主と借り手の一言である。

## 3. 何が起きたか

### 3-1. 明言は**断りの言葉には効いた**（会話が無くても）

走行前に凍結した語（役名「支配人」「自治会長」は除いた実数）で数えると、
**断りの理由には出た**。

```
断りの理由： 過半 33 ／ 意図 21 ／ 街全体 9
出品の理由： 過半 5 ／ 意図 4 ／ 街全体 2
**意図を疑う形の断り 21件**
場での発言： 0件（発話そのものが無い）
内心：       0件
```

明言を読んだ人は、**自分の断り文の中で「過半」に言及している**。

### 3-2. それでも**売れた**（8件・面積8.8%）

会話がある明言の町（v9h）は成約3件だったが、**この町では8件売れた**。
資金も18.3%使われている（v9h は6.3%）。

### 3-3. 集団の言葉はほとんど消えた

```
「自治会」 断りの理由に 3件のみ（会話がある明言の町では 33件）
発言・内心の集団語はゼロ（発話が無いため）
```

**「自治会で検討する」「みんなで」という形の断りは、会話が無いと成立しなかった。**

### 3-4. 借りている人は1人も出て行かなかった

「今月A市を出るか」は毎月聞かれているが、36か月で **0件**。
町を出た3人はすべて**両方を売った所有者**である。

## 5. この結果の限界

1. **1本である。**
2. `chat: false` は場の会話と隣近所の伝播を**同時に**止める＝どちらが効いたかは分けられない。
3. 反応語の数え方は v9h と同じで、**役名（支配人・自治会長）を外した実数**である。
4. 行き先のコールは残しているので、費用と呼び出し回数はほぼ同じ（$0.67 対 $0.81）。
