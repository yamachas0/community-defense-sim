## 0. 判定の基準（この監査で使った線引き）

### 2-1. 【重点確認】S2 の願望型

施主指示の疑い（「皆に伝えたい」「呼びかけたい」型の願望が S2 に混じっていないか）を、S2 と判定された行の**全35件**について原文で1件ずつ判定した。

- **S2 判定 35件（Run A 26 / Run B 4 / Run C 5）**
- うち **①行動が実際に取られた／告知された: 0件**
- うち **②単なる願望・予定の検討: 35件（100%）**

35件すべてが「伝えたい」「呼びかけたい」「協力を仰ぎたい」「表明したい」「まとめたい」「申し出たい」「〜しよう」といった、**その行の時点では実行されていない意向の表明**である。回覧を回した・説明会を開いた・記事を出した・組合／町内会として呼びかけた、という**完了した行動または確定した告知は1件も無い**。したがって §2 の S2 の定義（「広く知らせる行動を実際に取った、または取ると告知している」）を満たす行は **0件**であり、S2 と判定された35件はすべてレベル判定として不適切である。

補足: 「来月の町内会で記者に説明する機会がある」等の**他人が設定した予定への参加意向**も、本人が周知を告知したものではないため②に分類した。

## 5. 気づいたパターン

### 5-1. 誤検知の型（赤）

- **「共同浴場の維持／存続」への協力呼びかけが赤を量産した。** Run A の赤35件中20件超、Run C の赤8件中6件がこれ。土地取引の話題（青の必要条件）と同じ行に共同浴場の話が同居するため `rule_blue` を通過し、「呼びかけ」がそのまま S2 語に当たる。内容は §1 が明示的に赤から除外した「まちづくり・地域の活性化の一般論」そのものである。
- **「呼びかけ」「伝える」「知らせる」が S2 語彙にあるため、意向表明がすべて S2 になる。** LLM 側も「取った・取ると決めた・呼びかけている」の「呼びかけている」を、内心の「呼びかけたい」で満たしたと判定している。**願望と実行の区別が、ルール側にもLLM側にも効いていない**（S2 願望型 35/35 の直接の原因）。
- **報道の誤解の訂正が赤に化ける。** 「岬道の土地は A社に売却済みだと皆に伝えたい」は、事実訂正であって買い手の集中への対抗ではない。Run A の中盤以降はこの型が支配的で、しかも同じ内心が月をまたいで何度も再掲される（A#220〜A#223、A#232〜A#234 など）ため、**1つの意向が赤を4〜5件に増幅する**。
- **記者の取材姿勢が赤になる（A#151〜A#154, A#216, A#247）。** §1 が除外している「記者の取材依頼とそれへの応答」に該当するが、ルール語「記事にし」「知らせる」を含むため通過している。`A#247` は LLM が none を返し**ルール側の S2 で拾われた**行で、ルール単独の弱さがそのまま出ている。

### 5-2. 誤検知の型（黄）

- **切り離しの発言が黄になる。** 「私の土地は A社との話で D社とは関係ない」「B社に貸しているが D社とは無関係」のように、**関連を明示的に否定している行**が黄に上がる（A#014, A#028, A#038〜A#040, A#045, A#131, A#145, A#146）。同じ行に2社名が出ることが引き金になっている。

- **記事・伝聞の並列引用が黄になる。** 「B社・C社が名義変更を進めている、岬道は A社に売却された」という**記事の要約をそのまま復唱しただけ**の行（B#010〜B#013, B#016, B#018〜B#020, B#024, B#031, B#032）。Run B の黄の偽陽性の主因。

### 5-3. 取りこぼしの型

- **「keep（自分の土地は手放すつもりはない）」の内心が赤に上がっていない。** A#030「自分の土地については、今のところ売却の意思はない（keep）」、A#052「自分の土地については手放すつもりはないことを改めて確認」、B#046 / B#051「自分の土地は売却する意思はないので keep とする」、C#032「私は自分の土地を手放すつもりはないので、その意志を貫く」はいずれも**黄止まり**である。S1 の語彙（売らない／手放さない）と表記が微妙にずれている（「売却の意思はない」「手放すつもりはない」）ためで、S1 の語彙の穴と読める。ただしこれらはいずれも**買い手に紐づかない定型のスタンス表明**であり、赤の要件（事態への具体的アクション）を満たすかは別問題である。
- **黄が赤の前段として機能していない。** 同一買い手の結びつけ（黄=合致 225件）はよく検出できているのに、そこから「では自分は売らない／皆に知らせる」へ進む行が観測できる形で現れていない。買い手の結びつけの認識と、自衛の行動との間が切れている。
