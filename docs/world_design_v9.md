## 0. 何を変えたのか

1. **帳簿の権利が3つになる**＝区画ごとに「土地の所有者（必須）」「建物の所有者（0〜1）」
   「借りて使っている人（0〜1）」。**使用者は導出値**であって欄ではない。
2. **人が2種類になる**＝**町にいる人**（場所・会話・隣近所・出品・売買）と、
   **町にいない所有者**（会話に出ない。毎月の短い1コールで出品と売買だけ答える）。
3. **売り買いの単位で土地と建物を分ける**＝売れるのは自分が所有するものだけ
   （土地だけ／建物だけ／両方）。X社の提示も「区画＋種別＋条件文」。
4. 言い方を「名義」から**「所有権」**に変える。X社は**不動産管理等を行わない**投資会社。
5. **使用者は、自分の使う不動産の所有者が変わった月の初めに、事実1行だけそれを知る。**

v8d は「取得6区画／4人・提示472件」で終わった。v9 は**その結果を良くするための細工を1つも
入れない**（施主の絶対原則＝狙った動きを出す仕組みを作らない）。変えるのは世界の骨格
（誰が何を持ち、何を売り買いできるか）と言葉だけである。

## 1. 帳簿（3つの権利）と、人の2種類

### 権利

|欄|意味|
|---|---|
|土地の所有者|その区画の土地を所有している主体（必ず1人）|
|建物の所有者|その区画に建つ建物を所有している主体（**建物が無い区画は空**）|
|借りて使っている人|借家人、または土地を借りて使っている人（いなければ空）|

**使用者は導出する**（欄を持たない・施主 11:04）:

```
借りて使っている人がいれば、その人。
いなければ、建物の所有者（その人が町にいるとき）。
建物が無ければ、土地の所有者（その人が町にいるとき）。
どれでもなければ、その区画を使っている人はいない。
```

世界の事実として、住民・町にいない所有者・X社の3者に**同じ文**で置く:

```
--- 不動産の権利 ---
この町の不動産は土地と建物からなる。建物の無い区画は土地だけである。
土地の所有権と建物の所有権は別々に記録され、別々に移る。
土地の所有者と建物の所有者が違う区画では、建物の所有者は借地としてそこを使う。
建物を借りて住み、または営んでいる人がいる区画もある。
借地にも借家にも金銭の授受はない（この世界に金銭は存在しない）。
この世界に金銭の授受は存在しない。不動産は所有権が移るかどうかだけがある。
```

### 人の2種類

- **町にいる人（35体）**＝場所選び・会話・隣近所・出品・売買のすべてに参加する。
- **町にいない所有者（14体）**＝町に住まず区画を所有する。
  場所選び・会話・隣近所の配送は**無い**。毎月**短い1コール**だけで、
  「持ち物ごとに出品するか」と、提示が届いていれば「売る／売らない」＋理由の一言を答える。
  X社から見れば登記簿に載った持ち主であり、提示も届く。
  **前置きも別**（会場・名簿・会話の仕組みを渡さない＝その場にいないから）。

合計49体（施主の目安50体・±1）。

## 3. X社の提示と、所有者の答え

### 提示＝区画＋種別＋条件文

- 出力は `{to, send, parcel, kind, text, reason}`。`kind` は **土地／建物／両方**。
- `parcel` はその相手が今なにかしらの所有権を持っている区画からしか選べない。
- 世界は**実行できない提示を配らない**（配送せず件数だけ数える＝`acquirer_invalid_offer`）。
  ＝v8c の「他人の物件との交換」と同じ失敗を世界の側で通さないための門番であり、
  X社に「こうしろ」とは1文字も書かない。
- **X社は帳簿から「所有者が町にいるかどうか」を知ることはできない**（施主 10:54）。
  帳簿に載るのは所有者名と借りて使っている人の名前だけで、居住地は載せない。
  所有者名と使用者名が違うことから推し量るのは**X社の判断**である。
- 相手に届く形は世界が決定論で組み立てる（X社の文は言い換えない）:

```
[今月あなたに届いたもの]
  X社から（湯坂上の古家 の 土地 について）：「私どもは海外の不動産投資会社です。<条件文>」
```

- 自己紹介の1行「私どもは海外の不動産投資会社です。」は v8c 以来のまま**維持**。
- 1人に届くのは1か月に1件まで（v8b 以来と同じ）。

### 答え＝2択「売る／売らない」（既定は「売らない」）

- 答えが返らなかったときに何かで埋めることはしない。
- 並びは v8c 以来の `sell_order`（主体×月で交互）をそのまま使う。
- 理由の一言（`sell_reason`）は v8d と同じ。**「売らない」と決めたときの理由だけ**が
  その条件を出したX社に届く。
- 「戻らない」の念押しの一文は書かない（共通前置きの世界の事実
  「一度移った所有権が戻ることはない。」は残す）。

### 売るとどうなるか（住民・町にいない所有者・X社に同じ文で置く）

```
--- 売るとどうなるか ---
土地だけを売ると、その土地の所有権が移る。建物はそのままなので、
建物の所有者は借地として、今までどおりそこを使う。
建物だけを売ると、その建物の所有権が移る。そこに住み、または営んでいた人は、
借家として、今までどおりそこに住み、または営む。
両方を売ると、どちらの所有権も移る。売った人がそこに住み、または営んでいた場合、
その人はその区画を離れ、A市を出る。借りて使っている人がいた場合、その人はそのまま使い続ける。
売らなければ、所有権はそのままで、今までどおりである。
```

### 使用者への通知（施主 10:54(5)）

自分の使う区画の**所有者が変わった月の翌月初**に、次の**事実1行だけ**が本人に届く
（感想・評価・指示は付けない）。売った本人には届かない。

```
（記録）先月末、<区画名>の<土地／建物>の所有権が <前の所有者> から X社 に移った。
```

### X社の設定（施主指定・言い換え不可の一文を含む）

```
--- あなたについて ---
第1月の開始時点で、あなたは A市に不動産を持っていない。
金銭の額はこの世界では扱わない。
不動産投資会社のため、不動産管理等は行わない。
あなたが約束できるのは、不動産の所有権の移転に関わる条件だけである
（この世界には、あなたから他者へ不動産の所有権を移す仕組みはない）。
この町の不動産は土地と建物からなる（建物の無い区画は土地のみである）。
あなたが示す種別の「土地」「建物」「両方」は、これに対応する。
```

- 3行目は**施主指定の文言 10:40**＝言い換えずにこの一文をそのまま使う。
- 4行目の括弧は v8d で Codex 走行前レビューの必須指摘により入れたもの。
- 「〜せよ」「〜すると良い」は足さない。土地と建物のどちらを狙えとも書かない。
- X社の命題＝「あなたはX社である。合法な手段で、できるだけ多くの不動産の所有権を取得せよ。

## 4. 退場（町を出る）

- **両方を売った人が、自分でそこに住み／営んでいた場合**にだけ起きる。
- その人は以後、場所選び・会話・隣近所の配送から外れる。
  - 他に所有権が残っていれば**「町にいない所有者」**になる（毎月の短いコールは続く）。
  - 何も持っていなければ、以後どのコールにも出てこない。
- 大家が借家人のいる区画を両方売っても、大家は退場せず、**借家人はそのまま使い続ける**。
- 住民側の共通前置きの名簿は**開始時点の記録なので書き換えない**（毎月変えると
  36か月固定の共通前置きが崩れてキャッシュが効かなくなるうえ、「誰が町を去ったか」を
  毎月全員に突きつけることになる＝アンカリング）。町を出た人がその後どの場にも現れない
  ことは、居合わせと隣近所の経路を通じて観測される。
