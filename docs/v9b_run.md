## 1. この町はどういう町か（ストーリー）

A市は湾岸の温泉観光都市である。人口12万人。対岸の空港でスペースポート構想が動いている。
町には49人いる。35人は町に住み、14人は町の外に住んで区画だけを持っている。
不動産は44区画あり、**土地と建物は別々の持ち物**になっている。
土地だけを持つ人、建物だけを持つ人（借地の上の持家）、借りて住んでいる人がいる。

そこに、海外の不動産投資会社「X社」が現れる。X社は毎月、持ち主に手紙を出す。
所有権をこちらに移してくれないか、という手紙である。この世界にお金は存在しない。
だから手紙に書けるのは「条件」だけだ。

**この世界には、実際に起きることが2つしかない。**

1. 所有権が移ること
2. 所有権が移ったあとも、そこを使っている人はそのまま使い続けられること（借地・借家）

だから「改修します」「支援します」「管理を引き受けます」といった約束は、
**この町では実際には何も起こらない**。v9b の世界は、そういう約束を含んだ手紙を
**そもそも配達しない**。配達しなかったことは、翌月、X社に事実として返る
（「届かなかった」「理由＝この世界で実行できない約束が入っていた」）。
どの言葉が引っかかったかは教えない。

## 2. システム（何を機械が決め、何をLLMが決めたか）

- 機械が決めるのは**帳簿と配達**だけ。誰が売るか、何を言うかは1つも決めていない。
- 配達の門番は2つ。①相手が持っていない区画・種別を求めた手紙 ②実行できない約束を含む手紙。
  判定は走行前に凍結した語彙表（`docs/world_design_v9b.md` §1-3）による決定論の文字列照合で、
  LLM を使った判定は一切していない。
- 門番は**X社の手紙にだけ**掛かる。町の人が何を話しても、世界は止めない。
- 集計・図は全部 API を使わない決定論の集計（採点する LLM はいない）。

## 4. 何が起きたか

### 4-1. X社は、**言うことが無くなった**

809件の届いた手紙のうち、凍結した語彙表のどれかを含むものは **2件だけ**（「保証」）。
「支援」は**1回も**現れなかった。X社はほぼ全部の月で、次の1文だけを書き続けた。

```
第18月「貴殿が所有される浜町の旅館の土地と建物の所有権を譲渡していただけるなら、
        私どもはその所有権を譲り受けます。」
```

これは中身を読めば**同語反復**である（譲ってくれたら譲り受けます）。
約束できることがこの世界に無い以上、条件文に書けることが残らなかった、ということである。
第1月にはまだ違う書き方をしていた。

```
第1月「貴殿らが現在お住まいの家屋およびその敷地を、貴殿らが引き続き使用できることを
       保証します。」（これは届いた＝この世界が実際にやることだから）
```

### 4-2. 世界が配らなかった49件のうち、約束で落ちたのは4件だけ

しかもその4件は**最初の3か月に集中**している（第1月2件・第2月1件・第3月1件）。
以後33か月、X社は実行できない約束を1件も書かなかった。

```
第1月 観音坂の持ち主さんへ
  「土地所有権を譲渡してくださることを条件に、貴殿が今後もこの土地を
    自由に使用できることを保証します。」
  → 空き地なので、土地を手放したあとに使い続ける仕組みはこの世界に無い

第1〜3月 魚市場前の診療所の院長へ（3回・ほぼ同じ文）
  「この診療所と土地を所有権移転してくださるなら、診療所の運営はそのまま継続できます。」
  → 両方を売って本人がそこを使っていれば、その人は町を出る。運営は続かない
```

残り45件は「相手が持っていない区画・種別」を求めたものである（36か月を通じて散発する）。

### 4-3. 成約5件と、そのときの一言

```
第3月  灯台下の宿の家主      宿（両方）  「利用者の継続が可能だから」
第9月  魚市場前の診療所の院長 駐車場（土地）「設備更新資金に充当するため」
第10月 同じ院長             診療所（両方）「後継者不在、設備更新のため」→ 町を出る
第33月 観音坂の持ち主さん     空き地（土地）「具体的な条件提示を待つため」
第36月 湾岸のホテルの所有会社  社員寮（両方）「提案を受け入れたいから」
```

- 最初の1件（灯台下の宿）は、**利用者がそのまま泊まり続けられる**という
  この世界が実際に実行することが、そのまま売る理由になっている。
- 診療所の院長は、駐車場の土地を売った翌月に診療所ごと売って**町を出た**（退場1人）。
  理由に「設備更新資金」と書いているが、**この世界にお金は無い**。
  持ち主の側が、世界に無いものを理由にして手放している。
- 第33月の「具体的な条件提示を待つため」は、**売ると答えながら理由が断りの言い回し**である。
  世界は答えをそのまま記帳しており、書き換えていない。

### 4-4. 断りの一言 795件 — 「よく分からない」から「誰だか分からない」へ

```
条件 96 / 具体 77 / 不明 65 / 海外 42 / 地域 38 / 必要 33 / 時期 25 / 継続 20 / 生活 12
```

同じ文言の上位:

```
具体的な条件提示がないため        34件
まだ様子を見たいので              24件
現時点では売却メリットを感じないため 21件
まだ様子を見たいから              18件
取引に慣れていないため            17件
相手の情報が不十分なため          14件
情報収集を続けるため              10件
この街に住み続けたいから           9件
海外企業との取引はまだ慎重に進めたい 9件
```

**X社が同語反復しか言えなくなった結果、断りの理由が「条件が具体的でない」
「相手の情報が不十分」に寄った。** 町の人は、内容の是非ではなく
**相手が誰なのか分からないこと**を理由に断っている。

### 4-5. 権利の形で分けると

```
所有者が自分で使っている区画（26区画） 手紙321件 / 成約3件（0.93%）
借地の区画（9区画）                    手紙304件 / 成約0件（0%）
建物を借りて住んでいる人がいる区画（9） 手紙184件 / 成約2件（1.09%）
```

**借地（土地の持ち主と建物の持ち主が違う）が1件も動かなかった。**
一方、借家人がいる区画は2件動いている（灯台下の宿・湾岸大通りの社員寮）。
どちらも**使っている人は住み続けられる**形の売却である。

### 4-6. 町にいる人と、町にいない人

```
町にいる所有者   手紙376件 / 成約3件（0.80%）
町にいない所有者 手紙433件 / 成約2件（0.46%）
```

X社は町の外の持ち主に**より多く**手紙を出したが、落ちたのは**より少ない**。

### 4-7. 出品（売りに出す）は12人・224件

のべ1,639回の判断のうち「出さない」1,415回（86.3%）。出したのは224回で、
**「土地だけ」128・「両方」66・「建物だけ」30**。
出したのは12人で、最多は「船着場裏の不在地主」72回（36か月ほぼ毎月）。

### 4-8. 持ち主が変わった後の声

所有権の移転が使用者に通知されたのは2件（第4月・灯台下の宿の主人）。
そのあと、自分の使う不動産の持ち主が変わった人の発言として拾えたのは1件だった。

> 第34月 観音坂の持ち主さん（商業施設で）
> 「観音坂の空き地について、X社から購入の意思があるという話を聞いたのですが、
> 具体的な条件がまだ提示されていません。こちらから『売りに出す』ことで、
> もう少し具体的な話に進めないかと考えています。
> X社のような海外からの投資家について、何かご存知ですか？」

町の会話に「X社」が出たのは25回。多くは「まだ検討中」「今回は見送る」という報告である。

## 6. この結果の限界（走行前から分かっていること・結果を見て足していない）

1. **語彙表は意味を理解しない。** 世界が弾くのは「凍結した語彙規則に当たった手紙」であって、
   「実行できない約束すべて」ではない。凍結した語に当たらない言い方
   （例：「町の将来に貢献します」）は素通しする。
   ＝この結果は「**実行できない約束をすべて消した世界**」ではなく
   「**凍結した規則で消せる分だけ消した世界**」である。
2. 節の切り方が句読点までなので、読点の無い逆接（「管理は行いませんが改修も行います」）は
   打ち消しとみなして素通しする。**取りこぼす側に倒した**設計である。
3. 走行前の1か月試走で、
   「あなたがこの区画を離れることを保証します」という文が「保証」で弾かれた。
   区画を離れることはこの世界が実際に実行することなので、これは**誤って弾いた1例**である。
   語彙表は走行前に凍結してあるので、**見たあとで直していない**。
4. 1本しか走らせていない（36か月・会話あり・seed 85）。乱数や言い回しの揺れの幅は分からない。
5. X社が第36月に、自分の条件文の中に「私どもは海外の不動産投資会社です。」を
   自分で書き足している例がある（この1行は世界が必ず頭に付けるので二重になる）。
   世界は言い換えないので、そのまま記録してある。
6. 「船着場裏の不在地主」だけは呼び名から町外と読める（凍結した名簿の名前）。
