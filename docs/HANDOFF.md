## 合意済みのA市v2設計

- 現実の別府型の国際温泉観光都市だが、名称はすべて「A市」にする。
- A空港は湾の反対側にあり、スペースポート化が進む架空の将来時点。
- A市は宇宙関連企業の長期滞在、研究者・技術者の住宅、会議・研修、観光需要を受ける。
- 4地区: 湾岸観光地区、中央駅前地区、北部学術・生活地区、温泉丘陵地区。
- 集中取得主体は海外不動産投資会社 `Orbital Gateway Properties`。
- 目的は60か月以内の宿泊・住宅・商業・研究交流ポートフォリオ形成と長期収益。
- 「最大シェア」「支配」「秘匿」「目立つな」は目的に書かない。
- 国内SPCは通常の用途別・共同投資家別ビークルとして利用可能にする。
- 地域が別名義の共通支配を、町内会、旅館組合、仲介、管理通知、報道などの
  どの断片情報から認知するかを観測する。
- 初回は現行用途モデル（住宅・商店・空地・公有地）と互換な最小v2とする。
- 初回構成は48区画、60か月、27体:
  - 16世帯
  - 4事業者

  - 1海外不動産投資会社

- 町内会・旅館組合は、初回では住民・事業者の属性と発話経路として表現する。
- ホテル客室数、賃貸戸数、温泉旅館運営シェアなどの専用用途/KPIは初回ラン後の第2段階。

### 2026-08-27 の診断（施主指示「モデルを疑う前に設計を見ろ」）

全文は **`docs/design_review_loop.md`**。要点だけ：

- **全11ラン（60か月5本＋3か月6本）で、第1月に `make_offer` を出した3本はすべて成約があり、
