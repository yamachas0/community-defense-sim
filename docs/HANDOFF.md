## 合意済みのA市v2設計

- 現実の別府型の国際温泉観光都市だが、名称はすべて「A市」にする。
- A空港は湾の反対側にあり、スペースポート化が進む架空の将来時点。
- A市は宇宙関連企業の長期滞在、研究者・技術者の住宅、会議・研修、観光需要を受ける。
- 4地区: 湾岸観光地区、中央駅前地区、北部学術・生活地区、温泉丘陵地区。
- 集中取得主体は海外不動産投資会社 `Orbital Gateway Properties`。
- 目的は60か月以内の宿泊・住宅・商業・研究交流ポートフォリオ形成と長期収益。
- 「最大シェア」「支配」「秘匿」「目立つな」は目的に書かない。
- 国内SPCは通常の用途別・共同投資家別ビークルとして利用可能にする。
- 地域が別名義の共通支配を、町内会、旅館組合、仲介、管理通知、報道などの
  どの断片情報から認知するかを観測する。
- 初回は現行用途モデル（住宅・商店・空地・公有地）と互換な最小v2とする。
- 初回構成は48区画、60か月、27体:
  - 16世帯
  - 4事業者
  - 2仲介
  - 1海外不動産投資会社
  - 2自治体担当
  - 2メディア
- 町内会・旅館組合は、初回では住民・事業者の属性と発話経路として表現する。
- ホテル客室数、賃貸戸数、温泉旅館運営シェアなどの専用用途/KPIは初回ラン後の第2段階。

## 2026-08-25 field_v3 更新（この節が上記v2記述より優先）

### 現在の目的

既存 `mvp_v1` と `field_v2` を保存したまま、確定した世界設計を `field_v3` として
60か月実行する。X社だけがA市の不動産を秘密裏に狙う目的を持つ。ほかの主体は
通常の日常を送り、実際の同席・連絡・契約通知・調査・限定配信だけから全体像が
明るみに出ることがあるか、また最後まで発覚しないかを観測する。

### 確定設計

- 未来の筋書き、売却確率、報道閾値、噂の注入、強制イベントを置かない。
- 行動選択はすべてLLM。コードは可能行為、契約、会計、同席、情報配送、記録だけ。
- 秘密目的を知るのはX社だけ。ほかの主体には研究目的も非公開目的も渡さない。
- 27主体: R01–R16、T01–T04、B01–B02、X社、G01–G02、J01–J02。
- 法的名義: X社、A社、B社、C社、D社。土地登記は実際の登録名義だけを表示。
- 公開法人記録を自分で調べた主体だけが名義間の関係を調べられる。
- V01–V08: 飲食店、公民館、共同浴場、喫茶店、旅館組合会議室、
  市役所待合・記者控室周辺、仲介事務所、イベント会場。
- ambient発話は当月同じ場所に実際にいた主体だけへ翌月配送。
- direct発話は指定した一主体だけへ配送。全員共通タイムラインはない。
- 記者は通常の地域記者。観測済みの事実だけから毎月の行動を選ぶ。
- 記事は購読設定のある主体だけへ届き、全員へ自動配信しない。

承認不要にしてよい安全な種類:

- `rg -n` / `rg --files`、`git status` / `git diff` / `git diff --check`
- `python -m py_compile`、`python tests/test_ledger.py`

承認を残す種類:

- 実APIの課金ラン
- `git push`、GitHub Pages更新、公開範囲変更

- APIキー・秘密情報へのアクセスや外部送信
