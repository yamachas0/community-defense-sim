## 1. 先に結論（土地の話に限らない）

1. **土地の売買は、この世界の主役ではなかった。** 3本とも、会話量で最大の塊は「共同浴場をどう維持するか」「空き家・空き地をどう使うか」「集まりをどう開くか」といった**まちの世話の話**である。買い手（A/B/C/D社）の名前は、その話の**材料として**出てくる。
2. **3本で「まちの中心議題」が別々に立った。** A＝噂の訂正（管理委託）、B＝共同浴場跡地の名義、C＝住民が自主開催した情報交換会。**同じ台本・同じ世界・同じ入力なのに、町が抱えた課題が3本で違う。**
3. **日常の場（共同浴場・床屋・回覧板・スーパー）は、議題の“着火点”として実際に機能した。** 公の場（地区公民館・地域イベント会場）は着火点ではなく**増幅器**である。3本とも、後に町の中心議題になった論点の**最初の一言は日常の場で出ている**（B の名義問題＝共同浴場、C の情報交換会＝仲介の事務所の立ち話、A の維持費＝床屋）。
4. **話が止まる場も明確にある。** 小学校の校門前・診療所の待合・神社の境内は、**他所で出た話の受け取り・確認**しかしない（自分で議題を立てない）。特に C の校門前は6回のうち5回（83%）が土地の話ゼロ、A の旅館組合は40%が同様。
5. **「売らない」は第2便でも同じ会場（隣家の玄関先）で公言されていたが、分類器が拾っていない。** B 第18月・C 第23月に住民が「うちの土地は売るつもりはない」「手放すつもりはない」と隣人へ公言している（判定は緑／色なし）。第1便A で台本を止めたのは同じ会場・同じ型の「きっぱり断ろう」で、**語が1つ違うだけで止まる／止まらないが分かれている**（→ §6）。
6. **第1便A（第6月停止）と第2便では、町の話題構造が真逆になった。** 第1便は「スペースポート構想」1,434行が全会場を占め、共同浴場（73行）・跡地（3行）・コワーキング（7行）はほとんど育たなかった。**買収が止まると、住民の会話も“買収の噂”に固着する。**買収が最後まで進んだ第2便のほうが、まちづくりの創発が豊かに出た。

**創発の型**：**着火より“持ち込み”**。第1月から「来月の町内会で何を議題にするか」が他会場（床屋・共同浴場）で相談され、公民館はその受け皿になる。

  **B の U01909 は S1（自分は売らないと決める）の実質そのものだが、判定は緑どまりで赤に上がっていない。** RESULTS.md §3 が指摘した S1 の取りこぼし（「売るつもりはない」「手放すつもりはない」が凍結語彙に無い）が、**第1便で止める引き金になったのと同じ会場・同じ型の発言**で実際に起きている。第1便A の U00636/U00643 は「きっぱり断ろう」という語だったから拾われた。**語が1つ違っただけで、止まる／止まらないが分かれている。**

  さらにこの発言は消えずに翌月へ渡っている。**「売らない」が「呼びかけ」に転化した連鎖**：

> [B U02046] 第19月 S3 駅裏の大家さん @隣家の玄関先（回覧板） 緑
> 「そうですね。船着場裏の持ち主さんも売るつもりはないとおっしゃっていたようですし、町内会で皆さんに呼びかけて、良いアイデアを募ってみませんか？皆で集まって、共同浴場跡地と岬道の空き地をどう活用できるか、話し合えたらと思います。」

  つまり第2便の玄関先では、**個人の「売らない」が自衛の連帯ではなく、跡地活用の呼びかけに吸収された**。第1便では同じ場の同じ型の発言が「D社から接触があったら断る／記者に協力する」という自衛の方向に伸びた。**同じ会場が、同じ材料から違う方向へ話を伸ばしている。**
2. **第1便A は町全体が「買収の噂」に固着していた。**スペースポート構想1,434行に対し、共同浴場73行・跡地3行・コワーキング7行・段差11行・補助金6行。**世話の話が育つ余地が無かった。**逆に第2便は買収が最後まで進んだのに、住民の会話はまちづくりへ広がった。
3. **これは1本ずつの対比であり（LLM の出方は同じにならない）、因果としては断定できない。**言えるのは「停止条件を変えると、町が何を話す町になるかまで変わった」ことまでである。

## 8. この読みの限界

1. **話題クラスタは走行後に語彙で束ねた事後の分類**である。判定・停止には一切使っていないが、語彙の選び方で行数は動く（例：T23 引越しは A の「町内会を離れる」を取りこぼしている）。
2. **色（青緑黄赤）は走行時の分類器の出力そのまま**で、第2便には再判定が無い。人手監査（`docs/audit_v5e2.md`）では**赤47行のうち施主定義に合致 0件**・黄の偽陽性 12〜37%。**会場別の赤・黄の数字は、そのまま「その場で自衛が起きた」とは読めない。**
3. **「創発」と呼んでいるのは、原文と時系列と同席関係で追える連鎖**である。因果の証明ではない。deliveries は「誰に届いたか」しか持たず、「その一言が原因で次の発言が起きた」ことは示せない。本文書では**受け手の内心が発言を引用しているケースだけ**を連鎖として挙げた。
4. **3本は1本＝1実現**である。「3/3 で再現」と書いたものも、確率は測っていない。
5. **重複発話が多い**（同じ内容が同一シーンで2回出る）ため、行数は延べであり「異なる発言の数」ではない。
