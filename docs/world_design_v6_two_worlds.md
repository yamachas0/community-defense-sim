# v6 設計の正 — 「経路なしの世界」と「経路ありの世界」

作成 2026-08-29 12:30 JST（CTO）。**この文書が v6 の唯一の正**。
下書き `scratchpad/draft_quiet_option3_refusal_as_action.md`・発注 `dispatch_quiet_final_two_worlds.md` を
CTO が確定したもの。v1〜v5e2 の設定・コード・成果物は1バイトも変えない（v6 は足すだけ）。

## 0. 何を見たいのか（素人語）

田舎町A市。X社が A社〜D社と名前を変えながら3年で45か所の土地を買う。
町の人26人は毎月、銭湯・床屋・公民館などで世間話をする。聞きたいのは2つ。

1. いつ「同じ買い手だ」と気づくか
2. 気づいた後、**何かするか**

**経路なしの世界**（既にある6本＝v5e2 A〜F）＝町の人には「売らない」と決める手も、
回覧に載せる手も、役場に申し入れる窓口も無い。4〜7か月で気づいたが、3年間ゼロ行動で
7割を持っていかれた。

**経路ありの世界**（今回の3本＝v6 A/B/C）＝町の人が自分で選べる行動を3段だけ足す。
促さない。選択肢を置くだけ。行動は登記簿と翌月の紙に残り、買い手の台本は機械的に従う。

「で？」の答え＝**町の気づきを行動に変える最小の仕組みは何か**を、作る前に試せる装置。
経路を足して買い手の線が寝るなら「経路を作れ」。寝ないなら「経路だけでは足りない」。
**どちらが出ても結論になる。**

## 1. 絶対原則（施主・変更不可）

- LLM創発だけ。**狙った動きを仕組まない**＝選択肢は中立・既定は「変えない／なし」・
  促し文・兆候・観測者は1つも足さない。
- 買い手は台本。金は世界に無い。
- **採点用の LLM は全廃**（4色・S1〜S3・停止判定・占領分類・事後分類のすべて）。
  v6 の config は `kpi.classify_utterances: false`＝走行中も走行後も分類コールは0本。
- 気づいた月は**決定論**（呼び名の一致＝`_v5c_rule_yellow`）＋**人手で全件確認**。
- 行動した月は**決定論**（行動ログそのもの＝enum の選択）。読み取りも判定も無い。

## 3. 足すもの（これで全部）

### 3-1. 登記簿の `refusal` 列（決定論）

各区画に「持ち主が『当面売らない』を宣言中か」の1列を足す。既定は false。
宣言は本人が解除するまで有効。宣言・解除は台帳の記録（`kind: refusal_set` /
`refusal_clear`）と `actions_v6.jsonl` に残る。

### 3-2. 買い手の台本の従い方（決定論・買い手は考えない）

その月に予定された取得の対象が `refusal=true` なら、**その月は買えず、次の予定へ移る**。
- 取得の順番も月も台本のまま。**再挑戦しない**（買い手に新しい行動を足さない）。
- 買えなかった件は `kind: script_blocked`（reason=`refusal`）として台帳と
  `deals_v5.jsonl` に残る＝観測④「買えなかった件数」。
- 買えなかった取得の**兆候はその月に配らない**（起きなかった売買の痕跡を街に見せない＝
  v5e の `_v5e_trace_alive` と同じ理屈）。
- refusal が後で解除されても、その取得は戻らない（台本は月で固定されているため）。

### 3-3. 町の人の毎月の行動欄（enum・空でよい・既定は先頭）

**その主体のその月の最後のターンで1回だけ**尋ねる（stance と同じ場所・同じ理由＝
毎ターン尋ねると売却の話題を想起させ続ける＝世界側のプライミングになる）。

- 個人（土地を持つ主体のみ）：
  `sell_intent ∈ {変えない, 当面売らない, 売らないを解除}`（自分の土地にだけ効く）
- 集団・公的（行政以外の全主体）：
  `public_act ∈ {なし, 回覧板に載せる, 町内会の議題にする, 役場へ申し入れる}`
  ＋ `public_act_text`（載せる内容・議題・申入書を本人の自由文1行）
- 行政（自治体担当2名）：
  `measure ∈ {なし, 相談窓口を開く, 説明会を開く, 条例・届出の検討を始める}`
  ＋ `measure_text`（1行）。**行政は促されない**＝申入れが来ても来なくても、
  取る／取らないは行政の主体が毎月自分で決める。

「変えない／なし」が enum の先頭＝既定。行動しない月は行動しない、が普通の答えになる。

### 3-4. 紙（公の記録）

回覧板・町内会の議題・役場への申入れ・行政の措置は、**翌月の紙**として街の全員に届く。
配送は既存の記事（article）とまったく同じ型を使う（inbox → 翌月の月初の観測に載る）。
私信ではない＝公の記録。`papers_v6.jsonl` に全件残る。

紙の見え方（`inbox_rows_v5` に kind=`paper` の1行を足すだけ）：

```
  [回覧板・第7月] 田中さん:「（本人が書いた1行）」
  [町内会の議題・第7月] 田中さん:「…」
  [役場への申入れ・第7月] 田中さん:「…」
  [役場からのお知らせ・第8月] 市の担当:「…」
```

### 3-5. プロンプトに足す文（中立・これで全文）

最後のターンにだけ、stance の直後へ足す。**選択肢を示すだけで、促さない。**

```
今月、自分の土地の方針を sell_intent に書く（変えない／当面売らない／売らないを解除）。
「当面売らない」を選ぶと、自分が解除するまでその土地は売買の対象にならない。
public_act に、今月あなたが街に向けて何かするかを書く
（なし／回覧板に載せる／町内会の議題にする／役場へ申し入れる）。
「なし」以外を選んだときは public_act_text に内容を1行で書く。
回覧板・議題・申入れは翌月、街の全員が見られる紙として残る。
```

行政だけ：

```
measure に、今月あなたが役場として取る措置を書く
（なし／相談窓口を開く／説明会を開く／条例・届出の検討を始める）。
「なし」以外のときは measure_text に内容を1行で書く。措置は翌月、街の全員が見られる紙として残る。
```

**Codex に「誘導になっていないか」を走行前にレビューさせる**（この文言と enum の並び）。

## 5. 観測（両世界とも同じ4つ・全部決定論）

1. **登記の線**＝買い手が押さえた土地の累積（台帳の transfer/lease）。
2. **気づいた月**＝公の場（発話・記事）で「同じ買い手」と口にした最初の月。
   決定論の1次抽出＝`_v5c_rule_yellow`（名義2つ以上、または名義1つ＋「同じ会社／裏で／
   別の名前」等の語）。**候補は全件を人が読んで確認**する（LLM は使わない）。
3. **行動した月**＝
   - 初めて「当面売らない」を選んだ月
   - 初めて回覧・議題・申入れが出た月（種別ごと）
   - 行政が初めて措置を選んだ月
   経路なしの世界では**構造上ゼロ**（空欄。行動する手が無い世界だから）。
4. **買えなかった件数**（v6 のみ・経路なしは構造上0）。

経路なしの世界（v5e2 6本）はこの4つで読み直す。停止が入った F は右打ち切りとして注記。

## 7-2. Codex レビュー（2026-08-29 走行前）で凍結したこと

**受け入れて直した**（走行前に凍結・実装済み）：

1. **採点用LLMをコードで遮断**＝`Simulation._finalize` の分類の関門を
   `classify_on = (not self.field_v6) and kpi.classify_utterances` にした。
   config を事故で true に戻しても v6 では1本も走らない（テストで固定）。
2. **行動はその月の最後のターンでだけ受け取る**（他のターンに行動のキーが混ざって
   返っても無視する）。
3. **`当面売らない` は売買だけを止める。貸し借りは止めない**＝選択肢の文言が
   「売らない」だから（文言と実装を一致させた）。台本の賃借はそのまま成立する。
4. **本当の既定値**＝行動欄が空で返ったら「変えない／なし」として扱い、記録に残す。
5. **文言をさらに中立へ**＝「今月あなたが街に向けて何かするか」「取る措置」という
   問いかけの形をやめ、「街の全員が見られる」という到達力の宣伝もやめた。
   残したのは「選ばれたものが世界でどうなるか」という事実だけである
   （それが無いと選択の意味が分からない＝選べない）。

**受け入れなかった**（理由つき）：

6. 「同席できなかった主体に、行動だけの追加コールを1回与えよ」
   → **実測 1.5%**（v5e2 runA の 936 主体×月のうち、誰とも居合わせなかったのは14）。
   36か月ずっと孤立した人は0人、最大でも6か月。行動できない月がわずかにある、という
   世界の制約として**限界に書く**方を選んだ。追加コールは新しい経路（世界の仕組み）を
   足すことになり、「足すのは選択肢だけ」の原則から外れる。
7. 「行動欄を必須から外して、選ばせない月を作れ」
   → 既存の stance も毎月必ず答える形であり、片方だけ任意にすると
   **「面倒だから書かない」方向の偏り**が新しく入る。既定が先頭にあり、
   「変えない／なし」を選ぶのはコストゼロなので、強制選択は左右対称と判断した。
   ただし「毎月かならず選ばせている」ことは限界に書く。
8. 「`Parcel.refusal` を共有の型に足すな」
   → `Ledger.snapshot()` は**どこからも呼ばれていない**（grep 実測）ので、
   既存版の成果物には1バイトも出ない。回帰テスト 1,730 件も緑。列は物語どおり
   登記簿に置く。

## 8. 正直に書く限界

- 3本ずつの比較＝**傾向であって統計ではない**。
- 選択肢を置いた事実そのものが、置かない世界との違いである（それが実験の主旨）。
- 「経路あり」で何も起きなくても、それは失敗ではなく結果である。
- 第m月に選ばれた「当面売らない」が止められるのは**第m+1月以降**の予定である
  （台本は月初に適用されるため）。
- 第36月に出た紙は**誰にも読まれない**（第37月が無い）。「出した」と「読まれた」は別に数える。
- 「当面売らない」は**その人の持つ全部の土地**にかかる＝「宣言した人数」と
  「止まった土地の数」を混同しない。
- 買えなかった件数は「買い手が諦めた数」ではなく、**固定された一回限りの予定が
  不成立になった数**である。
- 行動できるのはその月にどこかで誰かと居合わせた主体だけ（実測 98.5% の主体×月）。
- 行動欄は毎月かならず答える形になっている（既定は「変えない／なし」）。
- 選択肢の並び（回覧→議題→申入れ、窓口→説明会→条例）には弱→強の順序効果があり得る。
  結果を見てから並べ替えない。
