# v9b は v9 と何が違うのか（設計の差と、結果の差）

- v9 の結果＝`docs/v9_run.md`（走行 `simulations/2026-08-30_1212_110_field_v9_land_and_building_chat/`）
- v9b の結果＝`docs/v9b_run.md`（走行 `simulations/2026-08-30_1333_114_field_v9b_promises_that_execute_chat/`）
- v9b の設計＝`docs/world_design_v9b.md`（走行前に凍結）

**v1〜v9 のファイルは1バイトも触っていない。** v9b は新規ファイルだけで完結する
（`src/field_v9b.py` / `src/sim_v9b.py` / `run_v9b.py` / `configs/config_field_v9b.yaml` /
`tests/test_v9b.py` / `tools/v9b_*.py`）。

（`configs/personas_v9.yaml` を共有）。

## 1. 設計の差（2つだけ）

| |v9|v9b|
|---|---|---|
|世界の配達|相手が持っていない区画・種別を求めた手紙は配らない|同＋**この世界で実行される仕組みが無い約束を含む手紙も配らない**|
|配らなかったことの扱い|件数を数えるだけ（X社には何も返らない）|**翌月X社に「届かなかった」事実と理由だけを返す**（①②とも同じ形）|
|X社の設定|v9 の7行|同＋施主指定の2行（「土地と建物のセットにこだわらない。土地だけ、建物だけの取得でもよい。」／「所有権の移転後に実行されるのは、使用者がそのまま使い続けること（借地・借家）だけである。支援・改修・管理・金銭の提供を実行する仕組みはない。」）|
|X社への規則の告知|「持っていない区画や種別は届かない」|同＋「実行される仕組みが無い約束を含む提示も届かない」|

変えていないもの＝町の人のプロンプト（前置き・行き先・会話・出品・売買・理由の一言）・
名簿49体・44区画・格子（seed 85）・場所5つ・会話の仕組み・出品4択・売る/売らない2択・
保証3通り・36か月・`gemini-2.5-flash-lite`・temperature 0.75・
X社の自己紹介「私どもは海外の不動産投資会社です。」・お金の概念を入れないこと。

**判定は走行前に凍結した語彙表による決定論の文字列照合**（強い語21・弱い語11・
打ち消し16・実行される事実12）。LLM を使った判定はしていない。
門番は X社の条件文にだけ掛かり、町の人の文章には一切適用していない（試験で固定）。

### v9 からの挙動差として明記すること

v9 では①（持っていない権利）で落ちた40件を**X社に返していなかった**。
v9b は①②のどちらも同じ形で翌月返す。片方だけ返すとX社に届く事実が食い違うためである。
**したがって v9→v9b の差は「②の門番」「②③の事実返し」「X社の設定2行」の
3つが同時に入ったもの**であり、どれか1つの効果として切り分けることはできない。

## 3. A で何が変わったか

### 3-1. X社の言葉が消えた（いちばん大きい差）

```
                              v9        v9b
条件文に「支援」              575回      0回
条件文に凍結語彙のどれか      多数       6回（保証3・運営3。うち届いたのは2件）
```

v9 のX社は、生活支援・改修・地域貢献といった**この世界に仕組みの無い約束**を並べて説得していた。
v9b では、それを書くと手紙が届かない。X社は**3か月でその書き方をやめ**、
以後33か月「所有権を譲っていただけるなら、私どもはその所有権を譲り受けます」という
**同語反復**だけを書き続けた。
＝**実行できない約束を取り上げると、この買い手には言うことが残らなかった。**

### 3-2. 断りの理由が「内容が不明」から「相手が不明」へ

```
                v9                          v9b
最多語          不明 217                    条件 96 → 具体 77 → 不明 65
上位の言い回し  「支援内容が不明瞭なため」   「具体的な条件提示がないため」34
                「具体的な条件提示がないため」「まだ様子を見たいので」24
                                            「相手の情報が不十分なため」14
「海外」の語    18回                        42回
```

v9 では「あなたの言う支援がよく分からない」だったのが、v9b では
**「そもそも条件が無い」「相手が誰か分からない」**に変わった。
「海外」に触れる断りが2.3倍になっている。

### 3-3. 狙う先が「両方」から「土地」へ寄った

「両方」63%→56%、「土地だけ」23%→37%、「建物だけ」15%→7%。
X社の設定に「土地だけ、建物だけでもよい」（B）が入ったことと同時に起きているので、
**A の効果とは切り分けられない**。

### 3-4. 借家と借地の結果が入れ替わった

```
                                  v9                 v9b
所有者が自分で使っている区画(26)  330件/3件(0.91%)   321件/3件(0.93%)
借地の区画(9)                     241件/2件(0.83%)   304件/0件(0%)
建物を借りている人がいる区画(9)   133件/0件(0%)      184件/2件(1.09%)
```

v9 で1件も動かなかった借家のある区画が、v9b では2件動いた。
どちらも**使っている人はそのまま住み／泊まり続けられる**形の売却で、
売り手の一言も「利用者の継続が可能だから」だった。
逆に借地は0件になった。**サンプルは各1〜3件で、揺れの範囲を分離できていない。**

### 3-5. 出品が倍近くに増えた（117→224件・11人→12人）

出す人の数はほぼ同じで、**同じ人が出し続けた回数**が増えている
（最多は「船着場裏の不在地主」72回）。

### 3-6. 変わらなかったもの

- **落ちた区画の数は 5 のまま**（4人）。X社の言葉を取り上げても、取り上げなくても、
  36か月で動いたのは44区画のうち5区画だった。
- 町にいない持ち主のほうが動かない（v9 0.37%対0.92%／v9b 0.46%対0.80%）。
- 出品の圧倒的多数は「出さない」（v9 92.8%／v9b 86.3%）。

## 4. 解釈しないこと

1本ずつしか走らせていないので、上の差はすべて**1本対1本の差**である。
特に成約・退場・借家借地の内訳は各0〜3件で、揺れと区別できない。
断言できるのは、件数の桁が違う **3-1（語彙の消失）と 3-2（断り方の変化）** だけである。
