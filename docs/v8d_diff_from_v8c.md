# v8c → v8d の差分と、その良し悪し

結果の本体は `docs/v8d_run.md`（単独で読める）。ここは**何を変えて、何が良くなり、
何が悪くなったか**だけ。設計の正＝`docs/world_design_v8d.md`。v8c の結果＝`docs/v8c_run.md`。

## 変えたのはこの3点だけ（世界の骨格・名簿・場所・隣近所・36か月・seed 85・町の紹介文は同じ）

1. **月末の問い２から「戻らない」の一文を削除**した。
   （v8c＝「売ると今月末に名義がX社へ移り、その後は戻らない。売らないと今月末の名義は
   あなたのままである。」）選択肢2つの説明と、共通前置きの「一度移った名義が戻ることはない。」は残した。
2. **X社の設定に事実を3つ足した**（情報であって当為ではない・住民側には1文字も出ない）。
   「第1月の開始時点で、あなたは A市に不動産を持っていない。／金銭の額はこの世界では扱わない。／
   あなたが約束できるのは、自分自身が実行できることだけである
   （この世界には、あなたから他者へ不動産の名義を移す仕組みはない）。」
3. **理由の一言を3つの判断だけに**した（出す/出さない・売る/売らない・X社の提示判断）。
   ＝**行き先の理由欄を外した**。

### 施主の原文からの変更（走行前 Codex レビューの必須指摘・報告済み）

- 差分2の1文目に「**第1月の開始時点で、**」を足した。前置きは36か月固定なので、
  X社が実際に取得したあとも「持っていない」と言い続け、同じコールに入る本物の登記簿と矛盾するため。
- 差分2の括弧の中の例3つ（売った後も住み続けてよい期間／引き渡しの時期は相手の都合／
  建物や土地の管理を引き受ける）を、**「この世界には、あなたから他者へ不動産の名義を移す
  仕組みはない」に置き換えた**。3つとも世界が持っていない仕組みで（住むことの継続は名義に
  関係なく世界が保証済み・名義が移るのは月末で固定・管理という状態は世界に無い）、
  **実行できない約束の例をこちらから教えることになる**ため。
  結果として v8d の会社は「住み続けられること」を自力で発明して条件に使った（§下記）。

## 良くなったこと

1. **名義が動いた。** 0件 → 6区画・4人。v8c で測れなかったもの（売った人の理由・
   売却の前に何を聞いていたか・売却後に隣人がどうしたか）が、少ないながら観測できた。
2. **会社が「自分にできない約束」をやめた。** 交換155件 → 0件。差分2の事実が効いたと
   考えるのが自然である（他の2点は住民側・問いの文言の話で、提示文の中身には触れていない）。
3. **町が動いた。** 発話 203→391件、外出しない率 72%→55%、出品した人 3人→13人。
   行き先の理由欄を外したことが効いた可能性がある（v8c の「悪くなったこと2」で立てた仮説と
   同じ向きの結果）。ただし**同時に3点変えているので、これだけを取り出して因果とは言えない**。
4. **売った4人の理由がそろっている**＝全員が「住み続けられる／営み続けられる」を挙げた。
   売買判断の根拠が原文で読める。

## 悪くなったこと・代償

1. **会社は世界がすでに保証しているものを対価にした。** 「住み続けてよい」は名義に関係なく
   世界が保証している事実で、会社が新たに与えたものではない。会社の前置きには
   「その継続を提示の条件として書かない」とあるのに、会社はそれを書いた（世界は提示文を
   検証しないので止まらない）。**したがって「取得が起きた」は「町の人が実質ゼロの対価で
   名義を手放した」とも読める**。ここは人が原文を読んで判断すべき論点である。
2. **売却が4人しかいない。** 伝染（売った人の隣人がどうしたか）は、触れた人44.4%・
   触れていない人50.0%で**差が出ていない**＝今回も伝染は観測できていない。
3. **「戻らない」の削除が効いたかは分からない。** 断りの一言のうち不可逆に触れた語
   （戻／取り消／永久／不可逆／二度と）を含むものは **v8d 0/468件・v8c も 0/187件**＝
   どちらの版でも町の人は不可逆を言葉にしていない（＝この差分の効き目は言葉からは追えない）。
   一方で第24月の売却は内心に「対話を継続し、より具体的な条件を引き出す」とあり、
   **v8b で問題になった「まず応じて後で詰める」の誤読が1件再発している**
   （「戻らない」を消したことと無関係とは言い切れない）。
4. **費用が上がった**（$0.4374 → $0.5386）。提示件数が2.5倍・発話が1.9倍になったため。

## 「海外」という自己紹介は効いたか（判定材料・判定は別途）

数えたのは語（「海外／外国／外資／国外／よその国／他国／異国／グローバル／インバウンド」）の
出現だけで、**意味の判定はしていない**（`tools/v8_foreign_words.py`・`foreign_words.json`）。

```
                        v8c              v8d
断りの一言             1/187（0.5%）   20/468（4.3%）
出品の理由             0/510（0.0%）    9/552（1.6%）
住民の発話            12/203（5.9%）   20/391（5.1%）
```

原文（v8d・断りの一言）

> 第2月 学園北の持ち主さん：「海外の会社への名義変更は慎重に検討したい」
> 第21月 湯坂下の持ち主さん：「条件は魅力的だが、海外会社で不安」
> 第24月 神明社の自治会長：「海外投資会社への不信感。活動継続を重視。」
> 第25月 北団地の持ち主さん：「海外企業への売却に不安があるため」
> 第25月 湾岸大通りのホテルの支配人：「海外投資会社への売却は時期尚早」

**読み方の注意**：v8d は断りの母数が2.5倍になったので、割合（0.5%→4.3%）の上昇は
「海外という語が効いた」とも「断りの内容が具体化した」とも読める。
断りの主因は語の分布では依然として「条件・不明・詳細」（164/106/84件）であり、
「海外」は19件である。
