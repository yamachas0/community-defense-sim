## 1. 判定＝4段階の色（施主指示①・走行前固定・事後分類ルール∧LLM）
主体ごと・月ごとに「その月までに到達した最高段階」を判定し、街全体は人数の推移で見る。発話（公言）と内心（思っただけ）を分けて数える。
- **青＝個別の売買の話題**：1件の取引（「P02が売られた」「あの空地に看板が」）だけを語った。
- **緑＝複数の売買の関係性・面的な話**：2件以上の取引を結びつけた／「この辺一帯」「あの通りが」など面として語った（同じ名義でも別名義でもよい）。
- **黄＝X社にたどり着いた**：名義の違う取引（A〜D社）を**同じ買い手・同じ動き**として結びつけた（＝隠れた1社に気づいた）。
- **赤＝行政が規制に動いた**：行政（municipality）の主体が、届出・条例・調査・規制・取得の制限 等の**行政としての対応**を公の場で口にした／内心で決めた（v5 系に条例の機構は無い＝「動こうとした」を観測する）。
- 集計：各段階の**初出**（月・主体・**場**・きっかけ）／段階別の人数推移（公言／内心）／**場所別の火種**（どの会場で色が上がったか）／記事・町内会・窓口での初出／**②のイベント前後**の変化（報道本数・色の上がり方）。
- 「問題化しなかった」「赤は出なかった」も同じ重みで報告。RESULTS・present.html はこの4色で描く（「連結」「意図」の語は使わない）。偽陰性の人手監査（無作為100行）を本便で実施。

## 2. 区画の属性（MAP・施主FB②前半）
各区画（46）に世界の事実として持たせる（生成は seed・人が読める YAML に凍結）：
- `zone`：中心／中間／郊外（4地区の内側でさらに分ける）
- `frontage`：表通り／裏通り／角地
- `area_sqm`（既存）と `size_class`：小／中／大
- `use`：空地／古い住宅／住宅／店舗／事業所／旅館・宿（既存 use を拡張）
- `owner_profile`：高齢単身／不在地主／後継者なし／営業中の店／現役世帯（ペルソナと整合させる。**ペルソナの中身は変えない**＝既存の年齢・世帯・生業から機械的に付与）
- `visibility`：目立ちやすさ（表通り・角地・大・店舗 ほど高い）＝**兆候の可視範囲の規則は変えない**。visibility は買い手が選ぶ時に使う値であって、街の観測には出さない。

## 3. 買い手（X社）の取得戦略＝台本生成器の規則（施主FB②後半）
X社は LLM を呼ばない（v5 と同じ）。生成器が次の**戦略規則**で取得順を決め、60か月ぶんを凍結する：
1. **入りやすい所から**：空地・古い住宅・高齢単身/不在地主/後継者なし・店じまい間近 を優先（`owner_profile` と `use` の重み）。
2. **目立たない所から**：裏通り・小面積・郊外寄りを先に。`visibility` が低い順。
3. **面をつくる**：既取得区画の隣接を優先して連ねる（`world.neighbors()`）。地区は少しずつ広げる。
4. **一等地・角地・大区画は後半**（面が出来てから）。旅館・宿は賃借（lease）で入ることが多い。
5. **名義を散らす**：同じ地区・同じ月に同じ名義を続けない（A〜D社のローテーション規則）。
6. 月あたりの件数レートは v5b と同じ（M1-12 月1〜2・M13-36 月0〜2・M37-60 月0〜1）。**総数は区画が尽きるまで**。
- 規則は**買い手の合理性**であって、街に気づかせるための調整ではない（visibility が低い所から＝むしろ気づきにくい方向）。生成後に結果を見て台本を触らない。
- 兆候（trace）は v5b の規則そのまま（登記1本必須＋0〜2本 seed・賃借は登記なし）。
- **②イベントの仕込み（施主指示）**：台本に**1件だけ**「一等地・大区画（中心 zone・表通り or 角地・size 大・営業中の店舗 or 旅館）の売買」を**第12〜14月のいずれか（seed で決定）**に固定で入れる。兆候の規則は他の取得と同じ（登記1本必須＋0〜2本 seed）＝**目立つ取引だから兆候を増やす、はしない**。観測ではこのイベントの前後で報道本数・色の段階・人数がどう変わったか／変わらなかったかを必ず並べる。

## 4. 日常の場（施主FB③）
- 月のシーン数は **4 のまま**（施主指示③「会場増やして4シーンでまずは」）。各シーンで主体が選べる**会場を増やす**：
  - 既存：商店街（V01/V04）・職場/店・公園・居酒屋・共同浴場（V03）・町内会（V02）・役所窓口・仲介の店先・記者の取材
  - 追加：**床屋／スーパーのレジ待ち／神社の掃除・祭りの準備／学校の送り迎え／回覧板の受け渡し（隣家）／バス停・駅のホーム／診療所の待合**
- S1〜S3 は「日常の場」から自由選択、S4 は月替わりの窓口（従来どおり）。**どの場で火が点いたか**（気づきの初出・問題化の初出・広がりの経路）を場ごとに集計＝「なんでもない場から火が付くか」の検証。
- 場の設定は世界の事実（誰がどこに行きやすいかはペルソナの生活動線から機械的に。例：子持ち世帯→送り迎え、高齢→診療所・銭湯）。**誘導はしない**（行き先は毎月 LLM が選ぶ・候補を並べるだけ）。

### 7.1 区画属性の規則（`configs/parcels_v5c.yaml` の meta にも同じものが入っている）
- `zone`：街の中心 (3.5, 1.5) からのチェビシェフ距離 ≤1.5 が中心／≤2.5 が中間／他は郊外
  → 中心16・中間14・郊外16。
- `frontage`：主要道路（行 y=2,3・列 x=3,4）の両方に面する＝角地、片方＝表通り、どちらでもない＝裏通り
  → 角地4・表通り20・裏通り22。
- `size_class`：≤110㎡ 小／≤240㎡ 中／それ超 大 → 小18・中17・大11。
- `use_detail`：既存 use ＋ 所有者・使い手のペルソナ本文の語で細分
  → 住宅19・店舗10・古い住宅9・空地6・旅館1・事業所1。
- `owner_profile`：所有者ペルソナの年齢・世帯・生業から機械判定
  → 現役世帯24・後継者なし8・不在地主7・営業中の店4・高齢単身3。**ペルソナ本文は変えていない。**
- `visibility`：frontage+size+use+zone の加点（0〜7）。**買い手の内部値**であり、
  どのプロンプトにも出ない（`tests/test_v5c.py` が mock ランの実プロンプト全文を grep して固定）。

### 7.2 台本生成器の規則
毎月、まだ買っていない区画のうち次の得点が最大のものを選ぶ：
`score = ease(use_detail) + ease(owner_profile) − visibility + 隣接ボーナス4.0 + 微小な揺らぎ(0〜0.5)`
- ease：空地+3・古い住宅+3・住宅0・店舗/事業所/旅館−1、不在地主+3・高齢単身+2・後継者なし+2・現役世帯0・営業中の店−2
- 角地・大区画・旅館は第31月以降（早い側の在庫が尽きた月＝**第21月**から前倒しで解禁された）
- 名義は同じ地区で連続月に同じものを使わない
- 月あたりの件数レート・兆候の規則・事情（note）の文面は **v5b から import してそのまま**
実測（凍結後）：46件・第1〜24月に34件。取得区画の平均 visibility は第1〜12月 **2.7** → 第13〜24月 **5.0**。
隣接率 42/45（v5b は 36/45）。第1〜6月の対象は空地・古い住宅・不在/高齢/後継なしが8割以上。

### 7.3 一等地イベント（設計 §3 からの逸脱と、その理由）
設計は「中心 zone・表通り/角地・**size 大**・営業中の店舗 or 旅館」を求めたが、この世界では
大区画（320/450㎡）が周縁の列 x=6,7 にしか無く**中心 zone に大区画は1つも存在しない**＝
4条件を全部満たす区画がゼロだった。そこで**走行前に**定義を
「店舗・旅館のうち visibility 最大（同点なら面積最大・なお同点なら pid 順）」へ固定した。
選ばれたのは **P30＝中心・表通り・240㎡・店舗・visibility 7（この街で最も目立つ店舗）**、
月は seed により **第12月**。兆候の規則は他の取得と同じ（登記1本＋0〜2本）。
※結果を見て選び直してはいない。

### 7.4 日常の場
会場は 8→15（追加＝床屋・スーパーのレジ待ち・神社・学校の送り迎え・回覧板・バス停・診療所）。
各主体が選べる会場は**ペルソナ本文の語と年齢から機械導出**した候補（平均6.3個／全員共通は

**行き先は毎月 LLM が選ぶ**。プロンプトに誘導文は無く、文面は v5 と同一で並ぶ会場だけが違う。

### 7.5 4段階の色の測り方（走行前に固定）
1行ごとに「ルール1次抽出 ∧ LLM ラベル」で色を付け、赤>黄>緑>青の順に最高段階を採る。
- 青：区画ID・名義・売買語のいずれかを含む ∧ LLM が「土地の取引の話だ」と判定
- 緑：取得済み区画2つ以上／名義2つ以上／面の語（一帯・この辺・次々…）∧ LLM の area
- 黄：名義2つ以上／名義1つ＋同一性の語（同じ会社・裏で・繋がって…）∧ LLM の same_buyer
- 赤：**話し手が行政の主体** ∧ 行政語（届出・条例・規制・調査・要綱…）∧ LLM の admin
- 分類に失敗した行は false ではなく **unknown**（主値から外す）。ルール単独・LLM単独の件数も併記する。
- 初出は（月・主体・**場**・その主体がその月に見ていた兆候）まで記録する。
- 会場ごとの火種＝**その主体がその色に初めて達した場**を会場別に数える。
- 一等地イベントの前後＝第9〜11月と第12〜14月（および全期間の前後）で、色別の行数・人数・記事本数・場を並べる。
