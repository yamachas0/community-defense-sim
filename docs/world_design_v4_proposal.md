# 世界設計 v4 提案：「シミュレーションが成立する」ための最小の世界（CEO 2026-08-27 14:50）

施主「複雑にしすぎたかな。一旦全部忘れて、シミュレーションを成立させる世界設計を考えて」への回答。
v1〜v3の実装・結果（run12〜56）を踏まえるが、設計は白紙から。

## 0. 何が「成立」か
研究の問い＝**合法な土地取引だけで都市の実効統治が非住民へ移るとき、住民は何の情報から気づき、規制はいつ手遅れになるか。**
成立条件は3つ：①X社が実際に取得を進める（0%では何も観測できない）②住民が断片情報から認知を変える ③行政・報道が反応し、その反応がX社の戦術に返る。
v3までは①で止まった。原因は「LLMの能力」ではなく **世界の作り＝LLMに『手続き』を選ばせていた** こと。

## 1. v3までの失敗の一般化（3つ）
1. **手続き動詞の存在**：market_research／internal_review／financing_review／check_land_registry／contact_broker／client_followup…＝**世界の状態を変えない行為**が選択肢にある限り、LLMは「もっとも説明しやすい次の一手」としてそれを選び続ける（11ラン全部）。
2. **非同期・月単位の会話**：発話は翌月配送＝1往復2か月。「来週会いましょう」は世界に存在しない。会話で交渉させると60か月が社交辞令で溶ける（run38: 通信の69%）。
3. **決定の中間者**：仲介というLLMを取引経路の途中に置くと、そこが止まれば全部止まる（run54-56: 仲介120回hold）。

原則に直すと：**「世界の状態を変えない行為は存在させない」「取引は会話でなく市場の機構で回す」「経路の途中にLLMの判断を置かない」**。これはルールベースではない＝LLMが決める内容を「手続き」から「条件と反応」に変えるだけ。

## 2. v4の骨格：LLMが決めるのは3種類だけ
- **X社**＝「今月どの区画に・いくらで・どの名義で買付（or 賃借提案）を出すか／どれを取り下げるか」（＋任意：誰に何を話すか）
- **所有者（住民・事業者）**＝「受けた買付を 受ける／断る／逆提示（金額）」＋「日常で見聞きしたことから何を思い、誰に何を話すか」
- **行政・記者**＝「何を調べ、何を公表・制定するか」
手続き（登記の照会、資金の確認、仲介への依頼、社内検討）は**世界が自動で処理する事実**であり、行為ではない。

## 3. 月の構造（1step＝1か月・同期3フェーズ）
```
フェーズ1 提示   X社が買付/賃借提案を出す（複数件・名義選択）。住民は日常行動＋発話。
フェーズ2 応答   買付を受けた所有者だけがその月に応答（受諾/拒否/逆提示）。※追加コールは提示件数分だけ
フェーズ3 清算   受諾→登記移転・決済・手数料。逆提示→翌月X社が見る。発話→同席者/宛先へ配送。
```
＝**1往復が1か月**。60か月で60往復。会話の往復を待つ設計を捨てる。

## 4. 世界の機構（LLMの外で決定論的に回るもの）
- **登記簿**＝世界の帳簿。全区画の所有名義・面積・用途・賃料。X社は最初から全件見える（公開情報）。「調べる」行為は無い。
- **買付と応答**＝台帳の状態機械（open→accepted/rejected/countered→closed）。IDは1系統。
- **決済**＝受諾時に自動。X社の資金は「調達可能（上限なし・調達累計を記録）」。
- **仲介＝自動リレー＋噂の源**：X社が仲介経由を選ぶと、仲介は**機構として**所有者へ買付を届け（LLM判断なし）、手数料は清算時に自動記帳。仲介のLLMは**話すだけ**（誰が買い漁っているかを同席者に漏らす）＝情報経路としての役割に専念。
- **名義と法人記録**＝X社は複数名義を使える。公開法人記録を「調べる」行為は残す（行政・記者の唯一の調査行為＝これは世界の状態を変えないが、**その主体の観測を変える**ので例外として残す。判断：調査は月1回・結果は事実）。
- **同席と配送**＝v3どおり（同じ場所にいた者にだけ聞こえる／直接連絡は宛先だけ）。
- **月次観測（機械記録）**＝各主体に「自分に関係する事実」を全件出す：X社にはポートフォリオ（所有/支配面積・シェア・未応答の買付・逆提示・残月数・調達累計）、所有者には「自分の区画への買付（金額・名義・評価額との比）」、全員に「先月の自分の行為の結果」。評価語・当為は書かない。

## 5. 各主体の出力スキーマ（最小）
- X社：`offers[]{parcel, price, name, via(direct|broker)}`, `withdraw[]`, `memo(200字)`, `talk?{to|venue, text}`
- 所有者：`responses[]{offer_id, decision(accept|reject|counter), counter_price?}`, `daily{location}`, `talk?`, `feeling(短文＝認知の観測用)`
- 行政・記者：`investigate?{target}`, `publish?/ordinance?{text}`, `talk?`
計画欄・代替案・根拠IDの必須は全部やめる（v3で83%が前月コピーだった）。

## 6. 認知と統治（研究の本体）
- 住民の認知は「見た事実」からLLMが書く短文（feeling）を毎月記録＝相転移の観測値。
- 行政は登記統計（機械記録＝月ごとの名義別面積）を**見ることができる**が、見るかは選択。記者も同様。
- 条例（取引規制）は制定されれば世界の機構として効く（例：一定面積超の取得に届出＝X社の買付に遅延月数）。

## 7. なぜこれで成立するか（v3の実測との対応）
- run36（第1月に買付6件→18件成約）が示したのは「買付を出しさえすれば市場は動く」。v4は**買付以外に選ぶものが無い**。
- 承諾消失（ID）・重複照会・社交辞令・仲介hold は、機構化で**構造的に起きない**。
- LLMの能力差は「価格の付け方・名義の散らし方・売り手の心理」に出る＝ここが研究で見たい差。

## 8. 最小実験（v4-mini）
48区画・住民16・事業者4・行政2・記者2・X社1・仲介2（機構＋噂）。まず **12か月×3本（≈$0.15/本・flash-lite）** で「取得が進む／住民が気づく」の両方が観測できることを確認→60か月。
v1〜v3は別ファイルのまま保存（比較用）。

## 9. 施主に決めてほしいこと（3つだけ）
1. X社の手続き動詞を全廃してよいか（「調べる・検討する」は世界が自動処理＝行為でなくなる）
2. 仲介を「自動リレー＋噂の源」にしてよいか（仲介のLLMは取引を止められない）
3. 所有者の応答を同月内にしてよいか（1往復=1か月）
