# v9f-nochat 本走の結果 — 会話が無い町

走行＝`simulations/2026-08-30_1846_134_field_v9f_pay_more_if_needed_nochat/`
設定は `configs/config_field_v9f_nochat.yaml`。
**v9f との差は2行だけ**（`run_name` と `chat: false`）。**コードは1バイトも変えていない。**
比較は `docs/v9f_chat_vs_nochat.md`。

- 36か月ぜんぶ走った・費用で打ち切られていない
- 手元集計の費用 **$0.6815**・14分5秒・49人・44区画
- 健全性：**すべて0**（読み取り失敗0・答えなし0・打ち切り0・時間切れ0）

## 1. 会話が無いとはどういうことか

`chat: false` は v8 から使っている既存のスイッチである。止まるのは2つ。

- **場での会話**（同じ場所に行った人どうしが一度ずつ話し、その場の全員に聞こえる）
- **隣近所への伝播**（開始時に隣り合う不動産の使用者どうしに、ひと言が毎月届く）

**止まらないもの**＝月初に「今月どこへ行くか」を決めるコールは残る（行き先だけ決めて、
そこで誰とも話さない）。X社の提示・出品・売る/売らない・借家人の「今月A市を出るか」・
家主と借り手の一言・所有権が移った通知・経過時間の事実行は、すべて v9f と同じである。

走行前に mock 1か月で実測して確認した＝**場の発話0件・隣近所などの配送0件**、
行き先のコール35件・提示13件・出品27件・借家人のコール10件・一言5件は動いている。

本走でも **場の発話は0件**（`utterances.json` が空）。
「会話が無いと消える項目」は次のとおりで、すべて **0** である。

```
場での発話            0件
隣近所などの配送       0件
会話でX社に触れた人     0人（照合対象の発話が無い）
持ち主が変わった後の声   0件
```

## 3. 何が起きたか

### 3-1. 成約は **5件**、面積は **6.9%** で止まった

```
第1月  船着場裏の不在地主  資材置場（土地）  1.00倍
第3月  湯の元前の店のご主人 店（両方）       1.00倍  → 町を出る
第15月 波止場通りのご夫婦  家（両方）       0.99倍  → 町を出る
第18月 魚市場前の診療所の院長 駐車場（土地） 2.00倍
第20月 湯坂上のご夫婦     古家（両方）      1.02倍  → 町を出る
```

**第20月以降、36か月まで1件も動かなかった**（取得割合は第24月から横ばい）。
資金は89.1%が余っている。

### 3-2. X社は同じように粘ったが、**通らなかった**

```
提示981件・再提示931件・値上げ269回（中央値+192万円・最大+1億4,700万円）
1.2倍以上の「積んだ」提示 553件 → 成約1件（0.18%）
```

**積む量は会話ありの町とほとんど同じ（562件→553件）なのに、成約は7件→1件**になった。

### 3-3. 断りの言葉が「自分と家の事情」だけになった

```
共同浴場の世話を続けるため   25件
まだ手放す決断ができない     23件
先代からの大切な家だから     20件
提示額が評価額を下回るため   13件
長期保有方針のため          13件
父の介護を優先するため      13件
```

**「自治会での検討が必要」「共有者との合意形成を優先」といった、
他人と相談する形の断りが上位から消えた**（会話が無いので相談する場が無い）。
代わりに「共同浴場の世話」「先代からの家」など、自分の事情だけが並ぶ。

### 3-4. 借りている人は1人も町を出なかった

「今月、A市を出るか」は毎月聞かれているが、**36か月で「出る」は0件**。
家主に届く「使う人がいなくなった」通知も0件だった。

### 3-5. 家主と借り手の一言は続いたが、返事が減った

```
一言 210件（返事率 68.0%）
```

会話とは別の経路なので止まっていないが、件数も返事率も落ちた。

## 5. この結果の限界

1. **1本である。** 会話ありの v9f も1本で、差はすべて1本対1本の比較にすぎない。
2. `chat: false` は「場の会話」と「隣近所の伝播」を同時に止める。
   **どちらが効いたかは分けられない。**
3. 行き先を選ぶコールは残しているので、**LLM の呼び出し回数と費用はほぼ同じ**である
   （$0.68 対 $0.75）。会話の有無は費用の差ではない。
