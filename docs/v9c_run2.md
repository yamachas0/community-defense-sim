## 2. 何が起きたか

### 2-1. X社は1か月目から36か月目まで、同じ1文を書き続けた

```
「貴殿の所有する<区画名>の土地と建物の所有権を、
  将来にわたり貴殿がそのまま使用できることを条件に譲渡いただきたい。」
```

第1月も第18月も第36月もこの形である。成約した6件もすべてこの形だった。
凍結した語彙表に当たったのは、届いた785件と届かなかった65件のあわせて850件のうち7回（「維持」）だけで、
実行できない約束として弾かれたのは**1件**（第1月「この区画の現況を維持します」）。

### 2-2. **「そのまま使える」と信じて両方を売り、結果として町を出た人が2人**

第5月・湯の元のひとり暮らしさんと、第7月・駅前広場の食堂のご夫婦。
どちらも自分が住み・営む区画の**土地と建物の両方**を売った。

- X社の条件文は「**将来にわたり貴殿がそのまま使用できることを条件に**」。
- しかしこの世界では、**両方を売って自分がそこを使っていた人は、その区画を離れて町を出る**。
  世界はそれを、答える直前の選択肢の説明で本人に見せている
  （「『売る』：…あなたはその区画を離れ、A市を出る。」）。
- 売り手が書いた理由はこうだった。

```
第5月 湯の元のひとり暮らしさん 「家族の勧めと将来の利用条件のため」
第7月 駅前広場の食堂のご夫婦   「経営継続の条件が魅力的」
```

**「使い続けられる」という条件を信じて売り、世界の規則どおり町を出た。**
※ この条件文を世界が配ったのは、凍結した語彙表が「使い続け」を
**実行される事実の言い方**として素通しさせるためである。
「両方を売る相手に対しては実行されない」ことまでは、語彙表は判定していない
（`docs/v9c_run.md` §6-3 に書いた「語彙表は意味を理解しない」の実例）。

### 2-3. 第1月の売り手は「提示額」で売った

最初の成約（第1月・湾岸のホテルの所有会社／社員寮の両方）の理由はこれである。

```
「海外投資会社からの提示額で売却」
```

**この世界に金額は存在しない。** 相手も一度も額を書いていない。

### 2-4. 借りている人は1人だけ出た（第36月）

```
駅裏北の駐車場の会社（2区画を借りて営業）
  「新しい土地での挑戦のため、A市を離れます。」
```

残る359回は「出ない」で、理由は「事業継続のため」26・「この場所で商売を続けたいから」12・
「ホテル運営を継続するため」9 など、**生業を続けることが理由**だった。

557件（返事率94.1%）。中身は挨拶と近況で、売買の話にはほとんど発展しない。
