## 1. 何が変わるか（v4系との決定的な違い）
| | v4 / v4.1 / v4.1b | **v5** |
|---|---|---|
| 取得（X社の買い進み） | LLMが打診・所有者がLLMで応答＝**動かない**のが結果だった | **固定の出来事（台本）として世界に挿入**。X社は主体でなく「出来事の源」 |
| 観測の主眼 | 成約数・所有率（取得が進むか） | **誰が・いつ・何をきっかけに気づくか／明るみに出るか／出ないか** |

| 世界の機構 | 3フェーズ・配送状態・届出/条例・相談プロトコル・案件表 | **登記簿＋兆候（trace）の配布＋シーン（同席）** だけ |

「取得が進まない問題」は消える。取得は起きている。問うのは**街がそれに気づくか**。

## 2. ピン留めされる出来事（台本・LLMは関与しない）
- **取得スケジュール**：60か月分を事前に固定（例：第1〜36月に月0〜2区画・名義は複数法人に分散・地区を少しずつ広げる・第37月以降に「共通支配」が見えやすい動き＝同一テナント入替・一斉改修）。seed で固定し全条件で同一。
- **各取得が世界に残す「兆候（trace）」**（施主が言う「きっかけ」の物理）。取得ごとに0〜数個。種類の例：
  1. 登記の名義変更（公開だが**見に行った者しか見えない**＝役所窓口シーンで閲覧、または仲介が知っている）
  2. 引っ越し／店じまい／看板の掛け替え（**近隣住民がその区画の前を通るシーンで見える**）
  3. 元所有者の発言（売った本人は「話す」ことも「黙る」ことも自分の thought で決める＝ここは主体の自由）
  4. 仲介の見聞（仲介役の主体は取引の一部を「知っている」状態で街に出る）
  5. 工事・測量・見慣れない人（一定確率でなく**台本で指定**）
  6. テナント入替・賃料改定の噂（元所有者・店子が発言源）
- 兆候は「**誰が・どのシーンで・見えるか**」を台本が決める（観測の配布は機械記録＝評価語なし）。**兆候をどう解釈し・誰に話すかは全部主体の thought**。

## 3. 発話シーン（月の構造）
- 1か月＝**シーン4本**（既定・実験で変える）：
  - S1 朝の商店街（買い物・すれ違い）／S2 昼の職場・店（同僚・常連）／S3 夕方の公園 or 居酒屋（雑談）／S4 町内会・役所窓口・仲介の店先・記者の取材（**月替わりで1つ**＝制度・情報の窓口）
- 各シーンで主体は**どこにいるか**（location）を選ぶ。同席者同士が**2〜3往復**の会話（既定＝各自 個別コール・自分の thought を持ったまま発話。グループ1コールは比較条件）。誰も居ない／1人だけなら独り言（thought のみ）。
- 発話は同席者に**全文**届く。私信（direct）は1か月に数通まで残す（電話・手紙）。
- **記者・行政も同じ主体**（特別な機構なし）。記者は取材シーンで聞いた話を記事にできる（記事＝翌月の全員の観測に入る「公開発話」）。行政は窓口で聞いた話を持つだけ。条例・届出の機構は**無し**（v5では作らない）。

## 4. 主体ループ（キモ＝ここだけを丁寧に）
```
入力（記憶）＝ 先月の自分の thought（全文）
            ＋ 今月これまでに自分が聞いた会話（全文 or 自分で書いた要約 ← 実験変数）
            ＋ 自分が見た兆候（機械記録）
            ＋ 自分の登記上の事実（自分の区画・近隣の名義は「見に行った時だけ」）
思考       ＝ thought（自由記述・誰にも伝わらない・目安字数のみ）
行動       ＝ シーン中：{location, talk_to[], text}
             月末   ：{sell|keep}（自分の区画がある主体だけ・買い手は台本）
```
- 指示するのは**順序だけ**（「まず内心を書き、それを踏まえて話す」）。内容・方向は指示しない。
- 金額：**世界は持たない**。主体が会話で「◯万円で売ったらしい」と言うのは自由＝噂の一部（施主判断で「あり」に振るなら台本の取得に価格を付けて元所有者だけが知る）。

## 5. 観測（全部ログから事後集計・機械）
- **初認知**：誰が・第何月・どのシーンで・どの兆候／誰の発話をきっかけに「取得」に触れたか（事後分類）
- **伝播経路**：発話ログのグラフ（誰→誰・何月・シーン）。噂の変形（事実／誇張／誤り）
- **明るみに出たか**：記者の記事化・町内会での議題化・役所窓口への問い合わせ、の月と経路。**出なかった**条件も同じ重みで記録
- **気づかれない取得の割合**：60か月で何件が誰にも語られなかったか
- 元所有者の沈黙／発言の分岐（thought で読む）

## 6. 実験（条件比較＝出来事は全条件で同一）
- E1 記憶の渡し方：全文持ち越し／自分で要約／直近2か月の会話ログ同梱
- E2 シーン構成：4本／2本／町内会なし
- E3 兆候の量：多め／少なめ／登記のみ
- 各 12か月×3本（≈$0.3〜0.6/本見込み・flash-lite）→ 有望な条件だけ60か月

## 7. ルールベース自己点検
確率・閾値・強制・指示文・台本は**出来事（取得・兆候の配布）にだけ**ある＝これは「世界で起きた事実」であって主体の判断ではない。主体の判断（何を話すか・売るか）に世界は一切触れない。**「気づかせるための仕組み」は作らない**（兆候の量は実験条件であって、調整して結果を出すものではない）。
