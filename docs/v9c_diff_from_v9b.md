## 3. 何が変わったか

### 3-1. 借りている人が、自分の意思で2人出て行った（v9b には無い出口）

v9b では、町を出るのは「土地も建物も売って、自分でそこを使っていた人」だけだった。
v9c では**借りている人が自分で出られる**。36か月で2人が出た。

- 第26月・駅前通りの持ち主さん＝第18月に**建物だけ**を売り、
  世界の規則どおり借家人として住み続けていた人。理由は
  **「建物の所有権移転に伴い、立ち退きが必要なため」**。
  この世界に立ち退きは無く、前月には「X社との取引後もA市に留まるため」と答えていた。
- 第35月・湯坂奥の借家のひとり＝理由は**「来月で契約満了のため」**。
  この世界に契約期間は無い。

**2人とも、この世界に存在しない制度を自分で持ち込んで出た。**
v9b までは、この動き（買い手が何もしないのに使用者が去る）を観測する経路が無かった。

### 3-2. X社の言葉が、さらに1段落ち着いた

```
                                     v9b        v9c
実行できない約束で配られなかった手紙   4件        0件
凍結語彙に当たる条件文                6件        0件
```

v9b では最初の3か月に4件あった「実行できない約束」が、v9c では**1件も無い**。
X社は最初から「所有権を譲っていただけるなら、使用者はそのまま使い続けられます」
という、**この世界が実際に実行することだけ**を書いた。
成約した3件もすべてこの言い回しである。

### 3-3. 出品が 224件 → 77件に減った

「出さない」が 86.3% → 95.4% になった。減ったのは主に**土地だけ**の出品
（128件 → 2件）で、代わりに**建物だけ**が中心（54件）になっている。
町にいない所有者の人物像に「長期保有」「代々の土地」「法要でこの土地の話が出る」等の
事実が入ったことと同時に起きているので、**どちらの効果かは切り分けられない**。
断りの一言にも「長期保有方針のため」が19件出た（v9b には無い言い回し）。

### 3-4. 借りている人と家主のあいだに、途切れない往復ができた

v9b には無かった経路で、36か月に554件（返事率95.8%）。
内容は挨拶と近況で、**売買の話にはほとんど発展しなかった**。
一言が届いたことのある家主の成約率 0.55%（182件中1件）と、
それ以外の 0.26%（778件中2件）に差があるように見えるが、**分子が1件と2件で、差とは呼べない**。

### 3-5. 変わらなかったもの

- **借家がある区画の成約は 0件のまま**（v9b は2件・v9c は0件。どちらも1桁）。
- 手紙の種別は「両方」が56%で同じ。
- 断りの一言はほぼ全員が書く（99%）。

## 4. 解釈しないこと

1本ずつしか走らせていないので、上の差はすべて**1本対1本の差**である。
成約（5→3）・退場（1→3）・借家借地の内訳は各0〜3件で、揺れと区別できない。
桁で言えるのは **3-1（借りている人の出口が実際に使われたこと）**、
**3-2（実行できない約束が0件になったこと）**、**3-3（出品が3分の1になったこと）**、
**3-4（往復が554件生まれたこと）**の4つである。
また 3-3 は「人物像の追記（①）」と「毎月の問い（②）」と「一言（③）」と「時間の表示（④）」が
同時に入った状態の結果であり、どれか1つの効果には帰属できない。
