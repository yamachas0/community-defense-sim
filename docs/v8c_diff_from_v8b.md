# v8b → v8c の差分と、その良し悪し

結果の本体は `docs/v8c_run.md`（単独で読める）。ここは**何を変えて、何が良くなり、何が悪くなったか**だけ。
設計の正＝`docs/world_design_v8c.md`。v8b の結果＝`docs/v8b_run.md`。

## 変えたのはこの4点だけ（世界の骨格・名簿・場所・36か月・seed 85 は同じ）

1. **応諾の語**：「応じる／応じない」→ **「売る／売らない」**。
   不可逆であることを問いの中に1行で書いた（両側の帰結を並べて）。
2. **全判断に「理由を一言」の欄**（行き先／出す・出さない／売る・売らない／会社の提示判断）。
   空欄可・40字。**「売らない」の理由だけが、条件を出した会社に翌月届く**（他は観測用ログのみ）。
3. **会社の目的文から「反発を招いて止まるほど目立つな」を削除**し、
   「合法な手段で、できるだけ多くの不動産を取得せよ。毎月動け。」にした。
4. **会社の提示に自己紹介の1行**を世界が必ず添える＝「私どもは海外の不動産投資会社です。」
   （国名なし・警戒語なし。町の人は提示を受けて初めて知る）。

会社の条件文の種類          43通り       98通り

## 良くなったこと

1. **「応じる」の誤読が消えた。** v8b では成約6件のうち4件が「まず応じて後で条件を詰める」＝
   交渉の入口だと読んだ結果だった（世界は「その月末に名義が移り戻らない」と書いていたのに）。
   v8c では「売る」という語にしたことで、その型の食い違いは1件も出ていない
   （もっとも、売った人自体が0人なので**消えたと断定はできない**）。
2. **断る理由が観測できるようになった。** 187件すべてに理由が書かれ（記入率100%）、
   3分の1（66件）が「条件が分からない」だった。v8b では「なぜ断ったのか」は
   内心から推測するしかなかった。
3. **会社の適応が見えるようになった。** 断りの一言を受け取った後に条件文を78回書き換えている
   （変更はすべて断りの直後）。条件文の種類は43→98通りに増えた
   ＝**同じ文を送り続ける機械から、言い換えを試す相手に変わった**。
4. 会社の名乗り（海外の不動産投資会社）が入ったことで、**町の会話に会社が出るのが第3月→第1月**に
   早まった。誰が来ているかが最初から言語化される。

## 悪くなったこと・代償

1. **取得が0件になった。** v8c では**自分に実行できない「交換」の提示が155/187件**観測された
   （会社は不動産を1件も持っていないのに、他人の物件を対価に差し出している。世界は提示文の
   中身を検証しないので止まらない）。ただし**4点を同時に変えた1本**であり、
   取得0との因果は分離できない（交換でない32件もすべて不成立）。
2. **町が静かになった。** 発話 531→203件、出席は第1月15人→後半3〜8人、
   「今月はどこにも行かない」が1,080回中779回（72%）。
   行き先にも理由欄を付けたことで「特に用事はないため」といった**外出しない理由**が
   毎月言語化された可能性がある（因果は測っていない）。会話が減れば人づての伝播も減る。
3. **売りに出す人が12人→3人に減った。** 出品の理由欄の記入率は50.6%と最も低く、
   「出す」という選択そのものが v8b より使われなくなった。
4. **売った人が0人なので、伝染・取得曲線・「売る理由」が測れない。**
   v8b で見えていた「早い売却が後の会話を変える」筋は、今回まったく観測できていない。
5. なお **出品33件は実人数3人のくり返し**であり、出品者についての割合は町全体に一般化できない。
   会話量の減少と理由欄の追加も同時に起きており、両者の因果は未識別である。

## 次に効きそうな一手（提案・未実施）

- **会社に「渡せるもの」を持たせるか、交換を世界の側で不可能にするか**を決める。
  今は「言えるが実行できない条件」を出せてしまい、断りの3分の1がそこで消えている。
  （どちらも世界の骨格に触るので、施主判断が要る。）
- **行き先の理由欄を外した版**と比べる。会話量の激減が理由欄由来かどうかは、
  そこを1つだけ戻せば分離できる（1本＝約$0.44）。
- 会話なしの対照（同じ seed・`configs/config_field_v8c_nochat.yaml`）は**実装済み・未走行**。
  見込み $0.35 前後。
