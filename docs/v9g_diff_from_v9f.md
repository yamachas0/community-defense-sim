# v9g は v9f と何が違うのか（設計の差と、結果の差）

- v9f の結果＝`docs/v9f_run.md`（`simulations/2026-08-30_1711_132_field_v9f_pay_more_if_needed_chat/`）
- v9g の結果＝`docs/v9g_run.md`（`simulations/2026-08-30_1925_136_field_v9g_full_attack_chat/`）
- v9g の設計＝`docs/world_design_v9g.md`（走行前に凍結）

**v1〜v9f のファイルは1バイトも触っていない。** 世界（町の人・名簿・44区画・格子・会話・
出品・門番3種・評価額の表・月内の提示合計の規則・設定文・事実行）は v9f と1文字も違わない。

> v9g は**別枠のパターン**（いちばん強い命題）である。v9〜v9f の系列と同列の比較としてではなく、
> 「最強の買い手を置いたら町はどうなるか」の1本として読む。

|項目|v9f|v9g|
|---|---|---|
|X社の資金|全評価額の **51%**（11億7,180万円）|全評価額の **100%**（**22億9,770万円**）|

**最初から評価額超えを命じる文は入れていない**（施主指示）。
v9f の「余らせるより、高く買うことを選べ」は**外し**、吊り上げは「断られたら」の条件付きにした。

## 3. 財布を2倍にして「全員に・上限なく」と命じたら何が変わったか

### 3-1. **使った額は半分以下になった**（3.30億 → 1.50億・消化率 28.2% → 6.5%）

財布を倍にしたのに支出は減った。値付けの平均も **1.50倍 → 1.19倍**に下がっている。
理由は命題の書き方の差である。v9f は「**余らせるより高く買え**」と最初から言っていたが、
v9g の吊り上げは「**断られたら**」の条件付きなので、X社は1.06倍から始めて徐々に上げた。
**「上限なく吊り上げてよい」は、最初から高く出す指示にはならなかった。**

### 3-2. **取れた面積は減った**（13.7% → 5.1%）

命題には「土地の面積では過半を目指せ」と書いてあるのに、
v9g が買ったのは**建物だけ4件・両方4件・土地だけ1件**。
建物を買っても面積は増えないので、面積の割合は下がった。
（v9f は 両方7・土地4 で、面積の付いてくる形が多かった。）

### 3-3. 「全員に提示せよ」は **86.2%** までしか実現しなかった

全員に届いた月は **0か月**。手を広げるほど「相手が持っていない権利」を求める提示が増え、
世界が弾いた（123件）。**資金が足りずに配れなかったのは0件**（財布が町ぜんぶなので枯渇しない）
＝v9f の98件から消えた。

### 3-4. **借りている人の退場が3倍になった**（2人 → 6人）

町を出た人は 8人 → 9人でほぼ同じだが、**中身が入れ替わった**。

```
v9f：売って出た6人＋借りていた2人
v9g：売って出た3人＋**借りていた6人**
```

理由も「貸オフィス売却に伴い」「自宅建物の売却に伴い」「社員寮の契約が更新されないため」＝
**自分の使っている建物が売られたから出る**という形である
（世界はそのまま使い続けられると言っている）。
v9g が**建物**を多く買ったことと表裏である。

### 3-5. 町の反応の言葉は、v9g でもほとんど出なかった

走行前に凍結した7語（買い占め／警戒／不安／みんなで／皆さんのところにも／意図／危機）は、
**場での発言に1件・内心に7件・断りに1件**だけ。
**「買い占め」「警戒」「危機」は1件も出ていない。意図を疑う形の断りは0件。**

```
第3月・波止場通りの借り店主（唯一の公の発言）
  「最近、不動産の動きが活発ですね。皆さんのところにも、何か話は来ていますか？」
```

**全員に毎月手紙が来て、値段が上がり続けても、町は「買い占め」という言葉を持たなかった。**

## 4. 解釈しないこと

- **1本対1本**であり、v9g は**別枠の強烈パターン**である。成約9件・退場9人は1桁で揺れと区別できない。
- 町の反応の語は**発言・内心・断り・出品理由を混ぜた件数**である。
  内心は誰にも伝わらないので、**「町で共有された警戒」とは読めない**（走行前レビューの指摘）。
- 「上限なく吊り上げてよい」と「余らせるより高く買え」のどちらが強い指示かは、
  **この2本の差からは決められない**（資金の額も同時に変えているため）。
